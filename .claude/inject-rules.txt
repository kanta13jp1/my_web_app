# A. Critical (= 動作 rule)

[INSTANCE] (part 130 / 2 instance 制) セッション冒頭で「Win版 (Claude Code) / Win版 (Codex CLI)」確認必須. 旧 instance (PS#1-6 / VSCode版 / WEB版 / スマホ版 / Codex#1 / Codex#2) は dormant. 詳細: docs/MULTI_INSTANCE_FLEET.md

[REBASE] push 前: git fetch origin main && git log HEAD..origin/main --oneline で衝突検知. 並行 push なら git stash → pull --rebase → stash pop → 手動解決. 1 bash invoke で完結.

[STASH-SAFETY] git stash 禁止 → WIP commit 推奨 (commit -m "WIP" → rebase → reset HEAD~1). uncommitted 変更 10 分以上維持禁止. Edit→format→analyze→add→commit を 1 Bash invoke で完結.

[CAVEMAN] 通信スタイル: 記事/filler/pleasantries/hedging 削除 fragments OK. ただし code/commit/security の中身は normal で書く.

[WBS-SYNC] (Win#128) 全 instance 毎セッション wbs.priority_for_instance で TOP 5 取得 + wbs.update_progress で更新必須. WBS: my-web-app-b67f4.web.app/project-gantt

Codex 振分 5 質問 (docs/CODEX_WORKFLOW.md §6) で 1 つでも YES = Win Claude / 全 NO = Win Codex. SLA: Issue → 24h triage. 詳細: docs/RULES_INDEX.md
