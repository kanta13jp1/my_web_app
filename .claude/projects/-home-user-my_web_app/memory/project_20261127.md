## 新規発見: Flutter Web 画像埋め込みの CORS 仕組み

### 1. CanvasKit の CORS 制限

Flutter Web は 2 つのレンダラーを提供:
- **HTML Renderer**: DOM 要素をそのまま使用
- **CanvasKit Renderer**: WASM ベースで自前で描画

CanvasKit は `<canvas>` 上に画像を描画するため、**ブラウザ同一オリジンポリシー（CORS）** に従う。
Wikimedia Commons のような外部オリジン画像は、CORS ヘッダーがない場合、CanvasKit デコード時に失敗する。

```
Request Chain:
Wikimedia URL → HTTP GET → CanvasKit が CORS チェック → 失敗 → Image.network errorBuilder へ
```

### 2. 公式対応: webHtmlElementStrategy パラメータ

**Flutter 3.29+ から** `Image.network` に `webHtmlElementStrategy` を追加可能。

```dart
enum WebHtmlElementStrategy {
  default,      // CanvasKit に統一
  fallback,     // CanvasKit 失敗時に HTML <img> へ
}
```

`webHtmlElementStrategy: WebHtmlElementStrategy.fallback` 指定時:
1. CanvasKit でデコード試行
2. CORS エラーなど失敗 → 自動的に `<img>` 要素へ切り替え
3. `<img>` の CORS ハンドリングはブラウザデフォルト（crossorigin 属性で制御可）

### 3. Wikimedia Commons URL 形式

Wikimedia API は以下フォーマットで画像 URL を返す:

```
https://upload.wikimedia.org/wikipedia/commons/thumb/
  <1st-char>/<1st-2chars>/File:<filename>.jpg/320px-File:<filename>.jpg
```

例: `File:Wind_Satire_001.jpg` → 
```
https://upload.wikimedia.org/wikipedia/commons/thumb/w/we/
  File:Wind_Satire_001.jpg/320px-File:Wind_Satire_001.jpg
```

**重要**: `File:` は大文字・コロン含む。名前不正が「404 Not Found」→ Image.network errorBuilder へ流れる。

### 4. 環境制約と検証戦略

#### 本セッション環境
- Proxy が Wikimedia URL を 403 Forbidden で遮断 → 直接 URL 検証不可
- **代替戦略**: CI 検証（flutter analyze / build web / format check）✅ + 本番環境での in-browser 検証

#### 本番環境での検証
URL: https://my-web-app-b67f4.web.app/sobriety-campaign
- CanvasKit 有効 → 実画像表示試行
- 失敗時 → HTML `<img>` フォールバック
- 両方失敗 → 背景の絵文字+グラデーション表示

### 5. 無回帰設計

```dart
_PrintImage(
  imageUrl: 'https://...commons.../File:...jpg',
)

// 内部構造
Image.network(
  imageUrl,
  webHtmlElementStrategy: WebHtmlElementStrategy.fallback,
  loadingBuilder: (_, __, ___) => SizedBox.shrink(),  // 読み込み中は透明
  errorBuilder: (_, __, ___) => SizedBox.shrink(),    // エラーは透明
)

// 背景は常に存在
Container(
  decoration: BoxDecoration(
    gradient: LinearGradient(...),  // 絵文字土台
  ),
  child: _PrintImage(...),  // ← Image は重ねただけ（失敗時も見える）
)
```

### 6. 次回注意点

- ✅ 新しい Web 動画機能: `webHtmlElementStrategy: WebHtmlElementStrategy.fallback` を必ず指定
- ⚠️ Flutter バージョン: 3.29 未満では使用不可。本リポ 3.38.x で OK
- 🔍 Wikimedia 画像が表示されない場合: Commons ファイル名の綴りを再確認（大文字・ハイフン・アンダースコア区別）
- 📸 ローカル検証: `flutter run -d chrome` でも同じ CORS 制限が発生するため、本番環境での検証が信頼性が高い
