# FLOW CITY

信号設定を変えた街Bと基準の街Aを同一需要で比較する。静止画でなく、セル上の車両移動から到着数・累積待機を算出する学習用モデル。Canvas 2Dの等角投影であり、3D物理エンジンではない。

## モデル

東行3本・南行3本の一方通行路、9交差点、直進のみ。1セル1台、1tickに最大1セル。交差点進入は信号と占有状態で許可する。更新は車両ID順で、この順序によるバイアスがある。現実の加減速・車間・右左折・歩行者・実秒との対応は扱わない。

720tickの同条件比較。最初の480tickに需要を生成。外部待機車も累積待機に含める。完了は観測期間終了であり全台到着の保証ではない。固定seedと設定で再現できる。Bの設定変更は両街をリセットし、異なる条件の途中結果を混ぜない。

## 検証と動画

`node --test model.test.mjs`はクラウドで実行予定。未実行を合格としない。ブラウザの表示・スマホ幅・保存失敗・停止復帰を別途検証する。40秒程度の動画: 全景→Bの信号設定→比較実行→実測指標→再実行。同じseedでの再現性を示す。録画は本番確認後のみ。
