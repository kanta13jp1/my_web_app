AI使用量の比較ノート

文章を増やしたとき、どこで使用量が増えたか。
記録した数値を、条件ごとに分けて見てみましょう。

1. 測定した記録を用意する

AI（人工知能）へ渡す文章は「トークン」という細かい単位で数えます。同じ入力を再利用する「キャッシュ」は、作成と読み込みを分けます。

入力はこの画面の中だけで計算します。外部送信・自動保存・AI呼び出しはありません。再読み込みすると消えます。

自分の記録を貼り付けるか、公開済みの測定例を選んでください。

入力する形式を見る

JSON（項目名と値の組でデータを表す形式）の配列です。1行が1回の作業。最大200試行・12条件、同一モデルで比較します。異なる課題や設定を混ぜると、単純比較できません。

[{"id":"試行1","condition":"短い指示","model":"測定したモデル名","input":100,"cacheWrite":20,"cacheRead":80,"output":50,"turns":2,"modelUSD":0.001,"runUSD":0.001}]
id / condition / model
試行を区別する名前 / 比較条件 / 使用したAIモデル（応答を生成する仕組み）の名前。
input / cacheWrite / cacheRead / output
通常入力 / キャッシュ作成 / キャッシュ読み込み / 出力のトークン数。二重計上しない内訳を入力します。
turns
その作業でモデルへ要求した回数。1以上。
modelUSD / runUSD
対象モデル分 / 小型モデルなども含めた作業全体の報告換算額（米ドル）。実際の請求額とは異なります。分からない数値を0で埋めないでください。
