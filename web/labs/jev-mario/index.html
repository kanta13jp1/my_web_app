1. 測定モード

初代1-1を参考に一から実装した再現ゲームです。原作ROMの実行や完全一致ではありません。手動プレイはAPI不要です。

クリア演出後に1-1→1-2→1-3→1-4→2-1→2-2→2-3へ自動で進みます。得点・コイン・残機・パワーを引き継ぎます。2-1は土管・穴・階段・敵を配置した独自の地上コースで、クリアすると2-2へ進みます。2-2は水中の独自コースで、ジャンプを押し直して泳ぎ、右端下部の土管を目指します。水中の敵は踏んで倒せません。2-2クリア後は、橋の切れ目と跳び上がる魚を避ける独自コース2-3へ進みます。2-3の旗で現在のキャンペーンを終了します。1-4は溶岩・回転する炎・橋の先の斧を目指す独自配置の城コースです（ボス戦は未実装）。1-3は足場と穴のある独自配置の空中コースです。1-2は独自配置の地下コースです。移動床・ワープゾーンは未実装。LightGBMは1-1で学習したモデルをそのまま使います。

BGM・効果音

音声ON（遊ぶボタンで再生開始）

地上・地下・城・水中・無敵・残り時間に合わせたオリジナル8bit風BGMと操作に同期する合成効果音です。停止・タブを非表示にすると音も止まります。

← →: 移動 ／ Space・X: ジャンプ（長押しで高く）／ Z: ダッシュ ／ ↓: しゃがむ・土管（離すと立つ）。スマートフォンは画面下の操作ボタンを使えます。

LightGBM＋探索は60秒で終了せず、クリア後も次のステージへ続きます。ミス・最終ステージ終了・停止ボタン・タブの非表示で停止します。別ウィンドウをクリックしても、表示中の自動プレイと録画は継続します。録画は1本最大60秒です。

LightGBMはJevの166局面から学習したモデルです。地形と物理を使う探索が判断を補助します。モデル単体の攻略ではなく、クリアは端末性能にも左右されます。初回のみモデルを読み込み、ゲーム状態は送信しません。

敵との距離・速度から計算した予測値を追加します。通信時間や判断の改善を保証するものではありません。同じ開始条件で比較してください。

補助は敵・穴・壁に対してジャンプを加える端末内ルールです。Jev単独の性能とは別に評価します。全ステージの安全やクリアは保証しません。ROM・固定状態モードには適用しません。

ROMはこのブラウザ内だけで処理します。ゲーム本体の同梱・アップロードはしません。SMB1の標準NROM版に対応。別ゲーム・改造版のRAM解析は対応外です。

Enter: START ／ ← →: 移動 ／ X: ジャンプ ／ Z: ダッシュ。手動で1-1に入り、Jev測定を開始してください。音声は無効です。

クラウドJevは設定したAPI回数または60秒でゲームと測定を停止します。自動で追加リクエストは行いません。続けるには測定を再開してください。リクエストは同時に1件のみ。API利用量を消費します。実ゲームは通信中も進み、設定した応答の有効期限を超えた応答は操作へ適用しません。

通信往復が有効期限を超えると、成功した応答も操作には使いません。期限を延ばすと適用しやすくなりますが、古い状態への判断でミスが増える場合があります。通信待ち中もゲームは進み、測定時間は補正しません。
