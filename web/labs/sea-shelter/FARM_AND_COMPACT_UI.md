# 農園とコンパクト画面

今回の追加はDraft PRまで。本番公開済み1.0.2268には含まれない。

## 遊び方

- 資源と回収は常時表示。PCは盤面と右タブ、スマホはタブで中央表示を切り替える。
- 建設タブで施設と費用を確認して盤面へ配置。取消は資材を消費しない。成功後は配置選択を解除。
- 菜園を建設し、盤面の菜園を選ぶか菜園タブを開く。木材2で種まき、60秒後に食料3を手動収穫。
- 食卓へ食料3を届けると木材4・金属1・EXP2。住民依頼とは別の繰り返し可能な循環。
- プロフィール、遊び方、保存状態、やり直しは上部から開く。

## 保存と時刻

既存の保存キーとversion1を維持。農園情報がない旧保存は食料0・作物なしへ移行し、既存資源・施設・依頼・プロフィールを保持する。不正な農園情報だけなら警告を表示して農園だけを初期化し、既存の拠点進行を保護する。拠点本体も壊れている場合は従来の初期化処理を使う。

作物は菜園座標と種まき時刻で保存。1回の収穫で作物を消費し、連打では二重報酬を得られない。栽培中は菜園を建て替えられない。端末の時計が戻ると待機、7日超の変化では収穫報酬を付けず種まき時刻を更新する。

ブラウザ内保存のみ。端末間同期、時計やlocalStorageの改ざん防止、複数タブの同時編集の競合解決は含まない。

## 画面の方針

通常のPC1280×720/1366×768とスマホ320×568/360×640/390×844ではページスクロールなしで盤面・資源・回収・タブへ到達できることを検証する。タッチ領域は44px以上。長いタブ内容には内部スクロールを許可する。

低い横向き画面、拡大文字、ソフトキーボードでは可読性と到達性を優先し、ページやダイアログのスクロールを許可する。操作をoverflow:hiddenで隠さない。
