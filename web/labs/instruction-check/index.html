Claude Codeの指示ファイルを確かめる練習

ファイルに書いた目印は、
AIの返答に出てくる？

Claude Codeは、プログラムを書く作業を手伝うAIです。CLAUDE.mdやAGENTS.mdは、AIに作業のルールを渡すための「指示メモ」です。

確かめたいのは、どの指示メモの内容が返答に現れるか。メモごとに別の目印を書き、AIに目印を答えてもらって比べます。

このページは、あなたが貼り付けた返答を照合する道具です。Claude Codeの起動やファイルの読み取りは行いません。下の練習例は、AIを使わずに試せます。

1. 何を比べるの？

2枚のメモに、別々の目印を付けると考えてください。目印は秘密のパスワードではなく、どのメモの内容が返ったか見分けるための文字です。

CLAUDE.mdに書く

LOADMARK: MARK_C

MARK_Cがこのメモの目印です。

AGENTS.mdに書く

LOADMARK: MARK_A

MARK_Aがもう1枚の目印です。

LOADMARK:は目印の置き場所を示す、この実験用の見出しです。Claude Codeの特別な設定命令ではありません。

続いてAIに「渡されている指示メモのLOADMARK行の値だけを返してください。なければNONE。推測しないでください」と質問します。

質問にはMARK_CやMARK_Aそのものを書きません。答えを質問に書いてしまうと、ファイルを使わず質問をまねただけでも正解できるためです。

返答がMARK_Cだけなら、「CLAUDE.md側の目印は返った。AGENTS.md側の目印は返らなかった」と読めます。返らなかったことだけで、そのファイルを読んでいないとは断定できません。読んでも答えから省く可能性があるためです。

4. ツールの回数も見るのはなぜ？


知りたいのは、質問する前から指示メモの内容がAIへ渡されていたかです。しかし、質問のあとにAIがツールでファイルを開けば、その場で目印を探せます。


    

  • 空欄（未確認）：目印の有無だけを比べます。途中でツールを使ったかは、ログで別に確認します。
    • 

  • 使用回数0：入力した記録上は、途中でツールを使っていません。目印が返ったことは確認できますが、それだけで読み込みの仕組みまでは証明できません。
    • 

  • 使用回数1以上：途中でファイルを開いて答えを見つけた可能性を、この画面では取り除けません。どのツールを何に使ったか、実行ログを確認します。
    • 



上の照合フォームの回数はあなたが入力した値です。実測エリアの回数は保存ログから取り出したイベントと照合しています。この画面はログの正しさや、指示をすべて守ったか、安全な操作だったかを判定しません。






5. 自分の環境では、何を変えて試す？


    

  1. 作業用の空フォルダーを用意し、Claude Codeの版をclaude --versionで記録します。
    2. 

  2. 最初に指示ファイルなしで試し、次にCLAUDE.mdだけ、AGENTS.mdだけ、両方の順に配置を変えます。各条件は新しいセッションで試します。
    3. 

  3. ファイルに、普段の文章と紛れない目印を置きます。自分の試験では、この例と異なる目印にすると、例を覚えて答える影響を減らせます。
    4. 

  4. 質問に目印の値を含めず、返答とツール使用記録を保存します。起動時の設定も条件ごとに残します。
    5. 

  5. このページへ目印・返答・確認済みの使用回数を入力し、同じ条件で比較します。
    6. 



版や配置、設定を一度に変えると、何が違いを生んだか分かりにくくなります。具体的な設定と2026年9月22日の結果はCLAUDE.mdとAGENTS.mdを比べた検証記事で説明しています。
