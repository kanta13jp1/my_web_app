# LUMEN PATH — independent prototype

Episode 4, initial source candidate created 2026-09-12. Not executed, visually reviewed, integrated or published yet.

## Why this direction

The bounded X research showed editable 3D artifacts and playable, guided games. This original arrangement aims at an immediately visible causal interaction: one mirror changes a complete light path. It does not reproduce those creators' assets, brands, levels or code. Beam-routing is an established puzzle genre; no claim of inventing the genre or surpassing all X posts.

Alternatives considered: another mechanical cutaway overlaps AERO LAB; another city or strategy board overlaps FLOW CITY and risks a less readable mobile video. The small light puzzle has a narrower, testable scope and large visible paths.

## Scope and truthfulness

Three authored levels, two mirror orientations, colored/symbol-marked targets, deterministic ray tracing, undo/reset and a bounded exhaustive hint search. SVG/HTML, no external graphics assets or paid API. Not a physical optics simulator, AI-powered runtime or 3D model. No persistence; reload intentionally resets. No session cost or model-effort claim without execution evidence.

The owner approved the episode-4 Claude design-review exception; no Claude review was performed. This candidate does not alter Flutter routes, authentication, billing, database, main or production. Repository integration design still needs current route/catalog and full applicable principle checks.

## Planned verification

Five Node model tests plus three Playwright flows on desktop and mobile using the existing repository configuration. Run against the candidate cloud server, not the old production site. Inspect initial/solved screenshots at phone size, keyboard focus, path alignment, empty/invalid state and console errors before approving release. Tests are authored, not yet executed.

## Video plan after production verification

0–3 seconds: one click redirects a beam and lights a target. 3–15: undo and solve again. 15–30: three-mirror route with hint highlighting. 30–45: three colors arrive at targets; show real URL. Record real interactions at normal speed, no replacement generated footage. This is a storyboard, not an existing recording.
