Jibun Spreadsheet for Windows 1.0.0
===================================

Windowsで使える、ローカル保存型の表計算アプリです。

主な機能
--------
- セル編集
- 四則演算と SUM / AVERAGE / MIN / MAX
- セル参照と範囲参照
- 複数シートの追加・切替・名前変更
- CSVの読み込み・書き出し（Excel互換UTF-8 BOM）
- 自動保存、元に戻す、やり直す
- Ctrl+S / Ctrl+Z / Ctrl+Y

動作環境
--------
- Windows 10 / 11（64bit）
- 画面解像度 1280 x 720 以上を推奨
- インターネット接続は不要です

起動方法
--------
1. ZIPを任意のフォルダーへ展開します。
2. JibunSpreadsheet.exe をダブルクリックします。
3. Windows SmartScreenが表示された場合は、販売ページに記載されたSHA-256と
   ダウンロードしたZIPのSHA-256が一致することを確認してください。

注意事項
--------
- EXEだけを別フォルダーへ移動しないでください。dataフォルダーとDLLが必要です。
- データは利用者のWindowsユーザー領域へ保存されます。
- 重要なブックは定期的にCSVへ書き出してください。
- Microsoft Excelの全機能やXLSX形式との完全互換を保証する製品ではありません。

アンインストール
--------------
展開したフォルダーを削除してください。保存データも削除する場合は、販売ページの
サポート窓口へお問い合わせください。
