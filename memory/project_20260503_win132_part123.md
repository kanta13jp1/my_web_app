## 技術的詳細

### platform ID 命名差異
- `blog_posts.target_platforms`: `zenn` `qiita` `note` `hatena` `medium` `devto` `hashnode` `substack` `github-pages` `notion` `x-article`
- `tech_blog_posts.platform`: `zenn` `qiita` `hatena` `note` `medium` `devto` `hashnode` `substack` `github_pages` `notion` `x_article`
- `_normalizePlatformId()` で `-` → `_` 統一

### `posted_at` 型処理
- `blog_posts.posted_at` = `timestamptz` (e.g. `2026-05-03T19:08:00+09:00`)
- yyyy-MM-dd 前方一致で判定 (= JST 前提 / timezone 考慮なしの単純実装)

### degrade safe
- `blog_posts` RLS 失敗時は try/catch で空 list (= 既存挙動と同じ動作)
- 既存 manual 記録 (= `_togglePost` / `_showAddDialog`) 無変更
