- 症状:

## Root cause 分析

`lib/pages/election_victory_page.dart` L1181-1310 (修正前):

```dart
Row(
  crossAxisAlignment: CrossAxisAlignment.start,
  children: [
    Expanded(child: Column(...)),  // 「最新の実データ」+ 説明
    const SizedBox(width: 12),
    Wrap(spacing: 8, alignment: WrapAlignment.end, children: [
      // 9 buttons (= 公開URLコピー / 集計ノート化 / KPIノート化 / 集計リンク /
      //   KPIリンク / 選挙ポスト作成 / X共有 / 最新取得 など)
    ]),
  ],
)
```

**Layout 計算**:
- `Wrap` は子要素を 1 行に配置するための intrinsic 幅を要求
- 9 button × 平均 130px = ~1200px 必要
- 親 `Row` は viewport 幅 ~1280px から `SizedBox(12)` 引いて分配
- `Expanded(child:Column)` は flex=1 で残幅取得 → でも Wrap が non-Flexible で先に 1200px 確保 → Expanded 残幅 ≈ 30-40px
- 「最新の実データ」(= 7 文字 × 16px font ≈ 112px) が 30px 幅に押し込まれて wrap → 1 文字 / 行

= classic Flutter Row + Expanded + non-Flexible Wrap pitfall.

## 完了 (= 1 ファイル / +51 / -32)

`lib/pages/election_victory_page.dart` L1181-1316 を以下構造に修正:

```dart
LayoutBuilder(
  builder: (context, constraints) {
    final wide = constraints.maxWidth >= 900;
    final textColumn = Column(...);  // 「最新の実データ」+ 説明
    final actionWrap = Wrap(
      spacing: 8, runSpacing: 8,
      alignment: wide ? WrapAlignment.end : WrapAlignment.start,
      children: [...9 buttons...],
    );
    if (wide) {
      return Row(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Flexible(flex: 5, child: textColumn),  // ← Expanded を Flexible 5/12 に
          const SizedBox(width: 12),
          Flexible(flex: 7, child: actionWrap),  // ← non-Flexible だった Wrap を 7/12 に
        ],
      );
    }
    return Column(  // narrow viewport 専用 layout
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [textColumn, const SizedBox(height: 12), actionWrap],
    );
  },
),
```

### 効果
- **wide (≥ 900px)**: textColumn と actionWrap が 5:7 比率で並列 → 文字潰れない
- **narrow (< 900px)**: 縦積みで full width 利用 → モバイル / 狭い viewport で自然
- **9 button** は両 layout で同じ Wrap 子要素 (= コード重複なし)
