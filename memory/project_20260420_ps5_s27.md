## 新パターン: local metadata merge

**発見した制約**: hub の `goal.update` は metadata を **full replace** で上書きする。

→ 単一 field 変更 (milestone の done / status) のみ送ると他 field (title/description/deadline/milestones) が消失。

**対応**:
1. `_findGoalById(goalId)` helper で `_activeGoals + _completedGoals` から goal lookup
2. 既存 metadata を `Map<String, dynamic>.from()` で clone
3. 変更分を merge (例: `meta['milestones'] = updated` / `meta['status'] = status`)
4. 全 metadata を body に `...meta` spread で送信 → `{'action': 'goal.update', 'id': goalId, ...meta}`
