1. **「次 part 候補」が次 part で実際に着地」pattern 確立** — part 117 §5.2 で起草 → part 118 で実装. 「memo の next-candidate が memo の next-part で消化される」自走 cycle. これ自体が #1647 受け入れ条件 #3 で自動化される構造 (= 自己言及的).

4. **memo seed 化 pattern** — repo `memory/` に過去 memo を commit するだけで scan 対象が成立. workflow 修正不要. 「インフラを整えれば content は後から付いてくる」第 N 例.
