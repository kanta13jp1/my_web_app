## 対応 Issues

### 修正1: social-commerce-hub CI 失敗 (#506 #508 #509 #511 #512)
**Why:** `esm.sh/@supabase/supabase-js@2` が 522 (connection timeout) で EF bundling 失敗
**Fix:** `https://esm.sh/@supabase/supabase-js@2` → `npm:@supabase/supabase-js@2`
**File:** `supabase/functions/social-commerce-hub/index.ts`
**Result:** 5件 CI失敗 Issue close

### 修正2: AI大学シェアURL旧名+ハッシュタグ (#517 priority:HIGH)
**Why:** 共有URLが旧名 `/gemini-university` のまま、ユーザーが不要なハッシュタグ不要と申告
**Fix:**
- URL: `#/gemini-university` → `#/ai-university` (3箇所)
- ハッシュタグ行削除 (6箇所)
- `main.dart` に `/ai-university` ルートエイリアス追加
**Files:** `lib/widgets/ai_university_home_card.dart`, `lib/pages/gemini_university_v2_page.dart`, `lib/main.dart`

### 修正3: ホーム「最近使った機能」履歴ゼロ (#519 priority:medium)
**Why:** `recordFeatureTap()` がどこからも呼ばれていない (helper定義済み・呼び出しゼロ)
**Fix:** `_runTrackedAction` に `unawaited(recordFeatureTap(toolId, toolId))` を追加 + import
**File:** `lib/pages/home_page.dart`

### 修正4: ギタースタジオ AI フィードバックが実音を参照しない (#513 priority:high bug)
**Why:** `generateRecordingFeedback()` がメタデータのみを Gemini に渡していた。同条件の録音で完全一致の文が出ていた
**Fix:**
- Supabase Storage から音声ダウンロード → base64 → Gemini `inline_data` で送信
- 15MB 超 or DL失敗時はメタデータのみフォールバック
- 戻り値を `string` → `{ text, source }` に変更 (source: gemini_audio | gemini_meta | fallback)
- `ai_feedback_source` カラム追加マイグレーション作成
- `mapAudioMime()` ヘルパー追加 (m4a/mp4/aac/mp3/ogg/flac/wav 対応)
**File:** `supabase/functions/guitar-recording-studio/index.ts`, `supabase/migrations/20260419220000_add_ai_feedback_source_guitar.sql`
