## 学び

1. **OneDrive sync lock の解除手順** (= bug pattern):
   - 一般的 `rm -rf` は Permission denied
   - **正解 sequence**:
     1. PowerShell `Get-ChildItem -Recurse -Force | Set-ItemProperty -Name IsReadOnly -Value $false`
     2. cmd `attrib -r -s -h <path>\* /s /d`
     3. cmd `rd /s /q <path>` (= 1 回で残存あれば 2-3 回反復)
   - これは **Win territory の Windows-native 知識** で Win Codex (= bash 系) では再現困難.

2. **Google Drive 暗号化フォルダ (= G:/.Encrypted/)** は普通の `rm -rf` で削除可能. パス内日本語 (= マイドライブ) も bash 経由で問題なし (= UTF-8 encoded path).

3. **bash `ls` cache 問題**: 削除直後 `ls` が古い entry を返すことがある. **`Test-Path` (PowerShell) で確認** が確実.

4. **「外部フォルダ削除も Win Claude territory」確認** — 一見「Codex 担当 (= scripts)」に見えるが、Windows-native 操作 (= attrib/icacls/cmd rd) は Win Claude (= Claude Code Win版) が直接 PowerShell tool 呼出して実行する方が早い. Codex CLI 経由だと bash + cygwin 経由になりトラブル多.
