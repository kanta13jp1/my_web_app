# PS版#4 S27 セッションメモ — 2026-04-20 夜 last 4

## 実施事項

S26 で Notion credit 単価を 2 社検証 → S27 は audit round 3 として **Cowork pricing 構造改定** ($200 flat → $20/seat + usage) を 6 ソースで検証。PS#2 本C (D-0・5/4 dispatch) は Notion 課金移行訴求が主軸だが、**同日 Anthropic も usage-based 強制移行中** = 2 段ロケット framing 可能。

### 検証結果 (公式 + 5 独立報道)

- 公式: `claude.com/pricing` ($20/seat base + standard API rates 確認)
- 独立報道:
  - The Register (4/16 · 「Anthropic ejects bundled tokens」)
  - PYMNTS (「switches to usage-based billing」)
  - Gizmodo (「hiked the price for power users」)
  - npifinancial (「lower seat fees, higher TCO」 構造分析)
  - Kingy AI (「2026 pricing shift changes everything」)
- **共通結論**: 表面の「$200 → $20」は値下げに見えるが、構造変更で TCO は上昇

### 新構造 3 点 (npifinancial 分析)

1. **強制コミット枠 (mandatory consumption commits)**: Anthropic 推定の月次 token 量を pre-pay → 実消費が下回っても請求
2. **大口割引廃止**: 従来の 10-15% volume discount が消滅
3. **per-token 単価は不変**: 値上げ要因は「コミット強制 + 割引廃止」の構造変更のみ

### インパクト

- Fredrik Filipsson (Redress Compliance 試算): **heavy users で 2-3 倍コスト増**
- npifinancial: 「For most enterprises, total cost of ownership goes up」
- 転換時期: 2025-11 から renewal-based 段階移行 / 2026-02 で all-inclusive Enterprise seat 化 (chat + Code + Cowork)
