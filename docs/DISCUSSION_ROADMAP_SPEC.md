# 議論ロードマップ・マイルストーン可視化仕様書 (#2807)

## 1. 目的

複数の論点・合意形成プロセスにおける目標スケジュール（総論討議・条文起草・合意済み・原案提出）をタイムライン形式で登録・可視化し、スケジュール変更時の遅延／前倒し（`deltaDays`）を不変の監査履歴として記録する。

## 2. 議論ステージ定義

| ステージキー | 日本語ラベル | 意味 |
|---|---|---|
| `general_debate` | `総論討議` | 論点整理・基本方針の討議段階 |
| `drafting` | `条文起草` | 条文・仕様案の起草段階 |
| `agreed` | `合意済み` | 関係会派・レビューア間の合意完了 |
| `submitted` | `原案提出` | 正式提出・発議完了 |

## 3. 不変監査ログと UI 制約

- マイルストーンの日程変更時は `deltaDays = (nextTargetDate - previousTargetDate) / 86400s` を算出し、削除・改変不可の監査ログ（`MilestoneScheduleAuditEntry`）へ追記する。
- Flutter UI（`DiscussionRoadmapTimelineCard`）は `360x800` 画面幅・`TextScaler.linear(2.0)` 下でも水平オーバーフローを起こさないよう `Wrap` レイアウト、最小タップ領域 `Size(64, 48)`、7文字以下のボタンラベルを厳守する。
- DB マイグレーションは `0` 件。
