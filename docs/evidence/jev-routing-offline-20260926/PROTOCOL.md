- 合成JSON課題12件、正解はcases.pyへ事前固定。短い課題に限定し実務の代表性はない。
- Jev jev-1.13.0へ各課題1回、fast/strongの2択を問い合わせる。正解・モデル出力は渡さない。全振り分けを生成モデル実行前に固定。
- fast=claude-haiku-4-5（effort未指定）、strong=claude-sonnet-5（effort low）。モデル構成全体の比較であり思考量を揃えた比較ではない。

- 各課題を両モデルで各1回、計24応答。順序seed20260926で固定。ツール/MCP/skills/自動メモリー無効、セッション保存なし。CLI timeout120秒、報告コスト上限0.5ドル/呼出、基盤失敗時停止・再試行なし。
- 外部コード実行は一切せず、応答全体をjson.loadsで解釈し事前正解と型・構造・値一致で採点。Markdown囲みも不合格。採点規則は結果後変更しない。
- 全fast、全strong、事前Jev選択の3方針を保存済み応答から再生。選択方針は対応する実応答を採用する反実仮想集計であり、新たな独立セッション12回の実測ではない。途中でモデル変更する複数ターン処理は未検証。
- 主評価:課題完全一致数/12。副評価:CLI total_cost_usd合計、usage、往復時間。CLI報告値は実請求やサブスク利用枠ではない。Jev入力token×0.042/1e6ドルは公式料金概算で別に足す。今回全体の測定は24応答+Jevを消費する。
- 結果を見たラベル・閾値・プロンプト変更なし。1回/課題のため統計的優位や一般的な節約効果は結論しない。誤答も全て保存。
- 入力/runner/CLIバージョン/計画のSHAを実行前に固定。認証アダプター・生ログは公開しない。
