# Blender MCP実践の証跡

実証run: https://github.com/kanta13jp1/my_web_app/actions/runs/39093308340
検証対象: 98744d8a6f5e7e92bbba8654f4dbc80532cf7d31。生成物は同runからハッシュ照合後に取り込んだもの。

Codexが用意した検証コードをGitHub Actionsで実行し、Python MCP SDKからコミュニティ版サーバー2.1.9を経由してBlender4.0.2へ接続。現チャットのDesktopネイティブBlenderツール呼出しとは区別する。

MCP初期化・9ツール検出・5呼出し成功、24メッシュ・1360頂点・編集メッシュ換算2628三角形。GLB書出し後は4336頂点・2628三角形。編集状態とファイル内の頂点数を同一としない。

PC1280x900、スマートフォン390x844、取得失敗と再読込回復の3条件で、操作・回し過ぎ防止・やり直し・横はみ出しなし・ページ例外なしを確認。実描画画像は同runのartifactに保存。画像は実際の実習画面であり、Blenderの静止画レンダリングを操作証跡へ代用していない。

初回はGitHub sourceのconfig.py不足で失敗。2回目はGLB exportのnumpy不足で失敗。配布wheelと同梱addon、python3-numpyを固定した構成で成功した。ログには未使用のDraco圧縮ライブラリ不足のメッセージもあり、非圧縮GLBで構造確認・ブラウザー読込を成功した。一般的な速度向上・全Codexクライアントの互換性・人の実機操作は未検証。

モデルと制作スクリプトは本依頼で作成したオリジナル。外部モデル・有料生成サービスなし。描画Three.jsはMIT、配布LICENSEを同梱。テレメトリー無効・safe mode有効。アプリ本番配信・Zenn公開・X投稿はこの時点では未実施。
