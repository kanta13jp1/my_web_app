# 合成6ケースの再現ファイル

このフォルダーのデータは、架空の日別クリック・送信件数を使う6例です。個別の利用者データ、認証情報、外部サービスへの接続処理は含みません。同じ入力を別の論点で扱う例があり、独立した入力の組は5種類です。

Python 3で保存済みの結果を変更せずに検算するには、このフォルダーで次を実行します。

```sh
python -B replay.py
```

`verify.py` は再計算結果で `results.json` を上書きします。前の結果を保持する場合は、先にフォルダーをコピーしてください。これらのスクリプトはサイトへのアクセスや本番データの取得を行いません。取得できなかった行動や施策の因果効果も、この計算からは分かりません。

判定条件は `PROTOCOL.md`、人工入力は `cases.json`、保存済みの結果は `results.json` です。保存結果の実行日時は、初回実験の2026年9月27日を示します。
