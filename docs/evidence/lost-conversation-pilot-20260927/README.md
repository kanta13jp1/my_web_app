# 複数ターンのJSON出力：保存済みパイロットの再採点

人工的な注文5件を使い、条件を一括で渡す場合、会話を分ける場合、全条件を別の新しい会話に渡す場合を各1回ずつ比較しました。保存されている5応答のうち、最終応答3件の厳密なJSON採点を再現します。実行条件は `protocol.json`、モデルの保存済み応答は `responses.json`、事前の採点結果は `scores.json` です。

Python 3でこのディレクトリから次を実行します。

```sh
python -B verify.py
```

プログラムは保存したファイルのプロトコルのSHA-256、応答件数、モデル表示と採点結果を照合します。モデルへの接続は行いません。成功時の結果は、厳密なJSONとして1/3件が合格です。残る2件はJSON配列をコードフェンスで囲んだため厳密な解析に失敗しました。人が囲みを除いた内容を確認したところ、いずれも正しい配列でしたが、これは事後の確認であり事前採点の変更ではありません。

1モデル・1課題・各条件1回の観測から一般的な成功率や会話分割の効果は推定できません。RESETは全指示を新しい会話に再提示した別標本であり、会話をリセットすると回復することを実証しません。Microsoft Researchの多課題研究における39%低下の再現実験でもありません。
