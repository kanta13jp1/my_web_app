## 依存パッケージ注意

### Deno Edge Functions — deno.land/std バージョン古化 (継続課題)

**問題**: ほぼ全 Edge Function が `deno.land/std@0.168.0` を使用 (一部 `@0.177.0`)。
Deno std 0.168.0 は 2023 年初頭のバージョンで、現在の最新 (0.224+) と比べ大幅に古い。
前週からの継続課題。

```typescript
// 現在 (大部分のEdge Functionで使用)
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";

// 推奨: JSR移行 (Deno公式推奨)
import { serve } from "jsr:@std/http/server";
// もしくはバージョン更新
import { serve } from "https://deno.land/std@0.224.0/http/server.ts";
```

**影響範囲**: 50本以上の Edge Function
**リスク**: セキュリティパッチ・パフォーマンス改善・バグ修正の未適用
**推奨対応**: 一括置換 (`sed -i 's|std@0.168.0|std@0.224.0|g'`) → `deno lint` 検証

### Flutter (pubspec.yaml) — http パッケージのバージョン未固定 (継続課題)

**問題**: `http: any` と記載されており、バージョン制約がない。

```yaml
# 現在 (バージョン制約なし)
http: any

# 推奨
http: ^1.2.0
```

**推奨対応**: `flutter pub deps` で現在の解決バージョンを確認後、制約を追記。
