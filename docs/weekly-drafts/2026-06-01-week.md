- **Linux**: Keyring ロック時に不正バイトが返るバグを修正

`flutter_secure_storage` はログイン情報やトークンの保存に使われるため、**早期マージ推奨**。

### ℹ️ Deno Edge Functions: deno.land/std@0.224.0 (将来リスク)

`supabase/functions/` 配下の全 Edge Function が旧来の `deno.land/std@0.224.0` URL を使用中。
Deno 公式は JSR (`jsr:@std/...`) への移行を推奨しており、`deno.land/std` は長期的に非推奨扱いになる予定。
即時の CVE はないが、Supabase ランタイムのアップデートに合わせた段階的移行を検討すること。
