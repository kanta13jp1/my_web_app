## 依存パッケージ注意

### Deno Edge Functions: `deno.land/std@0.168.0` が大幅に古い

- **現状**: 全 Edge Functions (40関数以上) が `https://deno.land/std@0.168.0` を使用
- **最新**: `deno.land/std` は現在 `0.220+` (2024年)
- **差分**: 約52マイナーバージョン遅れ (リリース日: 0.168 は 2022年末頃)
- **リスク**:
  - `serve()` API は Deno 1.35+ で標準 `Deno.serve()` に移行推奨
  - `std@0.168.0` 以降にセキュリティパッチが複数適用済み
  - `crypto/mod.ts` の古いAPIが `memo-reactions/index.ts` で使用中
- **推奨対応**: `std@0.220.0` 以上に一括アップグレード + `serve()` を `Deno.serve()` に移行
