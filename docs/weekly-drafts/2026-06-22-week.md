## 依存パッケージ注意

### 1. pubspec.yaml — `http: any` (バージョン未固定)

```yaml
http: any   # supabase 依存のため any に設定されているが脆弱性対応が遅延するリスク
```

- **問題**: バージョン制約なしのため、最新のセキュリティパッチが自動適用されず、また破壊的変更に無防備
- **推奨対応**: `http` の現在解決バージョンを `pubspec.lock` で確認し、`^1.2.x` 等の明示的な制約に変更する

### 2. Supabase Edge Functions — `deno.land/std@0.224.0`

- **問題**: 全49ファイルが `deno.land/std@0.224.0` を参照。2026年6月時点で Deno std は大幅バージョンアップされている可能性が高く、古いバージョンには潜在的な脆弱性が存在する場合がある
- **確認箇所**: `supabase/functions/_shared/mcp_auth_guard.ts` の `jose@v5.9.6` (JWT検証ライブラリ) も同様にバージョン固定確認が必要
- **推奨対応**: `deno.land/std` を最新安定版へ一括アップグレード (import map / deno.json で一元管理が望ましい)
