## 依存パッケージ注意

### Deno Edge Functions — deno.land/std バージョン古化 (要対応)

**問題**: 全238本以上のEdge Functionが `deno.land/std@0.168.0` を使用。
Deno std 0.168.0 は2023年初頭のバージョンであり、2026年現在の最新 (0.220+) と比較して
**約2メジャーマイナーバージョン以上古い**。

```typescript
// 現在 (全Edge Functionで使用中)
import { serve } from "https://deno.land/std@0.168.0/http/server.ts";

// 推奨: 最新バージョンへの更新、またはJSR移行
import { serve } from "https://deno.land/std@0.220.0/http/server.ts";
// もしくはJSR (Deno公式推奨)
import { serve } from "jsr:@std/http/server";
```

**影響範囲**: 238ファイル (全Edge Function)
**リスク**: セキュリティパッチ・パフォーマンス改善・バグ修正の未適用
**推奨対応**: 一括 sed 置換でバージョン番号を更新後、deno lint で検証

### Flutter (pubspec.yaml) — http パッケージのバージョン未固定

**問題**: `http: any` と記載されており、バージョン制約がない。

```yaml
# 現在 (バージョン制約なし)
http: any

# 推奨 (明示的なバージョン指定)
http: ^1.2.0
```

**リスク**: 将来のメジャーバージョンアップ時に破壊的変更が無警告で適用される可能性。
**推奨対応**: `flutter pub deps` で現在使用バージョンを確認後、制約を追記。
