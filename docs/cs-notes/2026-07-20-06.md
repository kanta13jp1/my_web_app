## 注目 Issue 詳細

### 🔴 本番 500 エラー — Issue #4202

`agent_memories` テーブルに `user_id` インデックスが欠落。本番で `57014 canceling statement due to statement timeout` が発生。

- `/admin` を開いた際に `agent_memories?select=... → 500 / 8.12s` として観測
- 索引は `idx_agent_memories_agent_created(agent_id, created_at DESC)` のみ → `user_id` 経路がシーケンシャルスキャン
- 兄弟テーブル (`agents`, `agent_tasks`) は `user_id` 索引あり・200ms以下で正常
- 推奨対応: Supabase SQL エディタ (トランザクション外) で実行:
  ```sql
  CREATE INDEX CONCURRENTLY IF NOT EXISTS idx_agent_memories_user_created
      ON agent_memories(user_id, created_at DESC);
  ANALYZE agent_memories;
  ```
