**根本原因分析 (notion-sync.yml 精査):**

`notion-sync.yml` は `schedule-hub:notion.sync_wbs` を呼び出し、`success=false` かつ
以下パターン**以外**の場合に `exit 1` → `workflow-failure-handler.yml` が Issue 生成:

- `notion_not_configured` → soft-fail (exit 0) 
- Notion DB property schema mismatch → soft-fail
- `IDLE_TIMEOUT` → soft-fail
- `rate_limited` / `429` → soft-fail
- `object_not_found` (< 10% fail rate) → soft-fail

**推定:** 上記パターンに合致しない新しいエラーが schedule-hub から返っている可能性。
例: Notion API の新しいエラーコード、EF timeout (non-IDLE_TIMEOUT 系)、
`SUPABASE_ANON_KEY` 未設定時の 401 など。

**対応:** 実際の run log 確認が必要 (WEB版から GitHub Actions ログ直接取得不可)。
→ VSCode版 または 手動確認を推奨。
→ 修復困難のため Issue を維持。
