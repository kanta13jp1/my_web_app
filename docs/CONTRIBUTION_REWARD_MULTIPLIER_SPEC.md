# 重点カテゴリ貢献 1.6 倍リワード＆改ざん防止検証仕様書 (#2810)

## 1. 概要

ユーザーがアプリ内へ有用なコンテンツ・ナレッジを提供（投資）した際、運営が動的に指定する「重点強化カテゴリ」に対して **1.6 倍**（既定値、インフレ防止上限 `2.0` 倍）のリワード倍率を適用し、累積スコアに応じて権限・ティアを段階解放する仕組みを定義する。

> 注記: 本機能の着想元である外部税制提案（「ハイパー償却税制」等）の経済的有効性・政策裏付けについては、当環境では一次情報による外部検証を実施していないため **未確認** として扱う。

## 2. 計算ルールとインフレ防止ガード

1. **動的重点カテゴリ**: `ContributionPolicy.focusCategories` により実行時に重点カテゴリを切り替え可能。
2. **倍率上限キャップ**: `clampMultiplier` により倍率を `[1.0, 2.0]` に制限し、誤設定によるエコシステム崩壊を防ぐ。
3. **段階的ティア解放**:
   - `standard`: `0` pt〜
   - `contributor`: `100` pt〜
   - `curator`: `400` pt〜
   - `steward`: `1,000` pt〜
4. **改ざん検知**: Supabase Edge Functions（`_shared/contribution_reward_multiplier.ts`）側で `crypto.subtle` HMAC-SHA256 署名（`signRewardReceipt` / `verifyRewardReceipt`）を生成・検証する。秘密鍵は環境変数等から注入し、コードに直書きしない。
5. **DB マイグレーション**: `0` 件。
