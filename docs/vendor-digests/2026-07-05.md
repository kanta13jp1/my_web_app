## 採用候補 TOP3 (具体アクション)

### 🥇 #1: Anthropic — Messages 配列内 system entry の採用
**優先度**: 高  
**対象**: GHA cron エージェント・Supabase Edge Functions ベースの multi-step エージェント  
**アクション**:
1. `docs/AI_DEV_PRINCIPLES.md` の agent prompt 設計ガイドを更新 (in-messages system entry パターン追記)
2. GHA cron の Claude API 呼び出し箇所を特定し、mid-task instruction update が必要な箇所に適用
3. キャッシュヒット率の before/after を計測

**推定効果**: プロンプトキャッシュ保持のまま動的指示更新 → キャッシュミス削減 → API コスト削減。Opus 4.7 コスト削減施策 (#1756) のさらなる強化。

---

### 🥈 #2: Anthropic — Cache diagnostics (public beta) の導入
**優先度**: 高  
**対象**: GHA cron ジョブ (ai-tool-watch / safety / residuals 等)  
**アクション**:
1. 主要 GHA cron ジョブに `diagnostics.previous_message_id` を追加 (beta opt-in)
2. `cache_miss_reason` をログとして Supabase に保存
3. miss パターンを分析し、プロンプト構造を最適化

**推定効果**: キャッシュミス原因が可視化されることで、88% コスト削減目標 (`docs/PROMPT_CACHING_OPUS47_COST_GUIDE.md`) の達成率をトラッキング・改善できる。

---

### 🥉 #3: Meta — LlamaFirewall / Llama Guard 4 の安全レイヤー導入評価
**優先度**: 中  
**対象**: Flutter Web のユーザー向け AI 生成機能  
**アクション**:
1. Llama Guard 4 の HuggingFace モデルを評価環境でテスト
2. Supabase Edge Function (Deno) 内で input/output フィルタとして動作検証
3. 本番 AI 機能のリリース前チェックリストに "Llama Guard 4 通過" を追加

**推定効果**: ユーザー向け AI 機能のコンテンツ安全性を無償で強化。コンプライアンスリスク低減。`docs/AI_DEV_PRINCIPLES.md` §deny-by-default 原則との整合。
