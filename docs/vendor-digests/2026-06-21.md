## 採用候補 TOP3 (具体アクション)

### 🥇 1位: DeepSeek API 名称移行 (期限: 2026-07-24)

**背景**: `deepseek-chat` / `deepseek-reasoner` が 2026-07-24 15:59 UTC に廃止。現在は V4-Flash へ透過ルーティングされているが、期限後はエラー。

**アクション**:
1. `grep -rE 'deepseek-chat|deepseek-reasoner' .` をリポジトリ全体・.env テンプレート・GHA yml で実行
2. 用途に応じて `deepseek-v4-flash` (軽量/高速) か `deepseek-v4-pro` (高精度) へ切り替え
3. 2026-07-24 前にステージング確認 + 本番反映

**推定効果**: 期限後の API エラーによるサービス断を未然防止。V4-Pro 移行で応答品質向上も期待。

---

### 🥈 2位: GitHub Agentic Workflows 導入

**背景**: GHA 内でコーディングエージェントが推論ベースタスクを自動化。自然言語 Markdown で定義、GITHUB_TOKEN のみで動作 (PAT 不要)。2026-06-11 Public Preview。

**アクション**:
1. `gh extension install github/agentic-workflows-cli` で CLI インストール
2. `.github/agentic-workflows/` に issue-triage.md (issue 自動ラベリング) を作成して試験運用
3. 安定稼働を確認後、wiki-compile / safety-check / blog-publish-cleanup を Agentic Workflow へ移行を検討

**推定効果**: 30+ GHA ワークフローの YAML 保守コスト削減。issue トリアージ自動化で人手レビュー工数削減。

---

### 🥉 3位: Firecrawl MCP Server + Parallel Agents 組み込み

**背景**: v2.8.0 で MCP Server に `firecrawl_agent` ツール追加・Parallel Agents 対応。ai-tool-watch cron での並列 web リサーチが可能に。

**アクション**:
1. `.claude/mcp_servers.json` に Firecrawl MCP Server を追加
2. ai-tool-watch GHA cron を Parallel Agents (Spark Mini) へ移行して速度・コスト改善を測定
3. PII リダクション設定を有効化してデータ安全性を確保

**推定効果**: 毎日 5 cron のうち web リサーチ系を 60% コスト削減。並列実行で処理速度向上。MCP 統合で Claude Code エージェントからダイレクト利用可能。
