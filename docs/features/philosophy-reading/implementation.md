# 哲学書の読書管理 — 実装と操作

利用者は 2026-10-11 に仕様案を承認し、実装と検証を依頼した。
実装 PR: https://github.com/kanta13jp1/my_web_app/pull/5730

## 操作

1. 既存の「読書リスト」入口、または `/reading-list` を開く。
2. 「著者」で名前・別名、活動世紀、国／地域、ジャンルを選び、著者を開く。
3. 「著作」で作品を選ぶ。成立世紀と活動世紀は別の分類。出典リンクで書誌や帰属の注意を確認できる。
4. ログイン後、「読書を始める」で総ページ数・訳者・出版社・出版年・言語・ISBN・巻を登録する。未知の総ページ数は空欄にする。
5. 「記録を追加」で日付・ページ数または区間・理解度・感想・疑問・重要な概念を保存する。感想は本人専用。
6. 「記録を編集」で再考を反映する。編集前の理解度と感想を履歴に保持する。削除は確認後に行う。
7. 読み終えたら「読了にする」を選ぶ。理解度が低い場合も読了できる。「別の版・再読を始める」で別の読書回を残す。
8. 「進捗」で全体・現在の分類対象・世紀別・地域別・ジャンル別の読了数と延べページ数を見る。

「著者を追加」「著作を追加」は本人専用の目録に保存する。共通目録には反映しない。成立時期や帰属が不明なら不明・注記を使う。初期目録は13著者・17著作で、世界の全著作を網羅するものではない。

## 保存と互換性

共通目録は `lib/data/catalogs/philosophy_catalog.dart` の出典付きメタデータ。
`reading_author` は本人の著者、`reading` は本人の著作・読書回・版・記録として既存 `hub_data` に保存する。
版は読書回に属し、他の版や過去の再読のページを混ぜない。
新規スキーマ、RLS変更、依存パッケージ追加はない。

既存の著者名とタイトルは確定した目録に自動統合しない。読了操作と保存は未知メタデータ・URL・タイトル・著者を保持する。
読み取りと変更は認証済みの本人の `metadata.user_id` を条件にし、本文の user_id を信用しない。
全メタデータの compare-and-swap と revision で古い画面からの更新を拒否する。
記録の追加IDを再利用し、共通著作の保存IDを利用者と著作から決定するため、再送や複数画面で共通著作のレコードを重複させない。

保存失敗時はダイアログと入力を保持する。競合時は再読込を案内する。ログアウト・アカウント変更で私的な一覧を消去し、遅れて戻った旧アカウントの応答を表示しない。

総ページ数が既知の場合、区間は1以上・開始≤終了・総ページ数以内。0ページの感想のみの記録も許す。
延べページ数は再読を含み、範囲の進捗は読書回内で重複区間を除く。区間のないページ数から既読範囲を推測しない。
読了著作数は複数の版や再読を重複計上しない。完了後に新しい再読を始めても過去の読了は残る。

保存の上限は100読書回、各回1000記録、各記録100編集履歴、メタデータ1MB。超過を拒否し、既存記録を切り捨てない。

## 検証

`Philosophy Reading Verification` が正確なPR head SHAを checkout する。

- Dart: 分類・紀元前・不明、区間重複、未知ページ数、再読の著作重複、旧記録、ログアウトと遅延応答、失敗時の入力保持、320pxの表示。
- Deno: ページ数・日付・理解度・重複ID、サーバ側編集履歴、未認証拒否。
- 実DB: 隔離したPostgreSQL/PostgRESTに本番のhub_data作成migration/RLSを適用し、他ユーザーのSELECT/UPDATE/DELETEと所有者差替えを拒否。JSONB compare-and-swap、同時保存、再送ID、旧metadata、500件超の一覧を検証。
- Web: 本番 `lib/main.dart` のrelease build。別の試験entry pointでは本番ページ・repository・APIと隔離DBを使用。
- Playwright: 記録→再読込→再読→進捗、ページ区間エラー→通信失敗→再試行→編集履歴→削除、ゲスト閲覧→複合分類→空結果。デスクトップとPixel5で各3ケース。

試験用サーバの認証は合成データで、productionのログイン確認ではない。
試験用SQL・サーバ・Dart entry pointは本番入口から参照しない。ブラウザの画像・フレーム・ログはActions artifactに保存する。
既存PR CIはmerge refも確認する。本番merge/deployは今回の依頼範囲に含まれない。
