
## データ待ち（~7/10 の X 課金サイクルリセット後に点灯）

計測ループ復旧後、perf context に自動で出る：
- `Save-worthiness leaders (by bookmarks)` = どの投稿・どのフォーマットが保存されたか → 保存版まとめの型を強化
- `Best profile-conversion posts (by profile clicks)` = どのフックがプロフィール訪問を生んだか → bio/固定ツイート/フックへ反映
- `Structural lift (video vs image/none)` = 動画リードが伸びるか → 1:1 アスペクト実験の判定

これらが n>=2 に達したサイクルで、上記 OP-1/OP-2 の**どのコピー/型が効くか**をデータで裏取りできる。それまでは OP-1（bio+固定）を今すぐ実行するのが最善。
