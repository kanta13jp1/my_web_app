### AI と一緒に、人生を「会社のように経営する」セルフマネジメント Web サービス「自分株式会社」を一般公開

**〜 健康・学び・お金・AI メンターを 1 つに。比べる相手は他人ではなく「昨日の自分」〜**

**`【発行体: CEO確認】`** は、AI と共に自分の人生を会社のように経営するセルフマネジメント Web サービス **「自分株式会社」** を **`【配信日】`** に一般公開しました。URL: <https://my-web-app-b67f4.web.app/>。利用は無料です。

#### ■ 背景 — 「自己管理アプリは多いのに、続かない」

健康・家計・学習・タスクは、それぞれ別のアプリに分かれがちです。数字は増えても「自分が前に進んでいる実感」が得にくく、他人との比較や順位は、かえって続ける気持ちを削ぐことがあります。「自分株式会社」は、**ユーザー自身を"社長"**に見立て、人生を 6 つの部署 (本社 / 人事 / R&D / 財務 / 横断 / マーケ) として運営する発想で、バラバラの記録を**一つの経営ダッシュボード**にまとめます。

#### ■ 特長

1. **昨日の自分と比べるダッシュボード** — 健康・お金・学びの主要指標を 1 画面で俯瞰し、**前日比**で自分の前進を確認できます。他人比較や順位を煽りません。
2. **健康・睡眠・ジャーナル (人事)** — 日々のコンディションを記録し、ダッシュボードに反映。土台となる「自分のメンテナンス」を最優先に置いています。
3. **AI大学 — 複数社の AI を 1 か所で** — 複数の AI を比較しながら学べる学習機能と、タグ付きノート。特定 1 社に依存しない学びが、本サービスの差別化点です。
4. **家計簿・収支ダッシュボード (財務)** — お金を「時間資本」として捉え、収支を記録・俯瞰します。
5. **横断 AI メンター** — 各部署のデータをもとに**提案**を返します。命令ではなく穏やかな提案で、**実行するかは常にユーザーが決めます**。

#### ■ 「自分株式会社」が大切にすること

比較対象は他人ではなく**昨日の自分**。射幸性や中毒的な仕掛けに頼らず、ユーザーの自己効力感とウェルビーイングを損なわない設計方針を掲げています (詳細はブランドガイドラインに準拠)。

#### ■ 今後の展望

まずは **`【配信日】` 以降、最初の 1,000 名**に「昨日の自分より良くなる」体験を届けることを目標とします。モバイル対応・連携機能の拡充は順次予定 (時期未定 / 確定は今後の案内にて)。

## 2. 配信戦略 — 「メディア配信先 50 社」

「50 社」は**個別契約のメディア 50 社リストを本書で確定する意味ではない**。PR Times は配信すると提携メディア網へ自動転載されるため、**(a) PR Times を主配信ワイヤとして使い、(b) 重点的に届けたいメディアのカテゴリ taxonomy を定義し、(c) 個別 50 件の最終リスト・連絡先・実配信は CEO + PR Times アカウントで確定する**、という設計にする。

**重点カテゴリ (taxonomy / 各カテゴリで具体先は CEO 確定)**:

| # | カテゴリ | 狙い | 代表例 (タイプ示唆 / 最終選定は CEO) |
|---|---------|------|----------------|
| 1 | IT・ガジェット系 Web メディア | 新サービス露出 | 一般的なテック系ニュースサイト |
| 2 | 生産性・ライフハック・手帳/PKM 系 | コア層 (自己管理) | 生産性・ノート術系メディア/ニュースレター |
| 3 | パーソナルファイナンス系 | 家計簿訴求 | 家計・節約・投資情報メディア |
| 4 | AI・スタートアップ系 | AI大学・多社 AI 差別化 | AI ニュース・スタートアップ系メディア |
| 5 | ウェルビーイング・健康系 | 人事 (健康) 訴求 | 睡眠・メンタルヘルス系メディア |
| 6 | 個人/インディー開発・build-in-public | 共感・初期ファン | 個人開発コミュニティ・X 経由 |

- **主配信**: PR Times (1 配信) → 提携メディア網へ自動転載。
- **補完**: [`X_ACCOUNT_OPERATIONS_DESIGN.md`](X_ACCOUNT_OPERATIONS_DESIGN.md) の build-in-public 運用で同日にオーガニック発信 (誇張しない / §2 ボイス準拠)。
- **タイミング**: 実 GA 日に合わせる。フライング配信しない。
- **禁止**: スパム的一斉送信 / カテゴリ無関係メディアへの無差別送付 / 誇張見出し。
