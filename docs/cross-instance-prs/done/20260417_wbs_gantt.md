## 進捗更新方法

タスク完了・進捗更新時:
```sql
UPDATE wbs_tasks SET progress = 100, status = 'completed'
WHERE title = 'タスク名';
```

または `wbs_tasks` テーブルを直接 upsert (service_role key 使用)。
