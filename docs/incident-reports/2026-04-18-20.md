# インシデントレポート 2026-04-18 20:00

## 概要
Deploy to Production CI が連続失敗中 (Issue #462〜#480 計20件以上)

## 根本原因分析

### 仮説1: dart format 強制チェック
- ci.yml 行131-132: `dart format --set-exit-if-changed .` が `continue-on-error: false` で設定
- 自動コミット (cs-check / Claude Schedule) が `dart format .` を実行せずにコミット
- Format差分 → CI ハードフェイル → Deploy 失敗

### 仮説2: prefer_const エラーの残存
- VSCode版#104 (commit 5a0f312) で prefer_const_* 4ルールをwarningに降格
- しかし最新の CI run 24612912064 (commit 5a0f312) も失敗中
- 別のエラーが残存している可能性

## 影響
- 本番デプロイが停止中 (Firebase continue-on-error: true のため部分的に動作の可能性)
- GitHub Issues が workflow-failure で大量蓄積 → ノイズ増大

## 推奨対応
1. **即時**: VSCode版またはWindows版で `dart format .` を実行してプッシュ
2. **根本修正**: cs-check の自動コミット前に `dart format .` を追加
3. **Issueの整理**: 重複 workflow-failure Issuesをまとめてクローズ

- 最新コミット: dcf24aa (ci: Rule 17 WF health check 2026-04-19)
- Deploy to Production は毎回のプッシュで失敗している
- WEB版からは flutter/dart コマンド実行不可のため、VSCode版での対応が必要
