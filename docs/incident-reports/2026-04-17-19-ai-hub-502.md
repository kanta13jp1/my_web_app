# ai-hub EF 502 Bad Gateway (2026-04-17 19:15 JST)

## 症状

ユーザーブラウザ (Flutter Web) で以下のエラーが2回連続発生:

```
POST https://smmkxxavexumewbfaqpy.supabase.co/functions/v1/ai-hub 502 (Bad Gateway)
Fetch failed loading: POST "https://smmkxxavexumewbfaqpy.supabase.co/functions/v1/ai-hub".
```

## タイムライン

| 時刻 (JST) | イベント |
| :--- | :--- |
| 19:14 | deploy-prod.yml run 24559958891 開始 (in_progress) |
| 19:15 | ブラウザで ai-hub 502 x 2 発生 |
| 19:17 | Windowsアプリ版#74 が curl で ai-hub を検査 |
| 19:17 | curl 結果: `search.query` action → HTTP 200 (0.55秒) ・ 他action 400/401 → **EF正常稼働中** |

## 根本原因

**Supabase Edge Function の cold-restart/redeploy 中の transient 502**

- `deploy-prod.yml` が 15分内に 4回実行 (Windows#74 の4 commit push に由来)
  - 24559958891 (in progress) ← 502 発生時
  - 24559399087 (success 19:00)
  - 24558121494 (success 18:29)
  - 24556583806 (success 17:52)
- 各 deploy で ai-hub EF が再起動 → 再起動中の数秒間に 502 応答
- ai-hub EF 本体のロジック・構文エラーなし (全 action テスト通過)

## 対処

**即時対応**: ブラウザをリロード → 502 解消見込み (deploy 完了後)

**再発防止**:
1. **deploy-prod の4重起動を抑止** (本質対応)
   - Windows#74 の rapid-fire push (5 commits in 15min) が主因
   - `deploy-prod.yml` の concurrency group 設定確認 (すでに `cancel-in-progress: false` か確認)
2. **UIで 502 retry を実装** (対症対応)
   - `lib/services/` の ai-hub client に exponential-backoff 追加 (現在ある? 要確認)
