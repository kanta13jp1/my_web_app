# 匿名化した比較流入・登録ファネル計測仕様 (#4727)

## 1. 最小匿名イベント定義

比較ページ（`/vs-*`）から CTA 遷移・登録完了までのファネルを計測するため、以下の 3 段階を定義する。

1. `comparison_arrival`: 比較ページ到達
2. `comparison_cta`: 比較ページ CTA 押下
3. `registration_completed`: 登録完了

### ペイロード制約（PII・入力内容ゼロ）

- 許可フィールドは `competitor_key`（小文字英数字・`_`・`-` の最大 32 文字スラッグ）、`stage`、`date_key`（UTC `YYYY-MM-DD`）のみ。
- ユーザー ID・メールアドレス・メモ本文・プロンプト入力内容は一切含めない。
- `optedOut == true` の場合は送信を完全抑止し、送信失敗時も例外を握りつぶして画面操作を阻害しない。

## 2. 保持ポリシーと集計クエリ方針

- **保持方針**: 日別・競合スラッグ別の集計カウンタのみを保持し、個人に紐づく時系列ログは保持しない。
- **集計指標**: `arrivals`、`ctaClicks`、`registrations`、`ctaRate = ctaClicks / arrivals`、`registrationRate = registrations / arrivals`。
