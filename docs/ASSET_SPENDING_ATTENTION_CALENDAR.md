# 浪費危険日のカレンダー表示

金曜日・土曜日・日曜日・内閣府の公式祝日/休日と、その前日を注意の背景と「注意」の文字で表示します。表示期間の件数は日付を重複排除します。選択日の理由は個別に表示します。この分類は本人の希望する注意喚起で、実際の浪費・外食・飲酒を記録したり、原因を判定したりしません。個別の勤務日・休暇は推測しません。

祝日出典: 内閣府 https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html
CSV: https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv
取得日: 2026-10-15。2026年・2027年の35行を使用し、振替休日・国民の休日を含みます。未対応年の祝日を生成せず、曜日だけを判定します。更新時は公式CSVの公開年・日付・名称を再照合し、サービスの対応年と取得日も更新してください。

実際の外食・飲酒等の印は別の出典付き機能として扱います。記録がない日・金額不明・ATM取引不成立は支出を追加する根拠にしません。
