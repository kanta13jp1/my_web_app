# Release Notes Data

`web/release-notes.json` is generated by `scripts/generate_release_notes.py`.

Fixed inputs:

- App version/build: CLI values, falling back to `pubspec.yaml`.
- Release links: GitHub Releases for `kanta13jp1/my_web_app`.
- Change links: merged GitHub pull requests.
- Deploy metadata: commit SHA and deploy URL when supplied by `deploy-prod.yml`.
- AI tooling extension point: `docs/ai-tool-watch/latest-report.json`.

Deduplication rules:

- Pull requests are de-duplicated by PR number, then URL.
- Release links are matched to the current `v{version}` tag.
- Generated JSON is sorted and deterministic so CI can detect manual drift.
