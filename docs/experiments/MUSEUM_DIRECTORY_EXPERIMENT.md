# 美術館ディレクトリ実験契約 v1

対象Issue: #5096（20260830T170216+0900、4番目の指摘）。
作成日: 2026-09-12。状態: **提案・未開始・未計測**。
この文書は実験設計であり、需要、継続、売上の実績ではない。

## 顧客と検証する課題

対象顧客の仮説を「月1回以上、週末に美術館へ行く予定を自分で立てる国内の成人」に限定する。
地域と館名を横断検索し、候補の公式情報を確認する手間を減らすことを検証する。
対象への該当は任意の参加確認で判断し、閲覧履歴や所在地から推定しない。
母集団への一般化や、全国の美術館利用者全体への需要証明は行わない。

## 一つのcohortと期間

実験ID: `museum_weekend_planning_v1`。開始日時T0は計測実装と参加説明のレビュー完了後に記録する。
T0から14日間に初めて参加した、同意済みの対象顧客を一つの募集cohortとする。
各参加者の最初の有効なdirectory到達をtとし、D7は[t+7日, t+8日)の再到達で判定する。
日時の保存・集計はUTC、表示にはJSTを併記する。最終観測はT0+22日以降とする。
テスト・運営者・botを除外する規則は募集前に固定し、結果を見て変更しない。
同意撤回者の削除と母数の変更を集計注記へ記録する。

## 計測契約（未実装）

| 事象 | 成立条件 | 重複排除と母数 |
| --- | --- | --- |
| directory到達 | カタログ読込成功後に一覧を表示 | 参加者ごとにcohort内1回。これをNとする |
| 検索 | 空でない検索または地域変更後の結果を表示 | 到達後24時間内に1回以上の参加者数 / N |
| 詳細 | 館の詳細sheetを表示 | 到達後24時間内に1回以上の参加者数 / N |
| 公式サイト遷移 | 館の公式URLのlauncherが成功 | 到達後24時間内に1回以上の参加者数 / N |
| D7再訪 | 成熟した参加者のD7窓内にdirectoryへ再到達 | 再訪人数 / D7窓終了済み人数 |
| 収益仮説への関心 | 任意の有限選択アンケートで既存Proの利用検討を回答 | 回答数、肯定数、回答者母数を併記 |

公式サイト遷移は外部アプリへの引き渡し成功であり、到着・入館・購入を証明しない。
一覧カードから直接公式URLを開けるため、詳細を必須の中間段階にはしない。
各事象の到達者比率と「検索→詳細→公式遷移」の順序付き人数を別々に集計する。
同一ページの再描画、同じ検索の連打、失敗したlauncherで人数を増やさない。
現行の挿入候補は `lib/pages/art_museum_directory_page.dart` の
一覧読込成功、`_buildFilters`、`_showMuseumDetails`、`_openUrl`。
出典リンクも `_openUrl` を使うため、館の公式URLと出典URLを必ず区別する。

## 収益仮説

「検索のための再訪が既存Proへの関心につながる」を探索仮説とし、料金変更や新有料機能は導入しない。
アンケートは「検討したい／不要／判断できない」の3択とし、購入意思・売上・paid転換とは呼ばない。
paid転換は #5085 の同意と決済集計の結合契約が完成するまで `unavailable` とする。
結合可能になってもcohortの観察結果であり、この機能による因果効果や増分MRRと断定しない。

## 個人追跡と公開範囲

D7には同一参加者を期間内で区別する仕組みが必要であり、匿名イベントの総数だけでは算出できない。
実装時は既存の同意・削除基盤を確認し、実験内だけの期限付き仮名キーをサーバー側に限定する。
仮名キーを完全匿名と表示しない。メール、検索語、館名、外部URL、位置情報、IP、決済IDを実験集計へ保存しない。
保持期限は最終観測後7日、最長T0+29日とする提案。実装前に削除処理と説明をレビューする。
公開結果はcohort単位のみ。各セル10人未満は `suppressed` とし、差し引きで少人数を復元できる表を出さない。
同意前・撤回後・保存失敗時に記録しないことを検証する。既存privacy文言をこの文書だけで変更しない。

## 欠測と判定

`measured` は観測済み、`zero` は正常計測が確認された上での0件、`immature` はD7窓未終了、
`unavailable` は未実装・欠測、`suppressed` は公開抑制を表す。欠測・未成熟を0%に変換しない。
開始前にイベント受信・重複排除・同意撤回・成熟窓の動作をクラウドで検証する。
募集上限は100人、最低判断母数はD7成熟50人。これは運用上の探索基準であり検出力計算ではない。
提案する継続基準は公式遷移者/Nが30%以上かつD7再訪が20%以上。
基準未達なら導線または課題仮説を見直し、母数不足・欠測なら判断保留。基準達成だけで収益化しない。
同意違反、識別情報漏出、削除不能を検出した場合は収集を停止し、既存インシデント手順へ渡す。
結果を見て閾値を変更する場合は別version・別cohortにし、旧結果を保存する。
