## 本文（全プラットフォーム共通）

「自分株式会社」という個人開発アプリを Flutter Web + Supabase で育てています。コンセプトは「自分自身を株式会社のように経営する」——ノート・タスク・投資・家計・競馬予想まで、人生のあらゆる情報を一元管理するオールインワンツールです。

今週（2026-07-15〜07-21）は大きく3つの機能を実装しました。

1. **資産異常検知システム**（anomaly detection）
2. **投資ポートフォリオ履歴チャート**
3. **LP パブリックトライアル変換パス + magic link 引継ぎ**

---

### 資産異常検知システム — 全体設計

```
anomaly_detections テーブル（PostgreSQL）
  ↓
asset.anomaly.detect Edge Function（Deno）
  ↓
daily-anomaly-scan cron（GitHub Actions / 毎日 09:00 JST）
  ↓
Flutter UI（残高不足・異常の導線表示）
```

**DB テーブル**

```sql
CREATE TABLE anomaly_detections (
  id           UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id      UUID NOT NULL REFERENCES auth.users(id),
  category     TEXT NOT NULL,
  target_month DATE NOT NULL,
  amount       NUMERIC(15,2) NOT NULL,
  avg_3month   NUMERIC(15,2) NOT NULL,
  deviation    NUMERIC(6,4) NOT NULL,
  severity     TEXT NOT NULL,
  ai_explanation TEXT,
  created_at   TIMESTAMPTZ DEFAULT now(),
  UNIQUE(user_id, category, target_month)
);
```

`UNIQUE(user_id, category, target_month)` の複合制約で cron 二重実行を無害化（冪等 upsert）。

**異常検知ロジック**

```typescript
const THRESHOLD = 0.20;  // ±20%
const deviation = (amount - avg) / avg;
if (Math.abs(deviation) < THRESHOLD) continue;

severity = deviation >= 0.5 ? 'high' : deviation >= 0.35 ? 'medium' : 'low';
```

`ANOMALY_AI_EXPLANATION_ENABLED=true` のときだけ Claude を呼んで AI説明を生成。デフォルト OFF でコストゼロ。

**日次 cron**

```yaml
schedule:
  - cron: '0 0 * * *'  # JST 09:00 = UTC 00:00
```

`scan_all: true` で全ユーザーバッチ対応。

`fl_chart` で時系列グラフを実装。過去12ヶ月のタイムレンジ選択 + タップで残高内訳ツールチップ。

### LP トライアルの magic link 引継ぎ修正

LP から「まず試す」で始めたトライアルデータを、magic link サインアップ完了後の新規ユーザーへ移行。`auth.onAuthStateChange` で `SIGNED_IN` イベントをキャッチして localStorage から Supabase DB へ移行する処理を追加。

---

### 詰まったポイント

**upsert の onConflict**

```typescript
// OK
.upsert(rows, { onConflict: 'user_id,category,target_month' })
// NG（スペースがあるとエラー）
.upsert(rows, { onConflict: 'user_id, category, target_month' })
```

**migration のリプレイ安全性**

時間依存の `UPDATE` は migration に書かない。将来データある状態でリプレイすると上書きリスクがある。

**GitHub Actions の UTC**

JST 09:00 = UTC 00:00 → `cron: '0 0 * * *'`
