## 共通本文（各プラットフォーム向けに微調整して使用）

X（旧Twitter）に動画を投稿したことがある方なら、あの「自動ミュート再生」の壁を知っているはずだ。タイムラインに流れてくる動画は無音でスタートする。

自分株式会社では、Flutter Web + Supabase を使って動画を自動投稿するシステムを運用しているが、この1週間でその動画投稿パイプラインを大きく強化した。

### ① キャプション焼き込み Cloud Run サービス (#3813)

Deno の Edge Function ではffmpegをin-processで実行できない。そこで、超軽量なNode.jsマイクロサービスをCloud Runにデプロイした。

- **インターフェース**: `POST /burn { videoUrl, srt, forceStyle, resolution, style } → { url }`
- **技術**: ffmpeg `subtitles` + `force_style` フィルタでSRTをMP4に焼き込み
- **日本語対応**: `fonts-noto-cjk` をDockerイメージに含める
- **安全設計**: エラー時は元のmp4をそのまま投稿（投稿をブロックしない）

```bash
# Cloud Run へのデプロイ（1コマンド）
gcloud run deploy caption-transcoder \
  --source . \
  --region asia-northeast1 \
  --allow-unauthenticated
```

### ② 動画最初3秒のフック最適化 (#3819)

muted autoplayの最初3秒でトピックフックを話すよう改善：

```dart
// 従来
'おはようございます。今日の話題は<topic>です。'

// 改善後（ローテーション式）
'<topic>、30秒で要点だけ。'
'<topic>について、今すぐ知るべきこと。'
```

同時に動画プロンプトに「強い最初のビート（即座のスピーチ＋プッシュイン）」を指示。

### ③ Growth Hub LLM文脈強化 (#3821)

`buildXPerformanceContextFromLogs` 関数を拡張し、以下をLLMプロンプトに渡すようにした：

- バリアントランキング（上位5件、サンプルサイズ保証付き）
- メディアあり vs なし の平均スコア差
- リンク配置による平均スコア差
- 最適スレッド長バケット
- 「真似すべきフックの構造」（具体的な言葉ではなく構造を学習）

サンプル数ガード（`rows >= 2` / `>= 3`）で統計的に薄いデータがLLMを誤誘導しないよう設計。
