# クロスポスト統合版 2026-06-02

AIフリートで個人SaaSを開発する — Claude Code × Codex 2インスタンス体制と競合21社自動監視の仕組み

## 本文 (共通ベース)

Flutter Web + Supabase で「自分株式会社」という個人向け資産・時間管理 SaaS を開発しています。本番 URL は https://my-web-app-b67f4.web.app/ です。

「AI をフル活用してインディー開発者が大企業と戦えるか」という実験として、今週の主な変化を build in public として共有します。

### 2インスタンス AI フリートへの最適化

以前は Claude Code 10 + Codex 2 という大規模フリートで運用していましたが、**Claude Code #1 + Codex #1 の 2インスタンス体制** に整理しました。

役割分担:
- Claude Code #1 → 問題定義・アーキテクチャ・コードレビュー・Hook 設計
- Codex #1 → 実装・SQL/マイグレーション・Edge Functions・GitHub Actions・UI QA

### AI ツール自動監視

主要 AI 開発ツールの公式ページを毎日クロールし、変化を検知して GitHub にコミットする `ai_tool_watch.py` を運用中。

今週の主な検知:
- **Claude Code 2.1.160** (2026-06-02) — Hook 機能強化
- **Codex Sites 機能** (2026-06-02) — アプリ内ウェブサイトビルド・デプロイ preview
- **Cursor v3.6** (2026-05-29) — Shell/MCP/Fetch への Auto-review
- **Devin 2.2** (2026-05-29) — コンピューターユース E2E テスト強化

### 競合21社監視 + xAI Grok Build の追加

今週 xAI Grok Build を 21 社目の競合として追加 (脅威度: High)。
毎朝 GHA cron が各競合の HTTP ステータスと変化を記録し、AI 分析レポートを自動生成します。

### Claude Code Hooks 自動化

`SessionStart` hook でルール・役割・哲学原則を毎セッション自動注入。
30+ ワークフロー・5 daily cron は Claude 非依存設計で quota 超過時も継続動作。

今週のアップデートまとめ:
- ✅ xAI Grok Build を競合リスト (21社目) に追加
- ✅ Claude Code 2.1.160 / Codex Sites / Cursor 3.6 の変化を自動検知
- ✅ AI フリートを 2 インスタンス体制に最適化
- ✅ 競合監視のフォールバック設計を堅牢化
