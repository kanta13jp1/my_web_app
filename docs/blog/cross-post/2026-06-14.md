### 実装詳細

#### マルチ月キャッシュフロー予測 (#3403 / #3419)

複数月にわたるキャッシュフロー残高予測を追加しました。ホライゾン（3ヶ月/6ヶ月/1年）を切り替えられる UI と、最低残高を示す「安全ライン」を fl_chart で描画。v2 では安全ラインを下回ったカテゴリへのレビューリンクも追加。

```dart
enum ForecastHorizon { threeMonths, sixMonths, oneYear }

final cashflows = await supabase
  .from('monthly_cashflow')
  .select('month, amount, category')
  .gte('month', DateTime.now())
  .lte('month', horizon.endDate);
```

#### Tombstone パターンによる削除伝播 (#3400 / #3402 / #3411)

クロスデバイス同期で最も難しかったのが削除の伝播。union マージだけでは削除が他端末へ伝わらないため、Tombstone テーブルを導入。

```sql
CREATE TABLE asset_pref_tombstones (
  user_id UUID,
  item_key TEXT,
  deleted_at TIMESTAMPTZ DEFAULT NOW(),
  PRIMARY KEY (user_id, item_key)
);
```

GC は削除時刻順で実行し audit 要件を満たします（#3411 で挿入位置順から修正）。

#### X シェア + AI 自動対応パイプライン (#3390)

X でシェアされたフィードバックを Claude API で自動返信するパイプラインを構築。Supabase Edge Functions（Deno）が Webhook を受け取り、Claude に返信文を生成させ、`feedback_queue` テーブルへ DLQ 保存。PII 保護のため送信者メールは `user_id` に置換（#3413）。

#### 禁酒で借金完済チャレンジ (#3388)

飲み機会コストを累積し借金完済日を逆算するユニークな機能。

```dart
final savedAmount = opportunities
  .where((e) => e.skipped)
  .fold(0.0, (sum, e) => sum + e.estimatedCost);

final debtFreeDate = _calcDebtFreeDate(
  currentDebt: debtBalance,
  monthlyPayment: basePayment + (savedAmount / monthsElapsed),
);
```
