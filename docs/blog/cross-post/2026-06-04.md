## 本文 (共通ベース)

Flutter Web + Supabase で「自分株式会社」という個人向け資産・時間管理 SaaS を開発しています。本番 URL は https://my-web-app-b67f4.web.app/ です。

今週は Karpathy 4サイクル（Ingest → Compile → Query → Lint）の定常稼働と、AI大学コンテンツの完全自動更新が大きな節目を迎えました。build in public として共有します。

### Karpathy 4サイクルの定常稼働

Andrej Karpathy が提唱する「第二の脳」構築サイクルをプロダクト開発に応用しています。

- Ingest: `scripts/memory_ingest.py` → ✅ 定常稼働
- Compile: `scripts/wiki_compile.py` → ✅ 毎日自動実行
- Query: `notebooklm` CLI → ✅ ゼロトークンリサーチ
- Lint: `scripts/knowledge_vault_lint.py` → ✅ 定常稼働

今週は wiki compile が正常実行され、`docs/concepts/` と `docs/INDEX.md` が自動生成されました。開発中に蓄積した知識が自動的に整理・インデックス化される仕組みが完全に定着しています。

### AI大学コンテンツ自動更新

「自分株式会社」の主要機能である AI大学 では、最新の AI ツール・サービス情報を GitHub Actions で毎日自動更新しています。今週だけで 10回以上の自動コミットが実行され、コンテンツが常に最新状態に保たれています。

実装のキー：コンテンツのハッシュ値を比較して更新判定を行い、不要なコミットを防止しつつ本当に変化のあったコンテンツのみを更新します。

### CI/CDコスト監査の自動化

GitHub Actions の実行コストを定期的に可視化し、無駄なワークフロー実行を検知する仕組みを構築しました。個人開発者がエンタープライズ級の自動化を維持するには、このコスト管理が欠かせません。

### インフラヘルスチェック × 日次レポート

本番環境の稼働状況を毎時チェックする仕組みも定着しています。毎時のインフラヘルスチェック、毎日の日次レポート・CS チェック・コスト監査がすべて GitHub Actions で自動実行されます。

### まとめ

今週の「自分株式会社」は自動化インフラの成熟が顕著でした。機能を作ることと同じくらい、「維持するコストをゼロに近づける仕組み」への投資が、個人開発者が大企業と戦うための本質です。
