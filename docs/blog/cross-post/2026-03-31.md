## 本文（共通・プレーンテキスト版）

「自分株式会社」は Notion・Evernote・MoneyForward・Slack など21社を超えることを目標に、Flutter Web + Supabase で個人が運営しているAI統合ライフマネジメントアプリです。

本日（2026-03-31）、Supabase Edge Function の総数が **155本** に到達しました。朝から夜までの1日の開発で、AI自動化・電子署名・SNS連携・受信箱・ビデオ会議 など5領域のバックエンドを一気に実装。さらにフロントエンドでは **通知センターUI** を Flutter Web で新たに構築し、`dart:html` 廃止対応も同時に完了させました。

### Edge Function 155本の内訳（主要カテゴリ）

| カテゴリ | 代表 Function |
|---------|--------------|
| AI・自動化 | `ai-secretary`, `daily-judgment`, `ai-assistant` |
| ファイル管理 | `file-storage`, `ocr-scanner`, `voice-memo` |
| コミュニケーション | `chat`, `realtime-presence`, `notification-center` |
| ビジネス | `compensation`, `financial-report`, `api-key-manager` |
| ライフスタイル | `fitness-tracker`, `recipe-manager`, `travel-planner` |
| 電子署名 | `e-signature` |
| ビデオ会議 | `video-conference` |
| SNS統合 | `post-x-update`, `sns-scheduler` |

### Edge Function 量産のポイント

Deno の共通 CORS テンプレートを使い回し、`service_role` キーで RLS をバイパスしながらバックエンド処理を実装。CI/CD に `deno lint` を組み込み、積み上げ式でも品質を担保しています。

### 通知センターUI — dart:html 廃止対応

Flutter 3.x 以降 `dart:html` は非推奨。`package:web` への移行手順：

```dart
// Before (deprecated)
import 'dart:html' as html;
html.window.localStorage['key'] = value;

// After
import 'package:web/web.dart' as web;
web.window.localStorage.setItem('key', value);
```

`pubspec.yaml` に `web: ^1.0.0` を追加するだけで移行完了です。

### 詰まったポイント

**migration 重複バージョン問題**：複数セッション並行作業でファイル番号が衝突。`ls supabase/migrations/ | sort | uniq -d` で即座に特定しリネーム対応。

**CS チェック Schedule の schema 修正**：`schedule_executions` テーブルに `task_name TEXT` カラムを追加して解消。
