## 共通本文

### はじめに

個人開発プロジェクト「自分株式会社」を Flutter Web + Supabase で構築しています。家計管理・資産管理・AI アシスタントを統合したパーソナル SaaS です。

今週の主な実装は **「給料サイクル別支出チャート」** (PR #1368) です。給料日を基準にした期間で支出を集計し、カテゴリ別に円グラフ表示します。

### 実装のポイント

**純粋 Dart サービス層**: `SalarySpendingBreakdownService` を `const` 純粋クラスとして実装。Flutter Widget にも Supabase クライアントにも依存しないため、103行のユニットテストで主要パスをカバーできました。

**期間計算の境界値処理**: 給料日28日以上は28に丸めて2月末問題を事前回避。

**CI 自動修復**: `dart format` と `deno fmt` のフォーマットエラーを GHA で自動コミット修復。PR ブロック時間がゼロに。

### まとめ

- `const` 純粋クラス設計でテスタビリティが大幅向上
- 月末境界値は事前制約で防御
- CI 自動修復は indie dev の必需品
