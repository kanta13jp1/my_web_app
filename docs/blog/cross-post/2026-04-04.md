Today marks a milestone for "Jibun Inc." — a Flutter Web + Supabase app that integrates 21 competing SaaS tools into one.

I finally connected all 15 Edge Functions to their corresponding Flutter UI screens. Here's what I learned:

**1. Keep Edge Functions single-responsibility**
Each function does one thing (e.g., `get-home-dashboard`, `get-support-tickets`). This makes mapping to Flutter widgets straightforward.

**2. Always check `mounted` after async calls**
```dart
if (!mounted) return;
ScaffoldMessenger.of(context).showSnackBar(...);
```

**3. UTC → Local time matters**
Supabase returns `timestamptz` in UTC. Use `.toLocal()` for JST display.
