## 統合本文 (全プラットフォーム共通)

「AIが仮説を立て、AIがコードを書き、AIが結果を測定する」——この一文が、直近1週間の自分株式会社の開発ログを一言で表しています。

Flutter Web + Supabase で構築したSaaS「自分株式会社」(https://my-web-app-b67f4.web.app/) では、ランディングページ(LP)のグロース施策をほぼ全自動化しました。

### 今週のハイライト

**10仮説の同時A/Bテスト**: Supabase Edge Functionで各仮説のコンバージョン率を自動集計。毎日Claudeが結果を判断し、次の施策を立案します。

**ワンタップトライアル**: メールアドレス入力不要でアプリ体験。OAuthリダイレクト後のセッション保持・ソーシャルプルーフ先行ロード・LP→アプリ間の文脈保持をセットで実装しました。

**OMOCHA WORKS (自律オペレーションコンソール)**: Claude Code / Codex / Geminiの稼働状況をリアルタイム表示するダッシュボード。

**証券評価額の月次履歴**: 「資本=時間」哲学を数値化。保有資産の推移を時系列グラフで追跡。

### 技術的な学び

AIが生成するコードには`require_trailing_commas`などのlint違反が混入しがちです。`dart fix + dart format + deno fmt`を自動実行するCI修復ワークフローで、AIが書いたコードをAIが自動修正する仕組みを整えました。

### まとめ

AI駆動開発の核心は「測定の自動化」にあります。仮説も実装もAIが担える時代に、人間が担うべき仕事は「測定ループの設計」です。

引き続き AI Fleet × Flutter Web × Supabase で、ソロ開発者が大企業と競えるSaaS開発を追求します。
