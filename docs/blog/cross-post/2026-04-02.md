### 実装方法

#### 1. MediaRecorder mimeType 自動検出

iOS Safari は `audio/webm;codecs=opus` 非対応です。優先順位をつけて自動選択します。

```dart
String _getSupportedMimeType() {
  const types = [
    'audio/webm;codecs=opus',
    'audio/webm',
    'audio/mp4',
    'audio/ogg;codecs=opus',
    '',
  ];
  for (final type in types) {
    if (type.isEmpty) return type;
    if (MediaRecorderJS.isTypeSupported(type).toDart) return type;
  }
  return '';
}
```

**ポイント**: `dart:js_interop` では `isTypeSupported` の戻り値が `JSBoolean` なので `.toDart` が必須です。

#### 2. WAV エンコーダ (16bit PCM)

録音 Blob を `decodeAudioData` でデコードし、WAV ヘッダーを付与します。

```typescript
// supabase/functions/guitar-studio/index.ts (Deno)
function encodeWAV(samples: Float32Array, sampleRate: number): ArrayBuffer {
  const buffer = new ArrayBuffer(44 + samples.length * 2);
  const view = new DataView(buffer);

  // RIFF ヘッダー
  writeString(view, 0, 'RIFF');
  view.setUint32(4, 36 + samples.length * 2, true);
  writeString(view, 8, 'WAVE');
  writeString(view, 12, 'fmt ');
  view.setUint32(16, 16, true);
  view.setUint16(20, 1, true);         // PCM フォーマット
  view.setUint16(22, 1, true);         // モノラル
  view.setUint32(24, sampleRate, true);
  view.setUint32(28, sampleRate * 2, true);
  view.setUint16(32, 2, true);
  view.setUint16(34, 16, true);        // 16bit
  writeString(view, 36, 'data');
  view.setUint32(40, samples.length * 2, true);

  // Float32 → Int16 変換
  let offset = 44;
  for (const s of samples) {
    const clamped = Math.max(-1, Math.min(1, s));
    view.setInt16(offset, clamped < 0 ? clamped * 0x8000 : clamped * 0x7FFF, true);
    offset += 2;
  }
  return buffer;
}
```

iOS Safari・Android Chrome・Windows Edge すべてで再生確認済みです。

#### 3. AI ギターコーチ

練習データを Supabase に蓄積し、Claude API で分析します。

```typescript
case 'ai_analyze': {
  const { data: stats } = await supabase
    .from('guitar_practice_stats')
    .select('*')
    .eq('user_id', userId)
    .order('practice_date', { ascending: false })
    .limit(7);

  const analysis = await callClaude(`
    直近7日間の練習データ: ${JSON.stringify(stats)}
    1. 練習パターン分析 (良い点・改善点)
    2. 今日の練習メニュー (3項目)
    3. 来週の目標
    を日本語で提案してください。
  `);
  return new Response(JSON.stringify({ analysis }), { status: 200 });
}
```

### 詰まったポイント

**① `req.json()` 空ボディクラッシュ**

GET リクエストで `await req.json()` を呼ぶとクラッシュします。192 本の Edge Function 全てで一括修正しました。

```typescript
let body: Record<string, unknown> = {};
try {
  if (req.method !== 'GET') body = await req.json();
} catch { /* 空ボディは許容 */ }
```

**② `JSAny?` 型エラー**

```dart
// NG
external JSAny someJsFunc();
// OK
external JSAny? someJsFunc();
```

**③ Migration 重複 version**

本番 DB に適用済みのマイグレーションを再 apply しようとした際に重複エラー。
`supabase migration repair --status applied <version>` で解消しました。
