### 実装1: TableCalendar 月次カレンダービュー

```dart
final Map<String, List<Map<String, dynamic>>> _eventsByDate = {};
```

`TableCalendar` に日付文字列キーのMapを渡すことで O(1) イベント取得を実現。ページ変更時のみフェッチすることで無駄なAPIコールを省きます。

### 実装2: ギタースタジオ share_plus 録音共有

```dart
// cross_file は share_plus が再エクスポートするため直接importは不要

```

`unnecessary_import` エラーの典型例。`share_plus` が `cross_file` を再エクスポートしているため直接インポートは不要です。

### 実装3: user-profile-manager PATCH API


今日、自分株式会社のアプリに3つの新機能を追加しました。

カレンダービュー、ギター録音のシェア機能、そして管理者がユーザーのプロフィールを編集できる機能です。

1日で3機能というのは、決して天才的な開発速度ではありません。**Claude Code Scheduleによる自動CSチェックと、毎日の小さな積み上げが可能にしています**。

毎時自動で動くCSチェックが「Supabase Edge Functionのデプロイ上限（94個）に近づいたら警告する」という QUOTA GUARD を持つことで、制約を意識せずに開発に集中できます。

制約があるから、既存の関数を「拡張」するという設計パターンが生まれる。制約は創造性を生む、と改めて実感した1日でした。
