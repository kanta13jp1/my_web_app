**エッセイ風リード**:

一人で「会社」を動かすとはどういうことか。

エンジニアリングも、マーケティングも、カスタマーサポートも、経営判断も——全部ひとり。でも、AI エージェントを 2 台並列で動かすことで、その「ひとり」の定義が変わりつつあります。

Claude Code がアーキテクトとして設計し、Codex が実装する。毎時 GitHub Actions が 30 以上のワークフローを自動で回す。人間の自分は「CEO」として意思決定だけに集中できる。

これが「自分株式会社」のシステムです。
