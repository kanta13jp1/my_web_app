# 【Flutter Web + Supabase】AIが給料振込を自動検知して家計を管理する仕組みを作った

> 週次 building in public 記事 — 2026-06-21

## 概要

個人向け経営ダッシュボード「自分株式会社」の今週のアップデートをまとめます。Flutter Web + Supabase + Claude API の組み合わせで、給料振込の自動検知・AI負債管理・タイムアウト対策など13本のPRを着地させました。

URL: https://my-web-app-b67f4.web.app/

---

## 今週のハイライト

### 給料振込の自動検知 + 想定給料額の登録導線 (PR #3600)

毎月の想定手取り額を事前登録しておくと、実際の振込額と比較して乖離を即座に通知します。税率変更や手当変動を見逃さなくなります。

### 定期固定費カードを給料日サイクル順に並べ替え (PR #3598)

「給料日から何日後に引き落とし」という視点でソート。キャッシュフローの流れが直感的に把握できます。

### 各負債に「手順を確認」ボタン — Claude AIが引き落とし手順を提示 (PR #3571)

ローンやクレカの各カードに「手順を確認」ボタンを追加。Supabase Edge Function 経由で Claude API を呼び出し、引き落とし日前日の残高確認手順をステップバイステップで提示します。

```typescript
// Supabase Edge Function
const response = await anthropic.messages.create({
  model: 'claude-sonnet-4-6',
  max_tokens: 500,
  messages: [{ role: 'user', content: `${bankName}の${debtName}の引き落とし確認手順を教えて` }],
});
```

### AI-hub の 502 エラー対策: タイムアウト全面展開 (PR #3576/#3586/#3597)

複数AIプロバイダを束ねるEdge Functionで、遅いプロバイダが502エラーを引き起こす問題を修正。全フェッチに15秒タイムアウトを設定しました。

### デバウンス最適化: Function呼び出しを約60%削減 (PR #3587/#3591)

デバウンス窓700ms→2500msに拡大。初期化時の重複リクエストを抑制しコストを大幅削減。
