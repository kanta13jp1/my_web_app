## 本文 (統合版・各プラットフォームで使用)

Flutter プロジェクトの「マジックナンバー色」問題 — `Colors.blue`、`Colors.grey`、`Colors.orangeAccent` がコード全体に散在する問題を、Claude Code で一括解決しました。

### 背景

自分株式会社 (https://my-web-app-b67f4.web.app/) は Flutter Web + Supabase のAI統合アプリです。`docs/DESIGN.md` でブランドカラーを定義していましたが、コードには off-brand な色が 200+ ファイルに散在。手動修正は非現実的でした。

### DESIGN token マッピング

| Flutter Color | ブランド hex | 用途 |
|---|---|---|
| `Colors.blue` / `Colors.lightBlue` | `0xFF5C6BC0` | Primary (Indigo) |
| `Colors.orangeAccent` | `0xFFFF7043` | Secondary (Orange) |
| `Colors.yellow` | `0xFFFFD54F` | Warning/Accent |
| `Colors.grey` | `0xFFB0B0B0` | Muted text |

### 実装の流れ

Claude Code に 3 フェーズで依頼:

1. **Phase 1 (14 pages)**: ページファイルの一括置換
2. **Phase 2 (118 files)**: widgets 含む全ファイルの一括置換
3. **Phase 3 (81 files)**: `Colors.grey.shade*` の個別対応

各フェーズ後に `flutter analyze 0 エラー` を確認。

### ハマったポイント

- `Color(0xFF...).shade200` → コンパイルエラー (`Color` クラスに `.shade` はない)
- `pdf` パッケージの `PdfColors` と混同
- trailing comma lint エラー 36 件 → `dart fix --apply` で一括解消

### 結果

**手動推定 8〜12 時間 → Claude Code で約 2 時間**  
Off-brand カラー 200+ 箇所を完全撲滅。DESIGN token 準拠率 ~100% 達成。

### まとめ

大規模 Flutter リファクタを Claude Code でやるなら:
1. 段階的バッチ処理
2. 各フェーズで `flutter analyze` 確認
3. shade 参照は個別対応
4. 最後に `dart fix --apply` で lint 整理
