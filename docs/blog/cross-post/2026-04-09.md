## 本文（クロスポスト共通）

自分株式会社（Flutter Web + Supabase）は Notion・Evernote・MoneyForward など
21 の競合サービスの機能を 1 つに統合する AI ライフマネジメントアプリです。
ソロ開発を #buildinpublic でオープンに進めています。

今週の主な実装をまとめます。

---

### Flutter Web ダークテーマ完全対応 — colorScheme トークン 160件置換

長期開発で蓄積した `Colors.grey[*]`・`Colors.white`・`Colors.black87` を
Material 3 の colorScheme トークンに置換しました。

**置換ルール**:

| Before | After | 用途 |
| --- | --- | --- |
| `Colors.grey[100]` | `colorScheme.surfaceContainerLow` | 薄い背景 |
| `Colors.grey[200/300]` | `colorScheme.surfaceContainerHighest` | カード背景 |
| `Colors.grey[400–600]` | `colorScheme.onSurfaceVariant` | サブテキスト |
| `Colors.grey[700/800]` | `colorScheme.onSurface` | 本文テキスト |
| `Colors.white` (背景) | `colorScheme.surfaceContainerLow` | ページ背景 |
| `Colors.black87` | `colorScheme.onSurface` | 見出し |
| `Colors.black54` | `colorScheme.onSurfaceVariant` | ヒントテキスト |
| `Colors.black12` | `colorScheme.outlineVariant` | 区切り線 |

バッチごとに `flutter analyze` を実行し、44ファイル・160件を段階的に修正。
0 エラーを維持しながら安全に進められました。

---

### Notion風 画像ドラッグ&ドロップ実装

`package:web` の HTML drag/drop API でブラウザネイティブのドロップを受け取り、
既存の Ctrl+V 貼り付けフローに接続しました。

**条件付きインポートでクロスプラットフォーム対応**:

```dart
export 'note_image_drop_stub.dart'
    if (dart.library.html) 'note_image_drop_web.dart';
```

Web では HTML の FileReader API でバイト列を取得し、Supabase Storage にアップロード後、
マークダウンに `![image](URL)` 形式で挿入します。

---

### コンソールエラー自動収集

`FlutterError.onError` と `PlatformDispatcher.instance.onError` をフックして
エラーを Supabase Edge Function に自動送信する ErrorReporter を実装しました。

- 未ログイン時スキップ
- セッション内重複防止（同一エラーは 1回のみ）
- 最大 10件/セッション
- 報告中の再帰ループ防止
