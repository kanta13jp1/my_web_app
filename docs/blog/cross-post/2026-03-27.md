## 本文 (全プラットフォーム共通)

### はじめに

「自分を会社として経営する」というコンセプトで、Flutter Web + Supabase を使ったライフマネジメントアプリを開発しています。

Notion・Evernote・MoneyForward・Slack・X・Amazon など**21社の競合サービス**が提供する機能を1つに統合し、さらに**人間の思考・行動・意思決定を補助するAI機能**を組み込んでいます。

サービスURL: https://my-web-app-b67f4.web.app/

---

### 今週実装した機能 (全21件から主要機能を紹介)

#### 見栄ガード (#242)
「なぜそれをやるのか」を5段階の問いで掘り下げ、見栄・承認欲求が動機の場合はアラートを出す機能。人間は意外と「かっこよく見られたい」という動機で行動していることが多いため、これを可視化するUIを設計しました。

#### 論理的意思決定ガード (#229)
感情的・衝動的な判断を検知してブロック。「3秒以内に決めていないか」「選択肢を3つ以上検討したか」などのチェックリストを通します。

#### MAGIシステム — 3視点AI判断 (#228)
エヴァンゲリオンのMAGIシステムをインスパイアした機能。CASPER(人間・母親視点)・BALTHASAR(科学者視点)・MELCHIOR(哲学者視点)の3視点でAIが判断を補強します。

#### 浪費トラッキング (#240)
MoneyForwardとの差別化ポイント。「投資(資産に変わる支出)を除いた純粋な浪費のみ」を追跡します。

#### 思考キャプチャ (#227)
GTDの「収集」フェーズに特化。浮かんだ思考を0.5秒でキャプチャするUIを目指しました。

#### 人生目標管理 — ドリームツリー (#226)
夢→大目標→中目標→小目標の4階層ツリー構造。再帰的なSQLとFlutterのTreeViewで実装。

#### コンビニ経営シミュレーション (#230)
経営判断力を鍛えるゲーム。在庫管理・価格設定・売上予測をシミュレーションします。

### Claude Code Scheduleによる完全自動化

今回の開発で最も力を入れたのが、Claude Code Scheduleを使った完全自動化です。

| タスク | 頻度 | 内容 |
|---|---|---|
| cs-check | 毎時 | サポートチケット返信・バグ自動修正・インフラ監視 |
| daily-report | 毎朝9時 | メトリクス取得・X自動投稿・競合モニタリング |
| blog-draft | 毎日8時 | 技術ブログ下書き自動生成 |
| pr-auto-review | 3時間ごと | PRのセキュリティ・品質自動レビュー |
| competitor-monitoring | 毎日7時 | 21社の競合動向チェック |

**この記事自体も、Claude Code Scheduleが自動生成した下書きをベースにしています。**

### 詰まったポイント

#### GitHub Actions の main ブランチ保護問題
自動化タスクから直接 `git push origin main` するとブランチ保護に引っかかる問題。
解決策: ブランチ作成→PR作成→自動マージ のフローに変更。

#### X投稿のJSONエスケープ
シェルスクリプト内で日本語テキストをJSONに埋め込む際の特殊文字問題。
解決策: `jq` を使って安全にJSONを生成。

#### マインドマップのスクロール競合
Flutter Webでマインドマップのズーム操作とページスクロールが競合する問題。
解決策: `GestureDetector` の `onPointerSignal` でポインタシグナルを横取り。
