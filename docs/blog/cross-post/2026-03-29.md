## 本文 (共通・全プラットフォーム対応版)

「自分株式会社」は Notion・Evernote・Slack など 21 競合の機能を 1 つに統合したAIライフマネジメントアプリです。Flutter Web + Supabase で開発しており、今回は **友達招待システム（ReferralShareCard）** と **Edge Function UI 自動連携** という 2 つの機能を同日に実装しました。

### なぜ友達招待を実装したか

グロース施策として「友達を招待したら特典がもらえる」仕組みは定番です。しかし Flutter Web でそれをきれいに実装しようとすると:

- 紹介コードの一意性保証（`UNIQUE` 制約 + 衝突時の再生成）
- `?ref=` パラメータの Flutter Web での読み取り
- Supabase RLS と `referred_by` カラムの権限設計
- シェア UI（コピー・SNS共有ボタン）

など意外と考えることが多い。今回の実装ログをまとめます。

### ReferralShareCard の実装

`ReferralShareCard` はホーム画面に配置するウィジェット:

```dart
ReferralShareCard(
  userId: currentUser.id,
  referralCode: profile.referralCode,
  referralCount: profile.referralCount,
),
```

Supabase 側:

```sql
ALTER TABLE profiles
  ADD COLUMN referral_code text UNIQUE,
  ADD COLUMN referred_by uuid REFERENCES profiles(id),
  ADD COLUMN referral_count int DEFAULT 0;
```

新規サインアップ時に `growth-acquisition-signal` Edge Function が `?ref=` を読んで `referred_by` をセット。招待元ユーザーの `referral_count` をインクリメントします。

### Edge Function UI 自動連携

`lib/data/home_tool_catalog.dart` にツールカタログを定義:

```dart
const kToolCatalog = [
  ToolCatalogEntry(
    functionName: 'memo-reactions',
    route: '/memo-reactions',
    icon: Icons.emoji_emotions,
    label: 'メモリアクション',
  ),
  ToolCatalogEntry(
    functionName: 'note-comments',
    route: '/note-comments',
    icon: Icons.comment,
    label: 'ノートコメント',
  ),
  ToolCatalogEntry(
    functionName: 'growth-acquisition-signal',
    route: '/growth-acquisition-signal',
    icon: Icons.person_add,
    label: '獲得シグナル',
  ),
];
```

新しい Edge Function を追加するたびにこのリストにエントリを追加するだけ。`main.dart` のルート登録も `kToolCatalog` を走査して自動化できます。

### 詰まったポイント

**① Flutter Web で URL パラメータを読む**

```dart
final refCode = Uri.base.queryParameters['ref'];
```

Firebase Hosting の SPA rewrite があっても、クエリパラメータはそのまま Flutter に渡されます。

**② UUID の型ミスマッチ**

```dart
// 修正前（実行時エラー）
.eq('id', commentId.toString()) // commentId が int 型

// 修正後
.eq('id', commentId) // String(UUID) に統一
```

flutter analyze では検出されないため要注意。

### まとめ

「友達招待 → 獲得シグナル記録 → 管理者確認 UI」の招待フローが一本つながりました。Edge Function UI の自動連携パターンも確立できたので、今後は Edge Function を追加するたびに UI も自動で生えてきます。
