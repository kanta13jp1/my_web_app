## 本文 (共通・JA版)

「自分株式会社」は Flutter Web + Supabase で構築した AI統合ライフマネジメントアプリです。今週の主な成果:

**AI大学320社突破**
世界中のAIプロバイダーを収録するデータベースが320社に到達。今週は AutoGen (Microsoft)・DSPy (Stanford)・Haystack (deepset)・CrewAI を追加しました。データはSupabase PostgreSQLで管理し、GHA スケジュールタスクが毎日自動更新します。

**競合比較ページ240社対応**
Flutter Web の `comparison_page.dart` で240社の競合情報をレンダリング。重複マップキーバグ (equal_keys) を `collision patrol` で検出・修正しました。

**12インスタンス並行開発体制**
Claude Code × 10 + Codex CLI × 2 = 12インスタンスが独立した git worktree で並行稼働。役割分担を明確化し、衝突を回避しています。

**競馬AI改良 (19因子体制)**
- `prevVenueMatchScore`: 前走同会場スコア
- `favOddsBonus`: 本命オッズconfidenceボーナス
