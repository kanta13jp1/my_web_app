## 統合版本文

### はじめに

個人開発アプリ「自分株式会社」（https://my-web-app-b67f4.web.app/）に、今週大きな機能を追加しました。

**給与明細（PDF）をアップロードするだけで、今月の可処分所得を自動計算し、AI が節約・支出改善のアクションを提案する** という機能です。

「毎月の給与は分かっているのに、いつの間にかお金が消えている」という感覚、ありませんか？ その正体は固定費・変動費の把握不足と、可処分所得の計算が曖昧なことにあります。本機能はその課題を、Claude AI + Supabase Edge Functions + Flutter Web で解決します。

---

### 実装した機能

今回マージした PR #3008 は3つのモジュールに分かれます（合計 3973行追加）。

#### 1. Payslip Ingestion — 給与明細OCR解析

Supabase Storage の `payslips` バケットに PDF をアップロードすると、Deno の Edge Function が Claude AI に OCR 解析を依頼。解析結果（総支給額 / 手取り / 社会保険料 / 各種控除）を PostgreSQL に保存します。

信頼度スコア (`confidence`) が 0.8 未満の場合は `needs_review` フラグを立て、UI でユーザーに確認を促します。

```typescript
export type ParsedPayslip = {
  gross_amount: number;        // 総支給額
  net_amount: number;          // 手取り額
  social_insurance_total: number | null;
  deductions: Record<string, unknown>;
  confidence: number;          // AI解析信頼度 0-1
};
```

#### 2. Expense AI — AI支出分類

家計簿データを AI が「固定費」「削減可能な変動費」「投資・自己研鑽」に自動分類し、月次支出レポートを生成します。

#### 3. Disposable Balance — 可処分所得計算

給与明細 + 支出を統合して「今月残り使える金額」と「1日あたり予算」を計算。AI がアクションプランを優先度順に最大5件提案します。

### 詰まったポイント

**PDF の Blob 処理**  
Supabase Storage の `download()` は `Blob | ArrayBuffer | Uint8Array` の Union 型を返します。Deno では `Blob.text()` が動かないケースがあるため、`ArrayBuffer → Uint8Array → TextDecoder` の変換チェーンで安定化しました。

**AI 解析の信頼度管理**  
給与明細のフォーマットは会社ごとに異なります。Claude に `confidence` スコアを返すようプロンプトを設計し、低スコア時は手動確認フローに誘導します。

**RLS の設計**  
給与情報は特に機密性が高いため、Storage の `payslips` バケットも `auth.uid()` 単位でアクセス制御しています。

```sql
create policy "Users can upload their own payslips"
  on storage.objects for insert
  with check (
    bucket_id = 'payslips'
    and (storage.foldername(name))[1] = auth.uid()::text
  );
```
