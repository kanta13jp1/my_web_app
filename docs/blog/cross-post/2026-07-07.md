## 本文 (全プラットフォーム共通)

個人開発で「自分株式会社」というFlutter Webアプリを作り続けています。メモ・タスク・成長記録を一元管理するパーソナルOS的なツールです。

今週は **「AIが読めるパブリックメモ」** と **「Xへの自動投稿品質を上げるアンチスロップ制約」** の2本柱を実装しました。

アプリURL: https://my-web-app-b67f4.web.app/

### 実装1: AIが読めるパブリックメモAPI

`format=json` または `format=txt` を渡すと、AI・ボット向けの構造化データを返します。

```
GET /public-memo/{id}?format=json
→ { "title": "...", "body": "...", "tags": [...], "related": [...] }

GET /public-memo/{id}?format=txt
→ プレーンテキスト (LLMプロンプトに直接貼り付け可能)
```

`search` と `related` アクションでメモ間の関連も自動探索できます。

Supabase Edge Function (Deno) で実装。HEAD リクエストと空ボディ POST にも対応しました。

### 実装2: X投稿のアンチスロップ制約

AIが生成するX投稿に混入する「スロップ」(空虚な決まり文句) を除去するため、以下の制約セットをプロンプトに組み込みました:

- **Feature facts**: 具体的な機能名・数値を必ず含める
- **First-person**: 一人称で書く
- **Banned phrases**: 「〜ですね」「素晴らしい」「ぜひ」等を禁止
- **Poll subject-lock**: Xポールの選択肢は投稿テーマと一致させる
- **Relevance gate**: スレッドの各ツイートがトピックと関連しているかチェック
- **Feature budget**: 1スレッドのトピックを最大3つに制限

### 実装3: グロースハブ計測強化

ブックマーク数・プロフィールクリック数・URLクリック数を追加計測。`media_type` × `Media lift` のA/Bテストで投稿効果を測定中。

毎朝自動でXの成長レポートをまとめる **daily X briefing cron** も追加。

### 詰まったポイント

- **`&amp;` URL問題**: Edge FunctionのHTML組み立て時に `&` が `&amp;` になりリダイレクトURLが壊れていた → format別にレスポンス生成パスを分割して解決
- **HEAD リクエスト**: クローラーが 405 を受け取っていた → Edge Functionに明示的なHANDLERを追加

### まとめ

今週は「AIが読める・AIが書く・AIが計測する」という3レイヤーが揃った週でした。

Claude Code + Supabase Edge Functions の組み合わせで、個人開発でも本格的な自動化を回せています。来週はXのフォロワー転換率 (profile-clicks → follow) をさらに掘り下げる予定です。
