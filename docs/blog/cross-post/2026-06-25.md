## 本文 (統合版)

個人開発で Flutter Web + Supabase を使った「自分株式会社」(https://my-web-app-b67f4.web.app/) というSaaSを作っています。今週は収益化に向けた重要なマイルストーンを達成したので記録します。

### 今週の主な実装

- **AI使用量メータリング + フリーミアム上限ゲート** — Supabase Edge Functions (Deno) で実装
- **特商法・利用規約ページ + 課金導線整備** — 日本のSaaS運営に必須の法務対応
- **Stripe連携のenv値 `.trim()` 防御** — コピペ空白によるバグを事前防止
- **資産管理ページのパフォーマンス改善** — 毎秒フル再ビルドを解消

### AI使用量ゲートの設計思想

Supabase Edge Functions の `ai-hub` 内に `usage_gate.ts` として**純粋関数**でロジックを切り出しました。

```typescript
// supabase/functions/ai-hub/usage_gate.ts
export async function decideUsage(
  userId: string,
  plan: "free" | "pro",
  currentMonthCount: number
): Promise<{ allowed: boolean; reason?: string; remaining?: number }> {
  // pro は無制限
  if (plan === "pro") return { allowed: true };

  const FREE_LIMIT = 30;
  if (currentMonthCount >= FREE_LIMIT) {
    return {
      allowed: false,
      reason: "月間無料AI利用回数(30回)に達しました。Proプランへアップグレードしてください。",
      remaining: 0,
    };
  }
  return { allowed: true, remaining: FREE_LIMIT - currentMonthCount };
}
```

**フェイルオープン設計**: DBエラー等でゲート判定が落ちた場合でも `allowed: true` で通します。課金ロジックは収益に直結するため、バグによる機会損失より「通しすぎ」の方が安全という判断です。

Deno テスト 9件 green — 純粋関数として切り出したことでテストが書きやすくなりました。

### Stripe env値の `.trim()` 防衛

```typescript
const stripeKey = Deno.env.get("STRIPE_SECRET_KEY")?.trim() ?? "";
const priceId = Deno.env.get("STRIPE_PRICE_ID_PRO")?.trim() ?? "";
```

Supabase ダッシュボードからコピペすると末尾に空白が混入することがあります。`No such price` エラーの原因になるため、必ず `.trim()` を付けましょう。

### Flutter パフォーマンス: 毎秒再ビルド問題

`initState` の `Timer.periodic(Duration(seconds: 1), ...)` が `setState` を呼ぶことでページ全体が毎秒再ビルドされていました。

日付(M/d)しか表示しないので、日付が変わった時だけ再描画する実装に変更:

```dart
Timer.periodic(const Duration(seconds: 1), (timer) {
  final newNow = DateTime.now();
  _maybeDetectSalaryDeposit(newNow); // 毎tick評価はそのまま

  if (newNow.day != _now.day || newNow.month != _now.month) {
    setState(() => _now = newNow); // 日付変更時のみ再描画
  } else {
    _now = newNow; // setState不要
  }
});
```

### 特商法ページの重要性

日本でSaaSを運営するには、特定商取引法に基づく表記が必要です。Stripe の審査でも確認されます。Flutter の GoRouter に `/legal/tokusho`、`/terms`、`/privacy` を追加し、課金画面フッターにリンクを配置しました。
