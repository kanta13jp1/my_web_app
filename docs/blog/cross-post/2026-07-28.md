# Flutter + Supabase でゼロから作る IQ テスト機能と買い切り販売基盤 — 自分株式会社の1週間

Flutter Web + Supabase で個人 SaaS「自分株式会社」を開発しています。今週は3つの大型フィーチャーをリリースしました。

## 今週のリリース

- **IQ テスト機能 (5領域)** — 25問で測定・学習プラン自動生成 (#4353)
- **HexCiv 買い切り販売** — ¥500 単品商品 × Supabase 安全販売基盤 (#4364)
- **月次借金返済報告カード** — 純関数設計で正確な進捗可視化 (#4373)

---

## 技術ハイライト

### IQ テスト (5領域)

論理推論 / 数的処理 / 空間認識 / ワーキングメモリ / 言語理解の5領域を難易度重みつきで測定し偏差IQ (100/15) に換算。未回答 = 不正解扱いで早期離脱を防止。換算定数は `IqCalibration` に集約し「標準化ではない」と明示します。

### Supabase で有料コンテンツを守る3重ガード

1. Storageバケット `public = false`
2. Edge Function で購入確認 → 署名URL (60秒)
3. `shop_purchases` に insert ポリシーなし (Stripe Webhook 経由のみ INSERT)

### 符号規約の統一 (返済カード)

負債 balance (負値) と前月残高 (絶対値) の混在を純関数で正規化。センシティブ情報はフィールドに持たせない設計。
