### Automating Debt Management Workflows in Flutter Web

I've been building "Jibun Kabushiki-gaisha" — a personal asset/liability management app using Flutter Web + Supabase. This week I added two features to eliminate manual tracking errors.

**Debt Control Review Panel**: A section that highlights debts with pending billing confirmations or missing payment sources. Color-coded amber (needs action) vs. teal (all clear).

**Transfer Task Execution Memo**: When completing a bank transfer task, users can log ATM fees, post-transfer balances, and notes. Persisted to Supabase for later review.

### はじめに

個人の資産・負債を一元管理する Flutter Web アプリ「自分株式会社」の開発を続けています。今回は資産管理画面に 2 つの新機能を追加しました。

1. **負債コントロールレビューパネル** — ビリング確認・支払い元設定の漏れを一覧表示
2. **口座移動タスクへの実行メモ** — ATM 手数料・残高などを記録
