個人開発アプリ「自分株式会社」（Flutter Web + Supabase）の今週アップデートです。

## 今週実装した3機能

1. **資産異常検知システム**（anomaly detection）— DB → Edge Function → cron → UI
2. **投資ポートフォリオ履歴チャート**
3. **LP パブリックトライアル + magic link 引継ぎ**

## 資産異常検知システム

カテゴリ別の月次支出が「3ヶ月平均の±20%を超えたら異常」とみなし、Supabase Edge Function（Deno）で検知して DB に記録する仕組みを実装しました。

### テーブル設計のポイント

```sql
UNIQUE(user_id, category, target_month)
```

この複合ユニーク制約で cron の二重実行を無害化（冪等 upsert）。

### LLM 説明フラグ

`ANOMALY_AI_EXPLANATION_ENABLED=true` の場合のみ Claude を呼んで自然言語で「なぜ異常か」を説明。デフォルト OFF でトークンコストゼロ運用。

### GitHub Actions 日次 cron

```yaml
schedule:
  - cron: '0 0 * * *'   # JST 09:00
```

`scan_all` input で全ユーザー一括スキャンにも対応。

## 投資ポートフォリオ履歴チャート

`fl_chart` で資産残高の時系列グラフを実装。過去12ヶ月のタイムレンジ選択 + タップで残高内訳ツールチップ表示。

## LP トライアルの magic link 引継ぎ

LP から「まず試す」で始めたトライアルデータを、magic link サインアップ後の新規ユーザーに引き継ぐバグを修正。`auth.onAuthStateChange` で認証完了イベントをキャッチして localStorage から移行。
