## 実装ハイライト

### Tombstone パターンによる削除伝播

クロスデバイス同期で最も難しかったのが「削除」の伝播です。union マージだけでは削除が他端末へ伝わりません。解決策は Tombstone テーブルの導入です。

```sql
CREATE TABLE asset_pref_tombstones (
  user_id UUID,
  item_key TEXT,
  deleted_at TIMESTAMPTZ DEFAULT NOW(),
  PRIMARY KEY (user_id, item_key)
);
```

マージ時は `tombstones.deleted_at > items.updated_at` を条件に削除扱いとし、GC は削除時刻順で実行します。

### AI フィードバックパイプライン

X（旧 Twitter）でシェアされたフィードバックを Claude API で自動対応するパイプラインを構築しました。Supabase Edge Functions（Deno）が Webhook を受け取り、Claude に返信文を生成させ、`feedback_queue` テーブルへ保存します。

### 禁酒で借金完済チャレンジ

ユニークな機能として、飲み機会コストを累積し借金完済日を逆算するチャレンジ機能を追加。「禁酒すれば○月○日に完済できる」という具体的な目標が可視化されます。
