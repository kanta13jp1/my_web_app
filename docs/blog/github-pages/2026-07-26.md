## はじめに

「自分株式会社」というコンセプトで、Flutter Web + Supabase を使った個人SaaSを開発しています。今週、Claude Code (AI コーディングアシスタント) が GitHub Actions のCI/CDパイプラインを自動最適化してくれました。

アプリ: [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)

## 今週の主要改善

### Flutter pub キャッシュ追加 (30-60秒 → 3-5秒)

`deploy-dev.yml` と `deploy-staging.yml` に `actions/cache@v6` を追加。月間で約90〜270 ubuntu-minutes の削減を達成。

```yaml
- name: Cache pub dependencies
  uses: actions/cache@v6
  with:
    path: ~/.pub-cache
    key: {% raw %}${{ runner.os }}-pub-${{ hashFiles('**/pubspec.lock') }}{% endraw %}
    restore-keys: |
      {% raw %}${{ runner.os }}-pub-{% endraw %}
```

`ci.yml` には既にあったのに deploy 系に適用し忘れていたパターンを Claude が検出。

### MCP Smoke テストのキャンセル処理修正

ステートレスな HTTP プローブで `cancel-in-progress: false` になっていた問題と、キャンセル時に `STATUS="critical"` と誤記録されていたバグを修正。誤アラートがゼロになりました。

### grill-me スキルの追加

実装前の認識合わせを自動化する Claude Code スキル。「作ってから違った」を防ぐための壁打ち機能です。

## 学んだこと

AI駆動の自律型開発は、特にインディー開発者にとって強力な武器です。コードベース全体を俯瞰できるAIは、人間が見落としがちなパターンの不整合を発見してくれます。一方で、AIが自律的に変更を加えていくため、変更の意図を理解した人間のレビューが不可欠です。
