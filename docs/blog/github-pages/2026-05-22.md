## はじめに

個人開発プロジェクト「自分株式会社」を Flutter Web + Supabase で構築しています。今週の主な実装は **給料サイクル別支出チャート** (PR #1368) です。

## 純粋 Dart サービス設計

`SalarySpendingBreakdownService` を `const` 純粋クラスとして実装しました。Flutter Widget にも Supabase クライアントにも依存しないため、103行のユニットテストで主要パスをカバーできます。

給料日(デフォルト25日)を基準にした期間計算では、28日以上を丸めて月末エッジを事前に閉じています。

## CI 自動修復の効果

`ci-auto-fix.yml` による `dart format` と `deno fmt` の自動修復コミットで、フォーマットエラーによる PR ブロック時間がゼロになりました。

## 今後の展望

資産管理ページは最も機能が充実した領域になってきており、次は AI による支出パターン分析(カテゴリ自動分類)を検討中です。
