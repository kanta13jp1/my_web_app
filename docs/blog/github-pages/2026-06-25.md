## AI使用量ゲートの設計

Supabase Edge Functions の `ai-hub` 内に `usage_gate.ts` として純粋関数でロジックを切り出しました。

```typescript
export async function decideUsage(
  userId: string,
  plan: "free" | "pro",
  currentMonthCount: number
): Promise<{ allowed: boolean; reason?: string; remaining?: number }> {
  if (plan === "pro") return { allowed: true };

  const FREE_LIMIT = 30;
  if (currentMonthCount >= FREE_LIMIT) {
    return { allowed: false, reason: "月間無料AI利用回数(30回)に達しました。", remaining: 0 };
  }
  return { allowed: true, remaining: FREE_LIMIT - currentMonthCount };
}
```

**フェイルオープン設計**: DBエラー時は `allowed: true` で通す。機会損失より「通しすぎ」の方が安全。

純粋関数として切り出したことで Deno テスト 9件 green を達成しました。

## Stripe env値の `.trim()` 防衛

```typescript
const stripeKey = Deno.env.get("STRIPE_SECRET_KEY")?.trim() ?? "";
```

Supabase ダッシュボードからコピペ時の末尾空白が `No such price` エラーの原因になります。

## Flutter パフォーマンス改善

`Timer.periodic(Duration(seconds: 1), ...)` が毎秒 `setState` を呼びページ全体を再ビルドしていた問題を修正。日付変更時のみ再描画するよう変更し、idle時の再計算をほぼゼロ化しました。
