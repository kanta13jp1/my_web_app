個人で会社を運営しながらソフトウェア開発をするというのは、エンジニアリングと経営の両方を一人でこなすことを意味します。「自分株式会社」は Flutter Web + Supabase で構築した SaaS アプリで、現在ユーザー数 37 名、機能リクエスト 53 件が積み上がっています。

## AI エージェント 2 台体制の構成

Claude Code（アーキテクト）と Codex CLI（実装担当）を並列で動かす 2 台体制で、一人でも複数人分の速度を実現しています。

| インスタンス | 役割 |
|---|---|
| Claude Code #1 | 設計判断・PR レビュー |
| Codex #1 | 機能実装・WBS 更新 |

GitHub Actions で 30 以上のワークフローを自動化し、毎時インフラヘルスチェック、AI 大学コンテンツ更新、CS ログ記録が無人で動いています。

## Karpathy 4 サイクルによる知識管理

- **Ingest**: `scripts/memory_ingest.py`
- **Compile**: `scripts/wiki_compile.py`  
- **Query**: `notebooklm` CLI（ゼロトークンリサーチ）
- **Lint**: `scripts/knowledge_vault_lint.py`

## 今週の開発ハイライト

- **CI ゲート修正**: PR Gate の `declaration body patch` エラーを v21 5 層構造予防仕様で対処
- **WBS リバランス**: アセット管理ロードマップを AI モデルベンチマーク計画と整合
- **動画 pipeline**: シークレット readiness ゲート (#1724) 実装
