Flutter プロジェクトで `Colors.blue`、`Colors.grey` が 200 ファイルに散在する問題を
Claude Code で一括解決しました。VSCode版#107〜109 の開発記録です。

## 背景

自分株式会社 ([https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)) は
Flutter Web + Supabase で構築した AI 統合アプリです。
`docs/DESIGN.md` でブランドカラー (Indigo/Orange ダークテーマ) を定義していますが、
コード全体には off-brand な Flutter color constants が散在していました。

## 移行アプローチ

Claude Code に以下の 3 フェーズで依頼:

1. **Phase 1**: 置換マッピング定義 (`Colors.blue` → `0xFF5C6BC0` など)
2. **Phase 2**: 118 ファイルの一括置換 (import/コメント除外)
3. **Phase 3**: shade 参照の個別対応 81 ファイル

各フェーズ後に `flutter analyze 0 エラー` を確認。

## 結果

200+ 箇所の off-brand カラーを撲滅し、DESIGN token 準拠率を約 100% に引き上げました。
作業時間は手動推定 8〜12 時間に対し、Claude Code 使用で約 2 時間。

詳細な実装手順は Zenn 記事をご参照ください。
