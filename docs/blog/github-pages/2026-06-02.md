Flutter Web + Supabase で「自分株式会社」という個人向け資産・時間管理 SaaS を開発しています。本番 URL は [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/) です。

## 今週のハイライト

### 2インスタンス AI フリート

以前の 12 インスタンス体制から **Claude Code #1 + Codex #1** の 2 インスタンスに最適化しました。

- **Claude Code #1**: アーキテクチャ・レビュー・Hook 設計・クロスインスタンス調整
- **Codex #1**: 実装・SQL・Edge Functions・GitHub Actions・UI QA

### AI ツール自動監視

毎日主要 AI 開発ツールの公式ページをクロールし、変化を検知しています。

今週の検知:
- Claude Code 2.1.160 (2026-06-02)
- Codex Sites 機能 preview (2026-06-02)
- Cursor v3.6 Auto-review (2026-05-29)
- Devin 2.2 computer-use E2E (2026-05-29)

### xAI Grok Build を競合追加

21 社目の競合として xAI Grok Build を追加。AI コーディング支援カテゴリで脅威度 High と評価しました。

### Claude Code Hooks 自動化

`SessionStart` hook でルール・役割・哲学原則を毎セッション自動注入し、コンテキスト設定コストをゼロにしました。

## 技術スタック

- Frontend: Flutter Web (Dart)
- Backend: Supabase (PostgreSQL + Edge Functions / Deno)
- Hosting: Firebase Hosting
- AI: Claude Code + Codex CLI (2インスタンス体制)
- CI/CD: GitHub Actions (30+ ワークフロー / 5 daily cron)
