「コードを書くだけで手一杯で、技術ブログを書く時間がない」

これはほぼすべての個人開発者が抱える悩みです。私が開発している **自分株式会社**（[https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)）は、Notion・Evernote・MoneyForward・Slack・Amazon など21競合を1つに統合する Flutter Web + Supabase のAIライフマネジメントアプリです。

今週、このアプリに「技術ブログ自動生成・自動クロスポスト」システムを実装しました。

## 全体アーキテクチャ

```
Claude Code Schedule (毎日 08:00 JST)
  ↓ git log --since="7 days ago" で開発活動を確認
  ↓ ブログ下書きを AI 生成 → docs/blog-drafts/
  ↓ Zenn / GitHub Pages / クロスポスト版も同時生成
  ↓
Supabase REST API
  ↓ blog_posts テーブルに draft として登録
  ↓
blog-auto-publisher Edge Function (Deno)
  ↓ Qiita API で投稿
  ↓ dev.to API で投稿
  ↓ status = "posted" に自動更新
```

## Qiita API 投稿コード

```typescript
const res = await fetch("https://qiita.com/api/v2/items", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${QIITA_ACCESS_TOKEN}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    title,
    body,
    tags: tags.slice(0, 5).map(t => ({ name: t.slice(0, 20) })),
    private: false,
  }),
});
```

## dev.to API 投稿コード

```typescript
const res = await fetch("https://dev.to/api/articles", {
  method: "POST",
  headers: { "api-key": DEVTO_API_KEY, "Content-Type": "application/json" },
  body: JSON.stringify({
    article: {
      title,
      body_markdown: body,
      tags: tags.slice(0, 4),
      published: true,
    },
  }),
});
```
