## はじめに

「自分株式会社」は、個人の資産・収支・学習・健康・仕事を一元管理する Flutter Web アプリです。
今週 (2026-07-24 〜 2026-07-30) は資産管理機能の大幅強化と IQ テストの仮説検証ループを同時並行で進めました。

Production: [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)

---

## 今週の主要実装 (9 PR)

### 資産管理機能の強化

- **「今日やること」ToDo + 細木数子 AI コーチング** (#4418): 六星占術スタイルの AI キャラクターが資産管理 ToDo にアドバイスを生成
- **返済報告カードの X 添付** (#4416): Supabase 公開バケット + X API v2 で画像付きツイートを自動化
- **二重計上バグ解消** (#4415): ハードコード ¥80,000 を排除し、ユーザー入力のみを信頼する設計に統一
- **セクション検索/ジャンプ** (#4413): ScrollController + GlobalKey + animateTo でアプリバーから目的のカードへ即時ジャンプ

### IQ テスト品質改善

10 仮説を立てて実測検証 → 9 件修正・1 件反証 (#4385)。
AI にテストケース生成と差分検証を任せることで、数週間分の改善を数時間で完了。

### Stripe・ショップ

- **全額返金でダウンロード権失効** (#4412): `refund.created` Webhook → Edge Function → `download_enabled: false`
- **販売ファネル計測** (#4392): GA4 カスタムイベントで `view_item → purchase` を追跡
