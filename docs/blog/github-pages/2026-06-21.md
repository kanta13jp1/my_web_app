## Weekly Dev Update — 2026-06-21

This week I shipped several major updates to [自分株式会社](https://my-web-app-b67f4.web.app/), my personal business dashboard built with Flutter Web + Supabase.

The highlight: **AI-powered salary detection** and **AI debt management guidance** that make personal finance management nearly hands-free.

### What Shipped This Week

**Salary Auto-Detection + Expected Amount Registration (PR #3600)**

The app now detects salary deposits automatically and compares them against a pre-registered expected amount. If the actual deposit deviates from the expected amount (e.g., due to tax changes or bonus adjustments), the user is immediately notified.

**Salary-Cycle Sorted Fixed Expenses (PR #3598)**

Fixed expenses are now sortable by "days after salary day" rather than calendar date. This makes cash flow management intuitive — you see exactly which bills come due in what order after each paycheck arrives.

**AI Debt Procedure Guide (PR #3571)**

Each debt entry now has a "Check Procedure" button that calls a Supabase Edge Function → Claude API to generate step-by-step instructions for verifying the upcoming debit will succeed.

**AI-Hub 502 Fix: Timeout Propagation (PR #3576, #3586, #3597)**

Added 15-second timeouts to all provider fetch calls in the `ai-hub` Edge Function, eliminating intermittent 502 errors caused by slow AI providers.

**Debounce Optimization: 60% Fewer Function Calls (PR #3587, #3591)**

Expanded debounce window from 700ms to 2500ms for AI summary and issue-matching requests during asset view initialization, significantly reducing Supabase Function invocations.

### Tech Stack

- **Frontend**: Flutter Web (Dart)
- **Backend**: Supabase (PostgreSQL + Edge Functions / Deno)
- **AI**: Claude API via Supabase Edge Functions
- **Hosting**: Firebase Hosting
- **CI/CD**: GitHub Actions
