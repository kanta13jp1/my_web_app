# 12 AI Agents in Parallel: One Week of Shipping Features Fast

I've been building "Jibun Kabushiki Kaisha" (My Corporation) — a personal life management app in Flutter Web + Supabase that integrates features from 21 competitors (Notion, Evernote, MoneyForward, Slack, etc.) into one product.

This week's highlights:

- **AI University 4-layer drill-down UI** (Faculty → Department → Course → Instructor)
- **Build in Public weekly automation** fully live
- **AI Second Brain Ingest Pipeline** (#974)
- **Theme Switcher UI Phase 2** — 10 theme catalog

The secret? **12 AI agent instances running in parallel**: Claude Code, Codex #1/#2, Gemini Code Assist, GitHub Copilot, and more.

## Lessons Learned

**Migration timestamp collisions** are real when 12 instances push migrations simultaneously. Solution: assign timestamp ranges per instance.

**CI race conditions** in `ci-auto-fix.yml` required adding `git pull --rebase` before every push.
