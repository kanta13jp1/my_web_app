「自分株式会社」は Notion・Evernote・MoneyForward・Slack など21社を超えることを目標に、Flutter Web + Supabase で個人が運営しているAI統合ライフマネジメントアプリです。

本日（2026-03-31）、Supabase Edge Function の総数が **155本** に到達しました。

## 今週の主な実装

- AI自動化・電子署名・SNS連携・受信箱・ビデオ会議 など5領域のバックエンド
- 通知センターUI を Flutter Web で新規構築
- `dart:html` 廃止対応（`package:web` へ移行）

## Edge Function 量産フロー

Deno の共通テンプレート（CORS ヘッダー・`service_role` キー利用）を使い回すことで、1日に20本以上の Edge Function を安全に量産しています。`deno lint` と `flutter analyze` の 0エラーを維持しながら機能追加を積み上げる体制が整ってきました。

## dart:html → package:web 移行

Flutter 3.x で `dart:html` が非推奨になったため、`package:web` に移行しました：

```dart
// After
import 'package:web/web.dart' as web;
web.window.localStorage.setItem('key', value);
```
