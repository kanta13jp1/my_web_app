Flutter Web + Supabase で「自分株式会社」という個人向け資産・時間管理 SaaS を開発しています。本番 URL は [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/) です。

今週は **Karpathy 4サイクル** の定常稼働と AI大学コンテンツの完全自動更新が節目を迎えました。

## Karpathy 4サイクルの定常稼働

Andrej Karpathy が提唱する「第二の脳」構築サイクルをプロダクト開発に応用しています。

| サイクル | 実装 | 状態 |
|---|---|---|
| Ingest | `scripts/memory_ingest.py` | ✅ 定常稼働 |
| Compile | `scripts/wiki_compile.py` | ✅ 毎日自動実行 |
| Query | `notebooklm` CLI | ✅ ゼロトークンリサーチ |
| Lint | `scripts/knowledge_vault_lint.py` | ✅ 定常稼働 |

今週は **wiki compile** が正常実行され、`docs/concepts/` と `docs/INDEX.md` が自動生成されました。

## AI大学コンテンツ自動更新

主要機能のひとつ **AI大学** では、AI ツール・サービス情報を GitHub Actions で毎日自動更新しています。今週だけで 10回以上の自動コミットが実行されました。

コンテンツのハッシュ比較による冪等性確保で、不要なコミットを防止しつつ本当に変化のあったコンテンツのみを更新しています。

## CI/CDコスト監査 & インフラヘルスチェック

GitHub Actions の実行コストを定期的に可視化する監査ジョブと、本番環境を毎時チェックするヘルスモニターが定着しています。

```
毎時: インフラヘルスチェック
毎日: CI/CDコスト監査 + 日次レポート + CS チェック
```
