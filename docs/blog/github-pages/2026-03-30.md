Flutter Web + Supabase で構築している「自分株式会社」というAI統合ライフマネジメントアプリを毎日ひとりでビルドしています。2026年3月30日に Supabase Edge Functions が**54本**に到達しました。

## 今回実装した内容

| 機能 | 概要 |
|------|------|
| notification-center | アプリ内通知管理（7カテゴリ・RLS対応） |
| onboarding-flow | 6ステップ自動オンボーディング |
| ai-secretary 強化 | 12部門業務知識 + 統計ベース回答 |
| agent-personality | AIエージェント個性管理 |
| agent-department-manager | 部門別AIエージェント管理 |

## 通知センター

`app_notifications` テーブルに RLS を適用し、`info / warning / error / success / feature / system / reminder` の7カテゴリに対応した汎用通知 API を実装しました。

## オンボーディングフロー

新規ユーザーの定着率向上のため、プロフィール設定→ノート作成→タスク登録→AI利用→チーム参加→通知設定の6ステップを DB 参照で自動判定します。

## 今回の主なバグ修正

- `ai-secretary`：`UPDATE + ORDER + LIMIT` の誤用を `INSERT` に変更
- `growth-achievement-summary`：存在しない `referrals` テーブル参照を `app_analytics` に修正
- `edge-function-coverage`：54本に更新
- `development-stats`：カウントを54に更新

## 詰まったポイント

Supabase JS クライアントの `.update()` に `.order()` と `.limit()` を組み合わせると PostgreSQL 側でエラーになります。最新レコードを更新したい場合は INSERT で別レコードを作るか、サブクエリで id を特定してから UPDATE する必要があります。
