## はじめに

「AIが仮説を立て、AIがコードを書き、AIが結果を測定する」——この一文が、直近1週間の自分株式会社の開発ログを一言で表しています。

Flutter Web + Supabase で構築したSaaS「自分株式会社」では、ランディングページ(LP)のグロース施策をほぼ全自動化しました。Claude Code と Codex を組み合わせた AI Fleet が、毎日仮説を生成し、コードを実装し、A/Bテスト結果をレポートする——そんな開発サイクルが実際に回っています。

今週のデモ: [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)

## 今週の主なリリース

### 1. 10仮説の同時測定 (#4321)

LPには現在10本の仮説が同時走行。各仮説のコンバージョン率をSupabase Edge Functionで追跡し、自動レポートで毎日判断を下します。

### 2. ワンタップトライアル (#4318)

メールアドレス入力なしでアプリを体験できるゲストトライアルフローを追加。セッション保持・ソーシャルプルーフ先行ロード・文脈保持の3点セットで実装しました。

### 3. 自律オペレーションコンソール「OMOCHA WORKS」

AI Fleet (Claude Code / Codex / Gemini) の稼働状況をリアルタイムで俯瞰できるダッシュボードを追加。

### 4. 証券評価額の月次履歴追跡 (#4295)

保有資産の評価額を月次スナップショット保存し、時系列グラフで可視化。「資本=時間」という哲学を数値で追跡します。

## 詰まったポイント

### Flutter lint との格闘

AIが生成したコードの`require_trailing_commas`違反でCIが落ちる問題が発生。`dart fix + dart format + deno fmt`を自動実行するワークフローで解決しました。

### LPのQAトラフィック混入

開発チーム自身のアクセスがコンバージョン率を汚染する問題をIPフィルタリングで解消。

## まとめ

AI駆動開発の核心は「測定の自動化」にあります。今後も AI Fleet × Flutter Web × Supabase で、ソロ開発者が大企業と競えるSaaS開発を追求します。
