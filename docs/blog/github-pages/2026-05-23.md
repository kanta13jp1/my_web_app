As an indie developer running "自分株式会社" (Jibun Inc.), I built a fully automated competitive intelligence system tracking 21 competitors — all without manual daily research.

This week hit a milestone: **Bolt.new** joined the watchlist, completing the **vibe coding "Big 4"**: Cursor / Replit / Lovable / Bolt.new.

## The Pipeline

Every day, GitHub Actions runs Claude Opus 4.7 to scan for signals from 21 competitors and commits a structured report to `docs/competitor-reports/`:

```
GHA cron (daily)
  → Claude Opus 4.7 (1M context)
  → docs/competitor-reports/YYYY-MM-DD.md
  → docs/competitor-reports/_competitors.json
  → git commit & push → Supabase log
```

Each report includes:
- Per-company signal digest (releases, pricing changes, strategy pivots)
- Impact scoring (🔴 high / 🟡 medium / 🟢 low)
- Strategic review agenda candidates

## Karpathy's Second Brain in Practice

I've fully integrated Andrej Karpathy's 4-cycle "second brain" framework into the dev workflow:

| Cycle | Script | Output |
|-------|--------|--------|
| **Ingest** | `scripts/memory_ingest.py` | Atomic notes → `memory/vault/` |
| **Compile** | `scripts/wiki_compile.py` | `docs/concepts/` + `docs/INDEX.md` |
| **Query** | `notebooklm` CLI | Zero-token research from past decisions |
| **Lint** | `scripts/knowledge_vault_lint.py` | Health score, orphan detection |

Weekly compile + daily lint run automatically via GHA cron.

## Tech Stack

- **Frontend**: Flutter Web
- **Backend**: Supabase (PostgreSQL + Edge Functions / Deno)
- **Hosting**: Firebase Hosting
- **CI/CD**: GitHub Actions (30+ workflows)
- **AI**: Claude Opus 4.7 + Prompt Caching (88% cost reduction)

## Key Lessons

1. **Design Claude-independent crons** — health checks and infra monitoring don't need AI; keep them running even during quota overages
2. **Quota fallback chain**: Claude → Gemini 1.5 Flash → Codex CLI → static template
3. **Competitor discovery rule**: 7 consecutive cycles as Plan A candidate #1 triggers adoption (how Bolt.new was added)
4. **Prompt Caching pays off**: ~88% cost reduction on Opus 4.7 for repetitive structured tasks
