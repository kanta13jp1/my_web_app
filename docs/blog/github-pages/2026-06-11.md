個人開発プロジェクト「自分株式会社」part 268〜271 の開発ログです。

Flutter Web + Supabase で構築した資産管理アプリに、今週は **マネーカレンダー**・**3段階表示モード**・**Human Approval Gate** などを追加しました。

本番 URL: [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)

## 主な変更点

### Part 268: 表示モード切替 + マネーカレンダー

`AssetDisplayMode.minimal / standard / full` の3段階で表示情報量を切替可能に。マネーカレンダーはFlutter `Table` で実装。

**落とし穴**: `ListView` 内の `Table` に `FlexColumnWidth` を使うと無限高さクラッシュが発生。`FractionColumnWidth(1/7)` に変更して解決（Part 268b）。

### Part 270b: 現金マイナス → 使途不明金自動記録

現金残高がマイナスになった際の減少分を自動的に「使途不明金」として登録。記録漏れを防ぎます。

### Part 270c: 同額更新の緩和

前回記録との差が1円未満の場合は「同額」更新として処理。毎月更新時のフラストレーションを解消。

### Part 271: 支払日警告からフォームへジャンプ

未入力警告の SnackBar に「入力する」アクションボタンを追加し、該当フォームへスクロール。

### SaaS Human Approval Gate

AI生成アクションの実行前に人間確認を挟むダイアログ。deny-by-default 原則の実装。

## まとめ

小さな改善の積み重ねがユーザー体験を確実に向上させます。次週はマネーカレンダーの収支予測機能を予定。
