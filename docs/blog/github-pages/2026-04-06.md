「自分株式会社」は、Notion・Evernote・MoneyForward・Slack・X など21の競合SaaSの機能を1つに統合することを目指すAIライフマネジメントアプリです。Flutter Web + Supabase で構築し、[https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/) で公開中です。

## 今回実装した3つの機能

### 1. 競合モニタリングカードに「今すぐチェック」ボタン追加

Claude Scheduleが自動実行する競合監視に加えて、UIから手動トリガーできるボタンを追加しました。

```dart
Future<void> _triggerCompetitorCheck() async {
  setState(() => _isChecking = true);
  try {
    final response = await supabase.functions.invoke(
      'check-competitor-updates',
      body: {'manual': true},
    );
    setState(() => _results = response.data);
  } finally {
    setState(() => _isChecking = false);
  }
}
```

### 2. バイラル共有カード強化

`share_plus` パッケージを使いリファラルリンクを1タップでSNS共有できるよう改善しました。async後の `BuildContext` 使用には `mounted` チェックを追加しています。

### 3. cs-check自己修復強化

Claude Scheduleが `public_gallery` Edge Functionのバグ（パラメータ読み取り優先順位の誤り）を自動検出・修正・コミットした実例を紹介します。

```typescript
// 修正後: bodyを優先
const body = await req.json().catch(() => ({}));
const sortBy = body.sortBy ?? url.searchParams.get('sortBy') ?? 'created_at';
```
