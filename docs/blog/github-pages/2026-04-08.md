## はじめに

「自分株式会社」はFlutter Web + Supabase Edge Functions (Deno) で構築したAI統合ライフマネジメントアプリです。機能拡充に伴い複数のEdge Functionで逐次クエリがボトルネックになっていたため、今週 `Promise.all` 並列化を一斉実施しました。

今回対象にしたEdge Functionと改善内容:

| Edge Function | Before | After |
|---|---|---|
| `blog-post-manager` | 14クエリ逐次 | Promise.all 1段 |
| `app-analytics-dashboard` | 9クエリ (3段) | Promise.all 1段 |
| `user-growth-analytics` | 3クエリ逐次 | Promise.all 1段 |
| `semantic-search` | 2クエリ逐次 | Promise.all 1段 |

## 基本パターン

```typescript
// Before: 逐次
const a = await supabase.from('table_a').select('*');
const b = await supabase.from('table_b').select('*');
const c = await supabase.from('table_c').select('*');

// After: 並列
const [a, b, c] = await Promise.all([
  supabase.from('table_a').select('*'),
  supabase.from('table_b').select('*'),
  supabase.from('table_c').select('*'),
]);
```

## 実例: user-growth-analytics

時刻境界を事前計算することで、全3クエリを依存なく並列起動できます。

```typescript
const now = new Date();
const todayStart = new Date(now.getFullYear(), now.getMonth(), now.getDate()).toISOString();
const weekStart = new Date(now.getTime() - 7 * 86400000).toISOString();

const [usersResult, signupResult, referralResult] = await Promise.all([
  supabase.auth.admin.listUsers(),
  supabase.from('signup_events').select('*').gte('created_at', todayStart),
  supabase.from('referral_events').select('*').gte('created_at', weekStart),
]);
```

## 実例: blog-post-manager (14クエリ)

11プラットフォーム別カウントを `map` で展開して `Promise.all` に渡します。

```typescript
const PLATFORMS = ['zenn','qiita','note','hatena','medium','devto',
                   'hashnode','substack','github-pages','notion','x-article'];
const todayStr = new Date().toISOString().slice(0, 10);

const [postsResult, ...rest] = await Promise.all([
  postsQuery,
  ...PLATFORMS.map(p =>
    supabase.from('blog_posts')
      .select('*', { count: 'exact', head: true })
      .contains('target_platforms', [p])
  ),
  supabase.from('blog_posts').select('*', { count: 'exact', head: true })
    .gte('created_at', todayStr),
]);
const platformCounts = rest.slice(0, PLATFORMS.length);
const todayCountResult = rest[PLATFORMS.length];
```

## まとめ

- 独立クエリは迷わず `Promise.all` 化する
- 時刻境界などの依存変数は事前計算してから並列起動
- `deno lint 0件` を維持するため、型が明確になった箇所は `?.` を外して明示的な nullish coalescing に統一
