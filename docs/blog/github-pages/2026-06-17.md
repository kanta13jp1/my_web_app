## はじめに

Flutter Webで作っている自分株式会社アプリ（[https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)）の資産管理ページで、家賃/KDDI/水道/ガスの固定費が約8箇所にハードコードされていました。

今週、この問題を根本から解決するデータ駆動モデルとUIを実装しました。

## 主な実装内容

### データモデル (PR #3452)

`AssetRecurringFixedCost` モデルを定義し、`AssetRecurringFixedCostStore` で Supabase の `asset_pref_mirror` に全量 upsert する端末間同期を実装しました。

### UIウィジェット (PR #3457)

- `RecurringFixedCostCard`: 一覧表示 + 追加/編集/削除
- `RecurringFixedCostEditorDialog`: 入力フォーム + バリデーション

ローカル優先・サーバーフォールバック方式でデータをロードします。

### キャッシュフロー予測 v2 (PR #3419)

- ホライゾン 3/6/12 ヶ月切替
- 安全証拠金ライン (¥10,000)
- カテゴリ別予算実績比較 (PR #3421)

## まとめ

「データ駆動 + ミラー同期」パターンにより、コード修正なしでビジネスロジックを変更できるようになりました。
