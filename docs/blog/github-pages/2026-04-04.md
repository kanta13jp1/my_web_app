## 全 Edge Function UI — 設計戦略

Supabase Edge Function は現在 15 本稼働。最後まで残っていた `growth-weekly-digest` と `check-competitor-updates` の UI を `admin_analytics_page.dart` に統合し、全 15 本の対応が完了しました。

```dart
Future<void> _loadWeeklyDigest() async {
  final resp = await supabase.functions.invoke('growth-weekly-digest');
  if (resp.status == 200) {
    setState(() => _weeklyDigest = resp.data as Map<String, dynamic>);
  }
}
```

## 開発実績カードの時系列ソート

```dart
final achievements = (data as List<dynamic>)
    .cast<Map<String, dynamic>>()
    .sorted((a, b) {
      final ta = DateTime.tryParse(a['completed_at'] ?? '') ?? DateTime(0);
      final tb = DateTime.tryParse(b['completed_at'] ?? '') ?? DateTime(0);
      return tb.compareTo(ta);
    });
```

## BuildContext 非同期問題

async 処理後の `context` 使用は `mounted` チェックで解決：

```dart
Future<void> _save() async {
  await supabase.from('goals').insert(data);
  if (!mounted) return;

}
```
