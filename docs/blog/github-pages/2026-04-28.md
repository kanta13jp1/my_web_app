## What is AI University?

AI University is a core feature — a comprehensive database of AI tools, frameworks, and providers worldwide, helping users understand "which AI to use and how."

```
Current count: 320 providers (+4 this week)
Added this week:
  - AutoGen (Microsoft): Multi-agent framework
  - DSPy (Stanford): Programmatic LLM pipelines
  - Haystack (deepset): RAG framework
  - CrewAI: Agent collaboration framework
```

Data is stored in Supabase PostgreSQL, with GitHub Actions running daily auto-updates.

---

## Data Design (Supabase)

```sql
INSERT INTO ai_providers (name, category, description, url, tags)
VALUES
  ('AutoGen', 'multi-agent', 'Microsoft multi-agent framework',
   'https://microsoft.github.io/autogen/', ARRAY['python', 'llm', 'agent']),
  ('DSPy', 'llm-pipeline', 'Stanford programmatic LLM pipeline',
   'https://dspy-docs.vercel.app/', ARRAY['python', 'optimization', 'rag'])
ON CONFLICT (name) DO UPDATE SET
  description = EXCLUDED.description,
  updated_at = now();
```
