個人開発アプリ「自分株式会社」に Payslip AI 機能を追加しました。給与明細（PDF）をアップロードするだけで可処分所得を自動計算し、AI が節約・支出改善のアクションを提案します。

## 実装概要

今回の PR #3008 では 3973行のコードを追加し、以下の3モジュールを実装しました。

### Payslip Ingestion (給与明細OCR解析)

Supabase Storage に PDF をアップロードすると、Deno の Edge Function が Claude AI に解析を依頼します。解析結果（総支給額・手取り・各種控除）を PostgreSQL テーブルに保存。信頼度スコアが低い場合は `needs_review` フラグを立てます。

### Expense AI (AI支出分類)

家計簿データを AI が自動分類。「固定費」「削減可能な変動費」「投資・自己研鑽」のラベリングで、支出の可視化を支援します。

### Disposable Balance Calculator (可処分所得計算)

給与明細 + 支出データを統合して「今月残り使える金額」と「1日あたり予算」をリアルタイム計算。AI がアクションプランを優先度順に提案します。

## 技術スタック

- **フロントエンド**: Flutter Web
- **バックエンド**: Supabase Edge Functions (Deno/TypeScript)
- **AI**: Claude API (via Edge Functions)
- **DB**: PostgreSQL (Supabase) with RLS
- **Storage**: Supabase Storage (payslips バケット)
- **ホスティング**: Firebase Hosting

## セキュリティ設計

給与情報の機密性を考慮し、RLS ポリシーを厳密に設計。Storage の payslips バケットも `auth.uid()` 単位でアクセス制御しています。
