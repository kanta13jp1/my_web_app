自社サービス「自分株式会社」(https://my-web-app-b67f4.web.app/) のバイラル動画広告生成機能で、AI音声生成の信頼性を大幅に改善しました。

## 問題: ElevenLabs 障害時に品質が低下する

Supabase Edge Function (Deno) で動くバイラル動画生成では、ElevenLabs → Hedra という流れで AI 音声・動画を生成しています。従来は ElevenLabs 失敗時のフォールバックが条件付きで、特定のエラー種別以外では品質の低い Hedra 内蔵 TTS に直行していました。

## 解決: 3段フォールバックと診断ログ

### フォールバック設計

1. **ElevenLabs** — メイン音声生成
2. **ElevenLabs フォールバック音声** — 条件付き
3. **OpenAI TTS** — ElevenLabs 失敗時の無条件フォールバック（今回追加）
4. **Hedra 内蔵 TTS** — 最終手段

### speech_chain 診断ログ

各プロバイダーの失敗理由を `speechChain` 配列に蓄積し、最終ログに1行で出力:

```
elevenlabs=quota_exceeded | fallback_voices=voice_not_found | openai_tts=OPENAI_API_KEY not configured
```

ダッシュボードを開かずに、レスポンスだけで音声フォールバックの全経緯が把握できます。
