## 競馬AI予想パイプライン

バックエンドは Deno Edge Function (tools-hub) に action パラメータで集約。Flutter UI は今日のレース / 予想履歴 / 的中率 の3タブ構成に刷新しました。

### ハマりポイント

| 問題 | 原因 | 解決策 |
|------|------|--------|
| GitHub Actions 401 エラー | action を auth ゾーンに誤配置 | NO_AUTH_ACTIONS に移動 |
| horse_results クエリタイムアウト | 全件一括 SELECT | Promise.all で個別クエリ並行化 |
| deploy-prod SQLSTATE 42P10 | UNIQUE 制約不足 | (provider, category) に制約追加 |
