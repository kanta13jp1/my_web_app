[自分株式会社](https://my-web-app-b67f4.web.app/) の週次開発ログ。今週は本番環境でしか再現しない2件のバグを修正した。

## Supabase Edge Function クエリタイムアウト修正

X投稿パフォーマンスレポートを生成する `growth-hub` Edge Function が本番で断続的にタイムアウトしていた問題。

`x_metric_snapshots` テーブルへのクエリで `batchSize=50` を使っており、最大50,000行スキャンが production timeout を超えていた。`batchSize=10` に削減し、週次レポート専用のコンテキスト関数 `buildXGrowthDataReportContext` に切り出すことで解決。

PostgREST の 1,000 行ページ上限はレスポンス制限であり DB スキャン量は制限しない点に注意が必要。

## Flutter UXデッドエンド解消

給料日未設定時に週次投稿トグルをオンにすると SnackBar でエラーを出して終了していた問題を修正。その場で給料日設定ダイアログを開いて設定後に処理を続行するフローに変更。

`async/await` を挟む場合は `if (!mounted) return;` を忘れずに。
