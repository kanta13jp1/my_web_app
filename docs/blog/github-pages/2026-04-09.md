自分株式会社（Flutter Web + Supabase）今週の開発記録です。

## 今週の主な実装

### 1. ダークテーマ完全対応 (160件・44ファイル)

ハードコードされた `Colors.grey[*]`・`Colors.white`・`Colors.black87` を
Material 3 の `colorScheme` トークンに一括置換しました。

置換マッピング:

- `Colors.grey[100]` → `colorScheme.surfaceContainerLow`
- `Colors.grey[200/300]` → `colorScheme.surfaceContainerHighest`
- `Colors.grey[400–600]` → `colorScheme.onSurfaceVariant`
- `Colors.grey[700/800]` → `colorScheme.onSurface`
- `Colors.black87` → `colorScheme.onSurface`
- `Colors.black54` → `colorScheme.onSurfaceVariant`

各バッチ後に `flutter analyze` を実行して 0 エラーを維持しながら進めました。

### 2. 画像ドラッグ&ドロップ (Notion風)

`package:web` の HTML drag/drop API を使い、メモエディタに画像をドロップできるようにしました。
条件付きインポートで Web 専用コードを分離し、モバイルでは stub を使うクロスプラットフォーム構成です。

### 3. コンソールエラー自動収集

`FlutterError.onError` + `PlatformDispatcher.instance.onError` をフックして
発生したエラーを Supabase Edge Function に自動送信する仕組みを追加しました。
