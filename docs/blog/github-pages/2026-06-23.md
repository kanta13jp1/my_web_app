## 今週の自分株式会社開発レポート (2026-06-23)

「自分株式会社」は自分自身の収支・資産・負債をSaaSのように管理するFlutter Webアプリです。
今週は **資産管理ページ（Asset Management）** のUX改善を中心に、Claude Opus 4.8との協働で機能追加・バグ修正・CI/CD最適化を進めました。

### 実装内容

**1. 収入¥0時CTA追加 (#3599)**
収支サマリーカードで当月収入が¥0の場合のみ「収入を記録する」ボタンを表示し、手入力収入導線を整備。タップで④収支カードへスクロールし種別を「収入」にプリセット。

**2. カード請求負債確認手順の改善 (#3617)**
`buildBaseGuide` に `billingCardName` パラメータを追加。カード統合負債はカード利用明細手順へ、直接引き落としは従来の銀行口座手順へと自動分岐。

**3. アコムショッピング枠バグ修正 (#3620)**
Anthropicサブスク費用¥40,000の分類誤りを修正。現金二重計上と期限超過誤アラートを解消。

**4. CI/CD最適化 (#3621)**
`cancel-in-progress: true` 導入により連続プッシュ時の不要なCIランをキャンセル。
