## はじめに

「自分を会社として経営する」というコンセプトで、Flutter Web + Supabase を使ったライフマネジメントアプリを開発しています。

Notion・Evernote・MoneyForward・Slack・X・Amazon など**21社の競合サービス**が提供する機能を1つに統合し、さらに**人間の思考・行動・意思決定を補助するAI機能**を組み込んでいます。

サービスURL: [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)

---

## 今週実装した機能

### 見栄ガード
「なぜそれをやるのか」を問いかけ、見栄・承認欲求が動機の場合はアラートを出す機能。

### 論理的意思決定ガード
感情的・衝動的な判断を検知してブロックするチェックリスト機能。

### MAGIシステム (NERV風3視点判断)
エヴァンゲリオンのMAGIシステムをインスパイアした、3視点でのAI判断補強機能。

### 浪費トラッキング
「投資か浪費か」を問いかけながら資産放出を記録・可視化。

### 思考キャプチャ
GTDの「収集」フェーズに特化。浮かんだ思考を0.5秒でキャプチャ。

### 人生目標管理 (ドリームツリー)
夢→大目標→中目標→小目標の4階層ツリー構造。

### コンビニ経営シミュレーション
経営判断力を鍛えるゲーム機能。

## Claude Code Scheduleによる完全自動化

| タスク | 頻度 | 内容 |
|---|---|---|
| cs-check | 毎時 | サポートチケット返信・バグ自動修正 |
| daily-report | 毎朝9時 | メトリクス取得・X自動投稿 |
| blog-draft | 毎日8時 | 技術ブログ下書き自動生成 |
| pr-auto-review | 3時間ごと | PRのセキュリティ・品質レビュー |

## 技術スタック

- **フロントエンド**: Flutter Web (Dart)
- **バックエンド**: Supabase (PostgreSQL + Edge Functions / Deno)
- **ホスティング**: Firebase Hosting
- **CI/CD**: GitHub Actions + Claude Code Schedule
- **AI**: Claude API (Anthropic)
