Flutter Web と Supabase の組み合わせで頻発する「匿名ユーザーによる不要な 401 エラー」を、16 ページ一括で修正した方法を紹介します。

## 問題

`initState()` で Supabase API を呼ぶと、未ログインユーザーが RLS によりブロックされ 401 が大量発生します。UX 上は問題ないように見えますが、デバッグの妨げになります。

## 解決策：Anonymous Auth Guard

```dart
Future<void> _loadData() async {
  final user = Supabase.instance.client.auth.currentUser;
  if (user == null) return; // 匿名ユーザーはスキップ
  
  // 認証済みユーザー向けの処理
}
```

## ポイント

- `mounted` チェックを非同期処理後に必ず行う
- RLS はセキュリティ層として引き続き維持する
- ユーザーアクションには SnackBar でフィードバックを提供する
