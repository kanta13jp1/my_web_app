個人開発の SaaS「自分株式会社」では、資産・負債管理機能に AI アシスタントを組み込んでいます。今週は AI へのプロンプトを大幅に強化し、「不明支出の自動トラッキング」と「AI Hub の maxTokens マルチプロバイダー対応」を実装しました。

アプリ URL: [https://my-web-app-b67f4.web.app/](https://my-web-app-b67f4.web.app/)

| レイヤー | 技術 |
|----------|------|

## 今週の主な実装

### 構造化プロンプトコンテキスト

`AssetManagementImplementationContext` を新設し、コードの文脈をプロンプトに埋め込みます。ファイルパス、サマリー、改善用途の説明を AI に渡すことで、単なる数値分析ではなく具体的な開発タスク提案が可能になります。

```dart
static const List<AssetManagementImplementationContext>
    defaultAssetManagementContexts = [
  AssetManagementImplementationContext(
    kind: 'source',
    title: '資産管理ページ UI と Issue 発行導線',
    path: 'lib/pages/asset_management_page.dart',
    summary: '資産/負債ボードを描画し、AssetManagementInsightReport を生成してAI要約、'
        'アクションアイテム、開発者向け改善提案、GitHub Issue化ボタンを表示する。',
    improvementUse: 'UI改善案では、画面上の表示粒度、Issue本文、重複判定キー、'
        'ユーザー操作の導線まで踏み込む。',
    excerpt: '...',
  ),
];
```

### AI Hub Edge Function の maxTokens 対応

Supabase Edge Function でプロバイダーごとのパラメーター名の差異を吸収します。

```typescript
// Google: generationConfig.maxOutputTokens
// OpenAI 互換: max_tokens
function applyProviderGenerationOptions(providerId, requestBody, options) {
  if (!options?.maxTokens) return requestBody;
  if (providerId === "google" || providerId === "google_flash_lite") {
    return { ...requestBody, generationConfig: { maxOutputTokens: options.maxTokens } };
  }
  return { ...requestBody, max_tokens: options.maxTokens };
}
```

### 不明支出の自動トラッキング

給与明細ベースの「使途明確支出」と「実際の残高減少」の差分を自動で不明支出として記録します。

## まとめ

Flutter Web + Supabase + Claude AI の組み合わせは個人開発 SaaS に非常に相性が良いです。特に Supabase Edge Functions を AI ファサードとして使うパターンは、プロバイダー切り替えをクライアント側に影響させない設計として有効です。
