個人開発で「自分株式会社」というFlutter Webアプリを作り続けています。メモ・タスク・成長記録を一元管理するパーソナルOS的なツールです。

今週は **「AIが読めるパブリックメモ」** と **「Xへの自動投稿品質を上げるアンチスロップ制約」** の2本柱を実装しました。

→ アプリ: <https://my-web-app-b67f4.web.app/>

## AIが読めるパブリックメモAPI

`format=json` または `format=txt` クエリパラメータを渡すことで、AI・ボット向けの構造化データを返すエンドポイントを追加しました。

```
GET /public-memo/{id}?format=json
→ { "title": "...", "body": "...", "tags": [...], "related": [...] }
```

`search` と `related` アクションも追加し、メモ同士の関連を自動探索できます。

## X投稿のアンチスロップ制約

AIが生成するX投稿に「〜ですね！」「素晴らしい〜」といった空虚な言葉が混入する問題を解決するため、以下の制約をプロンプトに組み込みました:

- Feature facts (具体的な機能名・数値を必ず含める)
- First-person (一人称で書く)
- Banned phrases (禁止フレーズの明示的除外)
- Poll subject-lock (Xポールのテーマ一致)
- Relevance gate (スレッドのトピック一貫性チェック)

## グロースハブ計測強化

ブックマーク数・プロフィールクリック数・URLクリック数を追加取得し、daily X briefing cron で毎朝レポートを自動生成するようにしました。

## 詰まったポイント

Edge FunctionでHTMLを組み立てる際の `&amp;` URL問題と、HEAD リクエストへの 405 レスポンス問題を修正しました。

## まとめ

今週は「AIが読める・AIが書く・AIが計測する」という3レイヤーが揃った週でした。Claude Code + Supabase Edge Functions の組み合わせで個人開発の自動化が進んでいます。
