# 衝動買いを撲滅する価格トラッカーをFlutter × Supabaseで無料で作った話

「この商品、もう少し安くなったら買おう」——そう思ってブラウザのブックマークに溜め込んでいる商品リストが、あなたのPCにもあるはずだ。

私が開発している**自分株式会社**（Flutter Web + Supabase の AI 統合ライフマネジメントアプリ）に価格トラッカー機能を追加した。

## 技術スタック

- **フロントエンド**: Flutter Web (Dart)
- **バックエンド**: Supabase (PostgreSQL + Deno Edge Functions)
- **DB設計**: RLS完備の `tracked_products` + `price_logs` テーブル
- **EF戦略**: 既存 `lifestyle-hub` への action 統合（50本制限維持）

## DBスキーマのポイント

```sql
CREATE TABLE tracked_products (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id uuid NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE,
  product_url text NOT NULL,
  current_price int,
  target_price int,
  highest_price int,
  lowest_price int,
  UNIQUE (user_id, product_url)
);
```

トリガーで `price_logs` INSERT 時に最安値・最高値を自動更新。

## Edge Function ハブパターン

```typescript
// lifestyle-hub に price.* を追加（新規EF不要）
case 'price.add':  return await handlePriceAdd(req, supabase);
case 'price.list': return await handlePriceList(req, supabase);
case 'price.log':  return await handlePriceLog(req, supabase);
```
