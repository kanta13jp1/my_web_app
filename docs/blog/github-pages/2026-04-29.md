## The PS#4 Batch Strategy

The PS#4 Claude Code instance handles competitor additions exclusively. Each commit adds exactly 9 companies:

```bash
feat(competitors): PS#4 S600-S602 競合9社追加 1618→1627社 (neo4j/amazon-neptune/...)
feat(competitors): PS#4 S603-S605 競合9社追加 1627→1636社 (kubeflow/seldon/...)
```

Why 9? It keeps each CI run under 4 minutes and each PR reviewable.

## memory-search-hub: Intelligent Task Routing

The new `memory-search-hub` Deno Edge Function estimates task complexity and routes to the appropriate Claude model:

```typescript
// S = claude-haiku-4-5    (< 2K tokens)
// M = claude-sonnet-4-6   (< 8K tokens)
// L = claude-sonnet-4-6   (< 32K tokens)
// XL = claude-opus-4-7    (100K tokens)
```

The `task_budget` component monitors context utilization and triggers compaction when usage exceeds 80%.

## Bug Fix: @TestOn('browser') Enforcement

CI started failing mid-week. Root cause: `@TestOn('browser')` had been accidentally removed from 9 test files. Fixed in a single commit:

