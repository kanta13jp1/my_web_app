Flutter Web + Supabase で AI統合アプリ「自分株式会社」を開発しています。

## ダークテーマ完全対応 — colorScheme トークン 160件置換

長期開発で蓄積した `Colors.grey[*]`・`Colors.white`・`Colors.black87` を
Material 3 の colorScheme トークンに一括置換しました。

### 置換マッピング

| Before | After |
| --- | --- |
| `Colors.grey[100]` | `colorScheme.surfaceContainerLow` |
| `Colors.grey[200/300]` | `colorScheme.surfaceContainerHighest` |
| `Colors.grey[400/500/600]` | `colorScheme.onSurfaceVariant` |
| `Colors.grey[700/800]` | `colorScheme.onSurface` |
| `Colors.white` (背景) | `colorScheme.surfaceContainerLow` |
| `Colors.black87` | `colorScheme.onSurface` |
| `Colors.black54` | `colorScheme.onSurfaceVariant` |
| `Colors.black12` | `colorScheme.outlineVariant` |

```dart
// 修正前
Container(
  color: Colors.grey[200],
  child: Text('label', style: TextStyle(color: Colors.black87)),
)

// 修正後
final cs = Theme.of(context).colorScheme;
Container(
  color: cs.surfaceContainerHighest,
  child: Text('label', style: TextStyle(color: cs.onSurface)),
)
```

160件を段階的にバッチ処理し、各バッチ後に `flutter analyze` で 0 エラーを確認。
44ファイルに渡る変更でも、ルールが明確なので機械的に進められました。

## Notion風 画像ドラッグ&ドロップ

`package:web` の HTML drag/drop API でブラウザネイティブのドロップを受け取ります。

```dart
// lib/utils/note_image_drop_web.dart
el.addEventListener('drop', (web.Event e) {
  final drag = e as web.DragEvent;
  drag.preventDefault();
  final file = drag.dataTransfer?.files?.item(0);
  if (file != null && file.type.startsWith('image/')) {
    final reader = web.FileReader();
    reader.readAsArrayBuffer(file);
    reader.onload = (_) {
      final bytes = Uint8List.view(
        (reader.result as web.ArrayBuffer).toDart,
      );
      widget.onDrop(bytes);
    } as web.EventHandler;
  }
});
```

条件付きインポートで Web/Stub を切り替えることでクロスプラットフォーム対応:

```dart
export 'note_image_drop_stub.dart'
    if (dart.library.html) 'note_image_drop_web.dart';
```

## コンソールエラー自動収集

`FlutterError.onError` と `PlatformDispatcher.instance.onError` をフックして
Supabase Edge Function にエラーを送信します。
重複防止・最大10件/セッション・再帰ループ防止を実装済みです。

```dart
static void install() {
  final prev = FlutterError.onError;
  FlutterError.onError = (details) {
    prev?.call(details);
    report(details.exceptionAsString(), details.stack?.toString());
  };
  PlatformDispatcher.instance.onError = (error, stack) {
    report(error.toString(), stack.toString());
    return false;
  };
}
```

## まとめ

- ハードコードカラー → colorScheme トークンのマッピングルールを決めれば一括置換可能
