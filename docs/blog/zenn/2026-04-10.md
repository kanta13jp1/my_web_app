「コードを書くだけで手一杯で、技術ブログを書く時間がない」。これはほぼすべての個人開発者が抱える悩みです。

私が開発している **自分株式会社**（https://my-web-app-b67f4.web.app/）は、Notion・Evernote・MoneyForward・Slack など21競合を1つに統合する Flutter Web + Supabase のAIライフマネジメントアプリです。今週、「技術ブログ自動生成・自動クロスポスト」システムを実装し、Qiita と dev.to への初投稿に成功しました。

## 全体アーキテクチャ

```
Claude Code Schedule (毎日 08:00 JST)
  ↓ git log で直近7日のコミット確認
  ↓ AI がブログ下書きを生成 → docs/blog-drafts/YYYY-MM-DD.md
  ↓ Zenn / GitHub Pages / クロスポスト版も同時生成
  ↓
Supabase REST API → blog_posts テーブルに draft 登録
  ↓
blog-auto-publisher Edge Function (Deno)
  ↓ Qiita API → 投稿
  ↓ dev.to API → 投稿
  ↓ status = "posted" に自動更新
```

## Qiita API 投稿実装

```typescript
async function publishToQiita(title, body, tags) {
  const res = await fetch("https://qiita.com/api/v2/items", {
    method: "POST",
    headers: {
      "Authorization": `Bearer ${QIITA_ACCESS_TOKEN}`,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({
      title,
      body,
      // Qiita: 最大5タグ、各20文字以内
      tags: tags.slice(0, 5).map(t => ({ name: t.slice(0, 20) })),
      private: false,
    }),
  });
  return { url: (await res.json()).url };
}
```

## dev.to API 投稿実装

```typescript
async function publishToDevto(title, body, tags) {
  const res = await fetch("https://dev.to/api/articles", {
    method: "POST",
    headers: { "api-key": DEVTO_API_KEY, "Content-Type": "application/json" },
    body: JSON.stringify({
      article: {
        title,
        body_markdown: body,
        tags: tags.slice(0, 4),  // dev.to: 最大4タグ
        published: true,
      },
    }),
  });
  return { url: (await res.json()).url };
}
```

## auto_publish で一括投稿

```typescript
case "auto_publish": {
  const results = {};
  for (const platform of post.target_platforms ?? []) {
    try {
      if (platform === "qiita") results.qiita = await publishToQiita(...);
      if (platform === "devto") results.devto = await publishToDevto(...);
    } catch (e) {
      results[platform] = { error: e.message };
    }
  }
  const anySuccess = Object.values(results).some(r => !r.error);
  if (anySuccess) {
    await supabase.from("blog_posts")
      .update({ status: "posted", posted_at: new Date().toISOString() })
      .eq("id", id);
  }
  return json({ results });
}
```

## 詰まったポイント

**Qiita のタグ制約**: 最大5タグ・各20文字以内 → `slice()` で対応。

**blog_posts テーブルのスキーマ差異**: CLAUDE.md に記載の `content_preview` カラムが実テーブルに存在しなかったためマイグレーション追加。

**GITHUB_TOKEN はブランチ保護をバイパスできない**: CI から直接 push する場合は保護のないブランチのみに限定する方針に変更。
