## はじめに

「自分株式会社」——個人開発者が、Notion・Evernote・MoneyForward・Slack・Amazonなど**21競合の機能を1つのアプリに統合する**プロジェクトです。

今週、競合比較データベースが**1816社**を突破しました。先週末の1555社から7日間で**+261社**を達成できた背景を共有します。

今週のもう一つの大きな成果は、**memory-search-hub Edge Function** のフル実装です。AIタスクルーティングエンジン（effort_router / task_budget）をSupabase Deno Edge Functionとして実装しました。

## PS#4バッチ追加戦略 — 9社ずつの意味

競合データ追加はPS#4インスタンスが専任で担当しています。1回のコミットで9社を追加するのには理由があります。

- **git commit size**: 9社 = 1PRの適切なサイズ
- **CI時間**: 9社追加 → sitemap更新 → flutter analyze → deploy で約4分
- **レビュー可能性**: 9社ならコードレビューが現実的

```bash
feat(competitors): PS#4 S600-S602 競合9社追加 1618→1627社
feat(competitors): PS#4 S603-S605 競合9社追加 1627→1636社
feat(competitors): PS#4 S606-S608 競合9社追加 1636→1645社
```

## memory-search-hub: AIルーティングエンジン

### 設計思想

effort_router でタスクの複雑度を推定し、最適なモデルに振り分けます。

```typescript
// supabase/functions/memory-search-hub/index.ts
interface TaskEffortEstimate {
  level: 'S' | 'M' | 'L' | 'XL';
  estimated_tokens: number;
  recommended_model: string;
}

async function effortRouter(task: string): Promise<TaskEffortEstimate> {
  const complexity = await analyzeComplexity(task);
  
  if (complexity.score < 0.3) {
    return { level: 'S', estimated_tokens: 2000, recommended_model: 'claude-haiku-4-5' };
  } else if (complexity.score < 0.6) {
    return { level: 'M', estimated_tokens: 8000, recommended_model: 'claude-sonnet-4-6' };
  } else {
    return { level: 'XL', estimated_tokens: 100000, recommended_model: 'claude-opus-4-7' };
  }
}
```

### タスクバジェット管理

```typescript
async function taskBudget(sessionId: string): Promise<BudgetStatus> {
  const usage = await getSessionUsage(sessionId);
  const limit = getModelLimit(usage.current_model);
  
  return {
    used: usage.tokens,
    remaining: limit - usage.tokens,
    utilization_pct: (usage.tokens / limit) * 100,
    should_compact: usage.tokens > limit * 0.8,
  };
}
```

## 詰まったポイント

### CI の `@TestOn('browser')` 問題

今週、CIが突然テストを落とし始めました。9ファイルから `@TestOn('browser')` が消えていたことが原因でした。

```dart
// 修正後: ブラウザテストを正しくアノテーション
@TestOn('browser')
void main() { ... }
```

`fix(ci): restore VM test enforcement — @TestOn('browser') on 9 files` として1コミットで修正しました。

### 1800社規模でのFlutter Web パフォーマンス

1800社のデータを一度にレンダリングするとフリーズします。対策:

- **遅延ロード**: スクロール位置に応じてバッチロード
- **検索フィルタリング**: クライアントサイドで高速絞り込み
- **仮想リスト**: 画面外をDOMから除去
