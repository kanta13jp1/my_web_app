## はじめに

Flutter Web + Supabase で「自分株式会社」という個人向け資産・時間管理 SaaS を開発しています。本番 URL は https://my-web-app-b67f4.web.app/ です。

「AI をフル活用してインディー開発者が大企業と戦えるか」という実験として、今週の主な変化を build in public として共有します。

---

## 2インスタンス AI フリートへの最適化

以前は Claude Code 10 + Codex 2 という大規模フリートで運用していましたが、**Claude Code #1 + Codex #1 の 2インスタンス体制** に整理しました。

| インスタンス | 担当 |
|---|---|
| Claude Code #1 | 問題定義・アーキテクチャ・レビュー・Hook 設計 |
| Codex #1 | 実装・SQL・Edge Functions・GHA・UI QA |

役割を明確化することで、コンテキストの混濁を防ぎつつ並列作業の効率を最大化しています。

シグナルは `hooks` `codex-runtime` `integration` `quality-cost` `schedule` の 5 グループに分類され、対応 Issue / Hook / GHA ワークフローにマッピングされます。

## 競合21社監視 + xAI Grok Build の追加

今週 **xAI Grok Build** を 21 社目の競合として追加しました。脅威度: 🔴 High。

```json
{
  "name": "xAI Grok Build",
  "category": "AI Coding Assistant",
  "threat_level": "high",
  "discovered_at": "2026-06-02"
}
```

毎朝 GHA cron が各競合の HTTP ステータスと変化を記録し、AI 分析レポートを自動生成します。API キー未設定時は static-template モードにフォールバックし、CI は必ず成功します。

---

## Claude Code Hooks によるセッション自動化

`SessionStart` hook で毎セッション自動注入:

```
[INSTANCE] WEB版
[INSTANCE-ROLES] Architecture / Review-gate / Cross-instance coordination
[PHILOSOPHY-22] CEO感 / ミッション / mentor ...
```

30+ のワークフローと 5 つの daily cron は Claude 非依存設計で、quota 超過時も継続動作します。
