Flutter プロジェクトの「マジックナンバー色」問題を Claude Code で一括解決した話です。

## 課題

`docs/DESIGN.md` でブランドカラーを定義しているのに、コードには `Colors.blue`、`Colors.grey`、`Colors.orangeAccent` が 200 ファイル以上に散在していました。

```
Primary:   #5C6BC0 (Indigo 400)
Secondary: #FF7043 (Deep Orange 400)
Surface:   #1A1A2E (Dark Navy)
```

## 移行マッピング

| Flutter Color | DESIGN token hex |
|---|---|
| `Colors.blue` / `Colors.lightBlue` | `0xFF5C6BC0` |
| `Colors.orangeAccent` | `0xFFFF7043` |
| `Colors.yellow` | `0xFFFFD54F` |
| `Colors.grey` | `0xFFB0B0B0` |

## Claude Code への指示

```
lib/ 配下の全 .dart ファイルを対象に DESIGN.md のトークンに従って
Colors.blue → Color(0xFF5C6BC0) など一括置換してください。
import 文・コメント・文字列リテラルは除外。
各ファイル後に flutter analyze を確認。
```

Claude Code は Grep でファイル列挙 → Edit で 118 ファイルを順次書き換え。

## 難所: shade 参照

`Colors.grey.shade400` は単純置換が効かないため、Claude Code が shade 値ごとに hex を判断:

```dart
// Before
color: Colors.grey.shade400,

// After
color: const Color(0xFFBDBDBD),
```

## ハマったポイント

1. **`Color(0xFF...).shade200` コンパイルエラー** — `Color` クラスには `.shade` がない。`flutter analyze` で即検知。
2. **pdf パッケージの PdfColors** — import を確認してから置換するルールが必要。
3. **trailing comma lint エラーが 36 件** — バッチ処理後に `dart fix --apply` で一括修正。

## 結果

| 指標 | Before | After |
|---|---|---|
| Off-brand Colors.* | 200+ 箇所 | 0 箇所 |
| DESIGN token 準拠率 | ~40% | ~100% |
| 推定手動工数 | 8〜12 時間 | 約 2 時間 |

## まとめ

- 段階的バッチ処理 → フェーズ間で `flutter analyze` を確認
- shade 参照は個別処理
- 最後に `dart fix --apply` で lint 一括修正
