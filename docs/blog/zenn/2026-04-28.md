## AI大学とは何か

AI大学は「自分株式会社」の中核機能です。世界中のAIツール・フレームワーク・プロバイダーを網羅したデータベースで、「どのAIをどう使うべきか」を学べるプラットフォームです。

```
現在の収録数: 320社 (前週比 +4社)
今週追加:
  - AutoGen (Microsoft): マルチエージェントフレームワーク
  - DSPy (Stanford): プログラマティックLLMパイプライン
  - Haystack (deepset): 検索拡張生成(RAG)フレームワーク
  - CrewAI: エージェント協調フレームワーク
```

データはSupabase PostgreSQLに蓄積され、GitHub Actionsが毎日自動更新します。

## データ設計 (Supabase)

```sql
INSERT INTO ai_providers (name, category, description, url, tags)
VALUES
  ('AutoGen', 'multi-agent', 'Microsoftのマルチエージェントフレームワーク',
   'https://microsoft.github.io/autogen/', ARRAY['python', 'llm', 'agent']),
  ('DSPy', 'llm-pipeline', 'StanfordのプログラマティックLLMパイプライン',
   'https://dspy-docs.vercel.app/', ARRAY['python', 'optimization', 'rag'])
ON CONFLICT (name) DO UPDATE SET
  description = EXCLUDED.description,
  updated_at = now();
```

追加ルールはドキュメントで明確化しており、**AI大学 provider 追加は Codex#1 専任**としています。

## Flutter Web フロントエンド

競合240社の比較ページは `comparison_page.dart` でレンダリング。今週は重複マップキー8件を修正しました。

```dart
// Dart の Map は重複キーを静かに上書きする → collision patrol で定期スキャン
final Map<String, CompetitorData> competitors = {
  'notion': CompetitorData(name: 'Notion', ...),
  // 重複キーがあると equal_keys CI が検出
};
```

`dart analyze` と CI (`equal_keys` ルール) で自動検出できる設計になっています。

## 詰まったポイント

### Comparison Pageのスケール問題

240社のデータを Flutter の `Map` で管理すると、重複キーが静かに上書きされます。`collision patrol` スクリプトで定期スキャンして解消しています。

### AI大学の更新頻度とトークン消費

GHA スケジュールタスクを **Claude Code 非依存設計** にすることで、quota 超過時も自動更新が継続します。

```yaml
schedule:
  - cron: '0 9 * * *'  # 毎日 JST 18:00
```
