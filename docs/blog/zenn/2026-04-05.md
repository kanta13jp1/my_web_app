## 1. TableCalendarによる月次カレンダービュー

Notionの機能ギャップ分析（現在カバー率94%）の中で「カレンダービュー」は長期ロードマップでしたが、既存の `calendar-events` Edge Functionと `table_calendar: ^3.1.2` パッケージが揃っていたため今日実装しました。

### O(1)イベントマッピング

```dart
final Map<String, List<Map<String, dynamic>>> _eventsByDate = {};

static String _dateKey(DateTime d) =>
    '${d.year}-${d.month.toString().padLeft(2, '0')}-${d.day.toString().padLeft(2, '0')}';
```

`TableCalendar` の `eventLoader` は `DateTime day` を受け取るため、`YYYY-MM-DD` 文字列をキーにしたMapに変換。O(1) で日付別イベントを取得できます。

### ページ変更時の遅延フェッチ

```dart
onPageChanged: (focusedDay) {
  _focusedDay = focusedDay;
  _fetchMonth(focusedDay);
},
```

ページスワイプ時のみ対象月データをフェッチ。既取得月は `_eventsByDate` に蓄積するため、戻ったときの再取得を回避。

### カラーピッカー（外部パッケージなし）

```dart
Wrap(
  spacing: 8,
  children: colors.map((c) => GestureDetector(
    onTap: () => setDialogState(() => selectedColor = c),
    child: Container(
      width: 28, height: 28,

```

5色のカラーピッカーを `flutter_colorpicker` などを使わず自前実装。依存を増やさない方針です。

## 2. ギタースタジオ — リアルタイムメーター + 録音共有

### Web Audio API でリアルタイムレベルメーター

```dart
_timer = Timer.periodic(const Duration(milliseconds: 16), (_) {
  if (!mounted) return;
  setState(() => _audioLevel = _analyser.getLevel());
});
```

`mounted` チェックは `async gap` 後の `BuildContext` 使用に必須。`flutter analyze` の `use_build_context_synchronously` ルールが検出します。

### share_plus で録音URLをシェア

```dart
import 'package:share_plus/share_plus.dart';
// cross_file は share_plus が再エクスポートするため直接importは不要

await SharePlus.instance.share(
  ShareParams(
    text: '自分のギター録音を聴いてください！\n$publicUrl',
    subject: recording['title'] ?? '録音',
  ),
);
```

:::message
`cross_file` を直接インポートすると `unnecessary_import` エラー。`share_plus` が内部で再エクスポートしています。
:::

## 3. 管理者ユーザープロフィール編集 + PATCH API

### Edge Function の拡張

```typescript
case "PATCH":
  const { user_id, display_name, avatar_url } = await req.json();
  const { error } = await adminClient
    .from("profiles")
    .update({ display_name, avatar_url, updated_at: new Date().toISOString() })
    .eq("id", user_id);
  if (error) return jsonError(error.message, 400);
  return jsonSuccess({ message: "updated" });
```

## 4. QUOTA GUARD — Edge Function上限の自動監視

Supabase Freeプランのデプロイ上限は94。Claude Code Scheduleによる自動CSチェック（毎時実行）に QUOTA GUARD を追加しました。

:::message alert
デプロイ数が 94 に達している場合は新規 Edge Function の追加を禁止。既存 Function へのアクション追加のみ許可。
:::

この制約が「ギャラリー機能を既存Functionのアクション追加で実装する」という設計判断を生みました。
