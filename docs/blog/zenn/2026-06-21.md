## はじめに

今回はその中でも特に反響が大きかった **給料振込の自動検知** と **AI駆動の負債管理機能** 、そして開発効率を高めた **タイムアウト対策とデバウンス最適化** について、実装の詳細を共有します。

## 実装詳細

### 1. 給料振込の自動検知 + 想定給料額の登録 (PR #3600)

給料日に入金があると、アプリが自動でそれを検知し「これは給料ですか？」と確認を促します。今週追加したのは、**想定給料額の事前登録UI**です。

```dart
class ExpectedSalaryDialog extends StatelessWidget {
  final TextEditingController _amountController = TextEditingController();

  @override
  Widget build(BuildContext context) {
    return AlertDialog(
      title: const Text('想定給料額を登録'),
      content: TextField(
        controller: _amountController,
        keyboardType: TextInputType.number,
        decoration: const InputDecoration(
          labelText: '毎月の手取り額 (円)',
          hintText: '例: 280000',
        ),
      ),
      actions: [
        TextButton(onPressed: () => Navigator.pop(context), child: const Text('キャンセル')),
        ElevatedButton(
          onPressed: () => _save(context),
          child: const Text('登録'),
        ),
      ],
    );
  }
}
```

Supabase の `salary_settings` テーブルに保存し、振込検知時に **実際の入金額と想定額を比較して乖離を通知** します。

### 2. 定期固定費を給料日サイクル順にソート (PR #3598)

固定費一覧を「給料日からN日後」でソートするオプションを追加しました。月末締め・翌月払いのクレジットカードと、給料日当日引き落としの家賃が混在しても、キャッシュフローの流れが一目でわかります。

```dart
expenses.sort((a, b) {
  final aDaysFromSalary = _daysFromSalaryDay(a.billingDay, salaryDay);
  final bDaysFromSalary = _daysFromSalaryDay(b.billingDay, salaryDay);
  return aDaysFromSalary.compareTo(bDaysFromSalary);
});

int _daysFromSalaryDay(int billingDay, int salaryDay) {
  final diff = billingDay - salaryDay;
  return diff >= 0 ? diff : diff + 30;
}
```

:::message alert
月を跨ぐ引き落としは `+30日` で処理しています。2月や月末日の扱いは今後改善予定。
:::

### 3. 負債に「手順を確認」ボタン — AI が引き落とし確認手順を提示 (PR #3571)

Supabase Edge Function 経由で Claude API を呼び出し、**その負債の引き落とし確認手順をステップバイステップで説明** します。

```typescript
// supabase/functions/debt-procedure-guide/index.ts
Deno.serve(async (req) => {
  const { debtName, bankName, amount } = await req.json();

  const response = await anthropic.messages.create({
    model: 'claude-sonnet-4-6',
    max_tokens: 500,
    messages: [{
      role: 'user',
      content: `${bankName}の${debtName}(残債: ${amount}円)について、
引き落とし日の前日までに確認すべき残高確認手順を
3〜5ステップで日本語で説明してください。`
    }],
  });

  return Response.json({ guide: response.content[0].text });
});
```

### 4. AI-hub の 502 対策: タイムアウト横展開 (PR #3576, #3586, #3597)

複数の AI プロバイダを束ねる `ai-hub` Edge Function で、遅延プロバイダが 502 エラーを引き起こす問題を修正。全フェッチに 15 秒タイムアウトを横展開しました。

```typescript
const fetchWithTimeout = (url: string, options: RequestInit, ms = 15000) => {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), ms);
  return fetch(url, { ...options, signal: controller.signal })
    .finally(() => clearTimeout(timer));
};
```

### 5. デバウンス最適化: Supabase Function 呼び出しを60%削減 (PR #3587, #3591)

デバウンス窓を **700ms → 2500ms** に拡大し、資産管理画面初期化時の重複リクエストを大幅に抑制。Function 実行コストが約60%削減されました。
