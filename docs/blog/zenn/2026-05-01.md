# 12AIエージェント並列開発: AI大学4層UI・Build in Public自動化・AI第二の脳を1週間で実装した記録

## はじめに

「自分株式会社」という個人開発のライフマネジメントアプリを Flutter Web + Supabase で開発しています。Notion・Evernote・MoneyForward・Slack など21の競合サービスの機能を1つに統合するプロダクトです。

今週達成した主なマイルストーン:

- **AI大学 4層ドリルダウンUI** の実装 (学部→学科→科目→講師)
- **Build in Public 週次自動化** クーロン完全稼働
- **AI第二の脳 Ingest pipeline** 実装
- **テーマ切り替えUI Phase 2** — 10種カタログ

これを実現した開発体制が、**Claude Code・Codex・Gemini・Copilot による12インスタンス並列稼働**です。

## 実装内容

### AI大学 — 4層ドリルダウンUI

AIプロバイダーの学習コンテンツを体系化する「AI大学」機能のUI刷新を行いました。

```
学部一覧 → 学科選択 → 科目一覧 → 講師・教材詳細
```

GoRouter で各層を独立ページとして設計し、Supabase RLS で閲覧権限を制御。`ai-university-update` Edge Function が毎日コンテンツを自動更新します。

```dart
GoRoute(
  path: '/ai-university/:facultyId/departments',
  builder: (context, state) => AiUniversityDepartmentPage(
    facultyId: state.pathParameters['facultyId']!,
  ),
),
```

### Build in Public 完全自動化

週次クーロン (GitHub Actions) が開発実績を自動集計し、Supabase の `development_achievements` テーブルから X (Twitter) へ自動投稿。手動SNS更新がゼロになりました。

### AI第二の脳 Ingest Pipeline

3層メモリシステムを構築:

| 層 | ツール | 用途 |
|---|---|---|
| L1 | claude-mem (SQLite) | セッション内の全操作記録 |
| L2 | auto-capture hooks | セッション間のgit履歴共有 |
| L3 | NotebookLM Master Brain | 長期アーキテクチャ知識 |

## 詰まったポイント

### マイグレーションのタイムスタンプ衝突

12インスタンス並列環境では `supabase/migrations/` のタイムスタンプが頻繁に衝突しました。解決策: 各インスタンスに帯域を割り当て。

```
VSCode版: YYYYMMDD01xxxx
PowerShell版: YYYYMMDD02xxxx
Codex#1: YYYYMMDD03xxxx
```

### CI race condition 修正

```yaml
# push前にrebaseで同期
- run: |
    git pull --rebase origin main
    git push origin HEAD
```
