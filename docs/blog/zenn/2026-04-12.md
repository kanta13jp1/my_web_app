自分株式会社（`https://my-web-app-b67f4.web.app/`）の開発記録です。今週は **競馬AI自動予想パイプライン**のFlutter UI全面刷新と、**AI大学プロバイダー40社突破**という2つのマイルストーンを達成しました。

## 競馬AI予想パイプライン — 全体設計

```
[JRA データ取得] → tools-hub EF: horseracing.today
        ↓
[AI予想生成]    → tools-hub EF: horseracing.predict_all
        ↓
[予想保存]      → Supabase: horse_results テーブル
        ↓
[Flutter UI]    → horse_racing_predictor_page.dart (3タブ)
```

バックエンドは Deno Edge Function の **tools-hub** に `action` パラメータでまとめています。EF 総数を50本以下に維持するハードキャップルールのもと、新機能は既存ハブへの action 追加で対応しています。

```typescript
switch (action) {
  case 'horseracing.today':       return await getHorseRacingToday(supabase);
  case 'horseracing.predict_all': return await predictAllRaces(supabase, body);
  case 'horseracing.predictions': return await getPredictions(supabase, body);
  case 'horseracing.accuracy':    return await getAccuracyStats(supabase);
}
```

## ハマりポイント3選

### 1. GitHub Actions からの 401 エラー

スケジューラ呼び出し用のアクションを誤って `auth` ゾーンに配置していたため 401 が発生。`NO_AUTH_ACTIONS` リストに移動して解消。

### 2. horse_results 一括クエリのタイムアウト

```typescript
// Before: 全件一括 → タイムアウト
// After: 個別クエリを Promise.all で並行実行
const results = await Promise.all(
  raceIds.map(id =>
    supabase.from('horse_results').select('*').eq('race_id', id)
  )
);
```

### 3. deploy-prod SQLSTATE 42P10

`ai_university_content` テーブルの UPSERT で一意制約不足エラー。
`(provider, category)` に `UNIQUE` 制約を追加して解消。

```sql
ALTER TABLE ai_university_content
  ADD CONSTRAINT ai_university_content_provider_category_key
  UNIQUE (provider, category);
```
