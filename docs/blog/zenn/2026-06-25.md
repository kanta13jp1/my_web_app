## AI使用量ゲートの設計思想

Supabase Edge Functions (Deno) の `ai-hub` 関数内に `usage_gate.ts` として**純粋関数**でロジックを切り出しました。

```typescript
// supabase/functions/ai-hub/usage_gate.ts

export type UsagePlan = "free" | "pro";

export interface UsageGateResult {
  allowed: boolean;
  reason?: string;
  remaining?: number;
}

export async function decideUsage(
  userId: string,
  plan: UsagePlan,
  currentMonthCount: number
): Promise<UsageGateResult> {
  if (plan === "pro") {
    return { allowed: true };
  }

  const FREE_LIMIT = 30;
  if (currentMonthCount >= FREE_LIMIT) {
    return {
      allowed: false,
      reason: "月間無料AI利用回数(30回)に達しました。Proプランへアップグレードしてください。",
      remaining: 0,
    };
  }

  return { allowed: true, remaining: FREE_LIMIT - currentMonthCount };
}
```

### フェイルオープン設計

DBエラー等でゲート判定が落ちた場合は `allowed: true` で通します。課金ロジックは収益に直結するため、バグによる機会損失より「通しすぎ」の方が安全という判断です。

### Deno テストで9件 green

純粋関数として切り出したことで、テストが書きやすくなりました。

```typescript
Deno.test("free user under limit → allowed", async () => {
  const result = await decideUsage("user_1", "free", 20);
  assertEquals(result.allowed, true);
  assertEquals(result.remaining, 10);
});

Deno.test("free user at limit → denied", async () => {
  const result = await decideUsage("user_1", "free", 30);
  assertEquals(result.allowed, false);
});

Deno.test("pro user over free limit → allowed", async () => {
  const result = await decideUsage("user_1", "pro", 100);
  assertEquals(result.allowed, true);
});
```

## Stripe env値の `.trim()` 防衛

```typescript
const stripeKey = Deno.env.get("STRIPE_SECRET_KEY")?.trim() ?? "";
const priceId = Deno.env.get("STRIPE_PRICE_ID_PRO")?.trim() ?? "";
```

Supabase ダッシュボードからコピペすると末尾に空白が混入することがあります。`No such price` エラーの温床なので `.trim()` を必ず付けましょう。

## 資産管理ページの毎秒再ビルド問題

`Timer.periodic(Duration(seconds: 1), ...)` が `setState` を呼ぶことでページ全体の再ビルドが毎秒発生していました。

日付(M/d)しか表示しないので、**日付が変わった時だけ再描画**する実装に変更しました。

```dart
Timer.periodic(const Duration(seconds: 1), (timer) {
  final newNow = DateTime.now();
  _maybeDetectSalaryDeposit(newNow); // 毎tick評価

  // UIの再描画は日付変更時のみ
  if (newNow.day != _now.day || newNow.month != _now.month) {
    setState(() => _now = newNow);
  } else {
    _now = newNow; // setState不要
  }
});
```
