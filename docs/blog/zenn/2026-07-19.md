## はじめに

ここ1週間、「自分株式会社」こと私の個人プロジェクト https://my-web-app-b67f4.web.app/ で、個人資産管理モジュールの開発を集中的に進めた。

「自分株式会社」とは、自分の人生を一つの会社として捉えるコンセプトのもと、時間・資産・タスク・目標を一元管理するFlutter Webアプリ。Supabase（PostgreSQL + Edge Functions）をバックエンドに、Firebase Hostingで配信している。

今週実装した主な機能：

- **純資産パネル** ── 前月比±¥/±% + 直近6ヶ月スパークライン
- **月次キャッシュフローパネル** ── 月収・月支出・累積キャッシュフロー
- **統合アラートパネル** ── 異常検知 + リマインダーを1箇所に集約
- **負債マスタ ドル建て入力** ── 為替自動換算（JPY/USD）
- **資金繰り盲点修正** ── 引落元種別フィルタの欠落バグ
- **Google Fonts廃止** ── LCP改善のためのランタイム読み込み排除

## 実装詳細

### 純資産パネル

純資産 = 総資産 − 総負債 をリアルタイムで可視化。前月比の絶対値・相対値と6ヶ月スパークラインを表示する。

集計ロジックはSupabase側のPostgreSQL Viewに寄せ、Flutterはシンプルに値を受け取るだけにした。

```dart
final netWorthHistory = await supabase
  .from('monthly_net_worth_summary')
  .select('month, net_worth')
  .order('month', ascending: true)
  .limit(6);
```

### 月次キャッシュフローパネル

収入予定が未登録の場合は過大に厳しい数字が表示されてしまう問題があった。ユーザーに正直に告知するカードを表示するよう修正した。

```dart
if (expectedIncome == null || expectedIncome == 0) {
  return CashflowWarningCard(
    message: '収入予定が未登録のため、資金繰りの数字が実態より厳しく表示されています',
  );
}
```

### 負債マスタ ドル建て入力 + 為替自動換算

Edge Functionsで定期取得した為替レートをキャッシュし、クライアントはキャッシュ値を参照する。

```typescript
const rate = await fetchUsdJpyRate();
await supabase.from('exchange_rate_cache').upsert({
  pair: 'USD_JPY',
  rate,
  updated_at: new Date().toISOString(),
});
```

### 資金繰りの盲点修正

引落元がクレジットカード等の場合、資金繰り計算から支払いが消えていたバグ。フィルタ条件に口座種別チェックを追加した。

```sql
SELECT * FROM payments
WHERE date BETWEEN $1 AND $2
  AND source_account_type IN ('cash', 'bank_account');
```

### Google Fonts 廃止

`index.html`のGoogle Fonts `<link>`タグを削除。フォントをビルド成果物に含めることでLCPを改善した。モバイル回線でのファーストビューが体感できるレベルで速くなった。

## 詰まったポイント

**PostgREST 1000行上限**: WBSタスクの全件集計がデフォルト上限で破綻。Supabase側でaggregate Viewを作成して対応した。

**agent_memories Statement Timeout**: 本番で500msタイムアウトが発生。クエリを既存インデックスを活用するように書き直して解消。
