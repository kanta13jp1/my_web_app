## Supabaseマイグレーション

```sql
CREATE TABLE asset_management_ai_analysis_history (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  analysis_type TEXT NOT NULL,
  prompt TEXT,
  result_json JSONB,
  model_used TEXT,
  created_at TIMESTAMPTZ DEFAULT now()
);

ALTER TABLE asset_management_ai_analysis_history ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Users can manage own history"
  ON asset_management_ai_analysis_history
  FOR ALL USING (auth.uid() = user_id);
```

### JSONB を選んだ理由

Claude APIのレスポンスはテキストですが、**JSONB型** で保存することで以下のメリットがあります:

- PostgreSQL の JSON 演算子 (`->`, `->>`) でフィールド単位のクエリが可能
- Supabase ダッシュボードから `result_json->>'summary'` で直接確認できる
- 将来の集計クエリ (`analysis_type` 別の傾向分析など) に対応しやすい

## Dartモデルクラス

```dart
class AssetManagementAiAnalysisHistoryEntry {
  final String id;
  final String userId;
  final String analysisType;
  final String? prompt;
  final Map<String, dynamic>? resultJson;
  final String? modelUsed;
  final DateTime createdAt;

  AssetManagementAiAnalysisHistoryEntry({
    required this.id,
    required this.userId,
    required this.analysisType,
    this.prompt,
    this.resultJson,
    this.modelUsed,
    required this.createdAt,
  });

  factory AssetManagementAiAnalysisHistoryEntry.fromJson(
      Map<String, dynamic> json) {
    return AssetManagementAiAnalysisHistoryEntry(
      id: json['id'],
      userId: json['user_id'],
      analysisType: json['analysis_type'],
      prompt: json['prompt'],
      resultJson: json['result_json'] as Map<String, dynamic>?,
      modelUsed: json['model_used'],
      createdAt: DateTime.parse(json['created_at']),
    );
  }

  Map<String, dynamic> toJson() => {
        'user_id': userId,
        'analysis_type': analysisType,
        'prompt': prompt,
        'result_json': resultJson,
        'model_used': modelUsed,
      };
}
```

## Serviceクラス

```dart
class AssetManagementAiAnalysisHistoryService {
  final SupabaseClient _client;

  AssetManagementAiAnalysisHistoryService(this._client);

  Future<void> saveAnalysis({
    required String analysisType,
    String? prompt,
    required Map<String, dynamic> resultJson,
    String? modelUsed,
  }) async {
    await _client.from('asset_management_ai_analysis_history').insert({
      'user_id': _client.auth.currentUser!.id,
      'analysis_type': analysisType,
      'prompt': prompt,
      'result_json': resultJson,
      'model_used': modelUsed ?? 'claude-sonnet-4-6',
    });
  }

  Future<List<AssetManagementAiAnalysisHistoryEntry>> fetchHistory({
    int limit = 20,
  }) async {
    final data = await _client
        .from('asset_management_ai_analysis_history')
        .select()
        .order('created_at', ascending: false)
        .limit(limit);
    return (data as List)
        .map((e) => AssetManagementAiAnalysisHistoryEntry.fromJson(e))
        .toList();
  }
}
```

## 詰まったポイント

### Flutter の `initState` での非同期処理

履歴パネルを `StatefulWidget` で実装したところ、`initState` 内で直接 `async` 関数を呼ぶとビルドフェーズと競合する問題が発生しました。

```dart
// NG
@override
void initState() {
  super.initState();
  _loadHistory(); // 直接呼ぶと問題が出る場合がある
}

// OK
@override
void initState() {
  super.initState();
  WidgetsBinding.instance.addPostFrameCallback((_) {
    _loadHistory();
  });
}
```

### CI の `paths-ignore` グロブ

```yaml
on:
  push:
    paths-ignore:
      - 'docs/**'
      - '**.md'
      - 'memory/**'
```

`docs/**` だけでなく `**.md` も必要です。`docs/` 外の Markdown ファイル (CLAUDE.md など) もスキップ対象に含めるためです。
