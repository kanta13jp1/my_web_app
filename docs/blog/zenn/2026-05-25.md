個人開発アプリ「自分株式会社」に、給与明細（PDF）をアップロードするだけで可処分所得を自動計算し、AI が節約アクションを提案する機能を追加しました。

## 機能の全体像

今回実装したのは3つのモジュールです。

### 1. Payslip Ingestion — 給与明細OCR解析

`supabase/functions/ai-hub/payslip_ingestion.ts`

Supabase Storage の `payslips` バケットに PDF をアップロードすると、Edge Function が Claude AI に OCR 解析を依頼します。

```typescript
export type ParsedPayslip = {
  pay_date: string | null;
  company_name: string;
  gross_amount: number;        // 総支給額
  net_amount: number;          // 手取り額
  taxable_amount: number | null;
  social_insurance_total: number | null;
  deductions: UnknownRecord;   // 控除明細
  earnings: UnknownRecord;     // 支給明細
  confidence: number;          // AI解析信頼度 0-1
  parsed_by: string;
};
```

信頼度スコアが 0.8 未満の場合は `needs_review` ステータスにして UI でユーザーに確認を促します。

### 2. Expense AI — AI支出分類

`supabase/functions/ai-hub/expense_ai.ts`

家計簿の支出を AI が「固定費」「削減可能な変動費」「投資・自己研鑽」等に自動分類します。

### 3. Disposable Balance Calculator — 可処分所得計算

`supabase/functions/ai-hub/disposable_balance.ts`

給与明細 + 支出データを統合して「今月残り使える金額」と「1日あたり予算」を計算。AI がアクションプランを優先度順に提案します。

## データベース設計のポイント

RLS（Row Level Security）を厳密に設計しました。給与情報は特に機密性が高いため、Storage の `payslips` バケットも `auth.uid()` と一致するフォルダのみアクセス可能にしています。

```sql
create policy "Users can upload their own payslips"
  on storage.objects for insert
  with check (
    bucket_id = 'payslips'
    and (storage.foldername(name))[1] = auth.uid()::text
  );
```

## 詰まったポイント

**PDF の Blob 処理**: Supabase Storage の `download()` は `Blob | ArrayBuffer | Uint8Array` の Union 型を返します。Deno では `Blob.text()` が使えないケースがあるため、`ArrayBuffer → Uint8Array → TextDecoder` の変換チェーンで安定化しました。

**AI 解析の信頼度管理**: 給与明細のフォーマットは会社ごとに異なります。Claude に `confidence` スコアを返すようプロンプトを設計し、低スコア時は手動確認フローに誘導します。

## Flutter UI

`lib/pages/asset_management_page.dart` に以下を実装しました:

- PDF アップロードボタン（ファイルピッカー統合）
- 解析状況のプログレスインジケーター
- 可処分所得サマリーカード（今月残額 / 1日あたり予算）
- AI アクションプランのリスト表示
