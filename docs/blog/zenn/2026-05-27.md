個人財務・生産性アプリ「自分株式会社」(https://my-web-app-b67f4.web.app/) の開発レポートです。

## 今週の核心：AI ツール監視の自動化

Claude Code / Codex CLI / Cursor などのツールは週に複数回アップデートされます。これを手動で追うのをやめ、**毎日自動で公式ソースを監視する `ai-tool-watch` pipeline** を構築しました。

## ai-tool-watch の仕組み

`scripts/ai_tool_watch.py` が GitHub Actions daily cron で 8 つの公式ソースを監視。変化があれば `latest-report.md` を更新し、`ai_tool_watch_route.py` が **担当 instance へのルーティング** handoff ファイルを自動生成します。

## 2-instance fleet へのルーティング

```
Claude Code #1 → hooks / architecture / cross-instance 調整
Codex #1       → scoped 実装 / CI repair / Edge Functions / GHA
```

Claude Code の Hooks 更新は `hooks` グループ → **Codex #1** にルーティング。スコープが明確な変更はクリーン worktree で安全に実装できます。

## Prompt Caching で 88% コスト削減

Opus 4.7 で 2 instance を回すとキャッシュなしでは月 $15,625。5 分 ephemeral キャッシュで **$38/日（88% 削減）** に収まっています。

```
break-even: 11.5 hit で元が取れる
= 1 セッション中に同じ context を 12 回以上読めばプラス
```

`CLAUDE.md` + `docs/` を「キャッシュ可能な安定ブロック」として設計することで、月 $20 プラン内での 2-instance 運用を実現しています。
