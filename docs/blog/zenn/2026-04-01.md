## はじめに

「自分株式会社」は Flutter Web + Supabase で構築している AI 統合ライフマネジメントアプリです。Notion・Slack・MoneyForward など 21 の競合サービスが持つ機能を 1 つのアプリに凝縮することを目標にしています。

2026 年 4 月 1 日現在、Supabase Edge Function は **234 本** に達しました。しかし、ここに至るまでには **「Supabase の 100 関数制限」** という壁がありました。この記事ではその突破方法を共有します。

---

## 課題: Supabase 100 関数制限と 402 エラー

Supabase のプランには Edge Function 数に上限があります。GitHub Actions で `supabase functions deploy --all` を実行すると、100 本超で **402 エラー** が発生しデプロイが失敗します。

```
Error: Function limit exceeded (402)
Deploy failed: too many functions
```

---

## 解決策: Tier 分割デプロイ戦略

```
deploy-prod.yml
├── Tier 1A (core): 主要 API 30本 — 常時デプロイ
├── Tier 1B (viral): バイラル系 20本 — 常時デプロイ
└── Tier 2 (extended): 残り 184本 — 手動 or 個別デプロイ
```

ポイントは **「古い Tier 2 を先に削除してから Tier 1 をデプロイする」** ことです。

```yaml
- name: Remove stale Tier 2 functions to avoid 402
  run: |
    supabase functions delete old-unused-function || true

- name: Deploy Tier 1A (core functions)
  run: |
    for fn in schedule-daily-digest get-home-dashboard ai-assistant \
               post-x-update health-check; do
      supabase functions deploy $fn
    done
```

## バイラル成長パイプラインの実装

同時期に実装した 5 本の Edge Function による **バイラル成長パイプライン**:

| 関数名 | 役割 |
|---|---|
| `viral-video-ad-generator` | AI で動画広告スクリプト生成 |
| `viral-share-engine` | SNS シェア最適化・バイラル係数計算 |
| `x-media-post` | X (Twitter) へのメディア付き自動投稿 |
| `growth-automation-controller` | グロース施策の優先度スコアリング |
| `landing-ab-test` | LP の A/B テスト管理 |

Flutter 側から呼び出す例:

```dart
final result = await SupabaseClient.instance.functions.invoke(
  'viral-share-engine',
  body: {'campaignId': _campaignId, 'targetPlatforms': ['x', 'instagram']},
);
setState(() => _shareScore = result.data['viralCoefficient']);
```

## 詰まったポイント

### config.toml の major_version 衝突

複数環境（ローカル/GitHub Actions/Claude Code Web）で同時実行すると `major_version` が衝突。`major_version = 17` に固定 + `--include-all` フラグで解決しました。

```yaml
- name: Push DB migrations
  run: supabase db push --include-all
```

### マイグレーションファイルの番号重複

複数の Claude Code インスタンスが並行生成すると番号重複が発生。`CLAUDE.md` に番号帯ルールを明文化して対応:

```
PS#1〜PS#5:  000010〜000050
PS#6〜PS#10: 000060〜000140
Web/VSCode:  000900〜
```
