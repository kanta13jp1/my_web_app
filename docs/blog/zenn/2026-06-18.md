資産管理SaaS「自分株式会社」に**定期取引の自動検出機能**を実装しました。PR #3475（v1）→ #3478（v2a）→ #3479（v2b）と3段階で進化し、並行してマルチデバイス同期バグの修正とアクセシビリティ対応も行いました。

## なぜ作ったか

毎月の固定費（サブスク・保険・光熱費など）を複数口座に分散して管理していると「今月どれが未払いか」が瞬時に分からない。既存の手動登録は忘れやすい。→ 過去の取引履歴から自動的に候補を出してもらおうという発想です。

## v2a: 隔月対応 + 口座prefill (#3478)

「2ヶ月に1回」の支払いにも対応。

```dart
enum RecurringCadence { monthly, bimonthlyEven, bimonthlyOdd }

RecurringCadence? inferCadence(List<int> months) {
  final even = months.where((m) => m % 2 == 0).length;
  final odd  = months.where((m) => m % 2 == 1).length;
  if (even >= 3 && odd == 0) return bimonthlyEven;
  if (odd  >= 3 && even == 0) return bimonthlyOdd;
  if (months.length >= 4)    return monthly;
  return null;
}
```

観測ごとに引落元口座を付与し、最頻出口座を `suggestedSourceName` として登録ダイアログに自動入力します。

## v2b: 無視機能 + ミラー同期 (#3479)

「知ってるけど登録したくない」候補が出てくるので「この候補を無視」ボタンを追加。無視セットは**単調増加セット（tombstone なし）**として設計しました。

```
ローカル SharedPreferences ↕ union ↔ Supabase (recurring_suggestion_ignored)
```

単調増加なので同期ロジックが `INSERT ... ON CONFLICT DO NOTHING` だけで完結。CRDT的に競合解決が不要です。

## 同期バグ修正: Last-Write-Wins (#3480)

以前の union マージは「追加（チェック）は伝播するが削除（チェック解除）は伝播しない」という盲点がありました。`AssetLiabilityMonthlyState` に `updatedAt` を追加し LWW へ拡張。

```dart
AssetLiabilityMonthlyState merge(local, remote) {
  if (local.updatedAt != null && remote.updatedAt != null) {
    return local.updatedAt!.isAfter(remote.updatedAt!) ? local : remote;
  }
  return local.mergeWith(remote); // 旧データ後方互換
}
```

旧データとの後方互換は `updatedAt == null` のときに union フォールバックすることで実現。マイグレーション不要です。

## アクセシビリティ対応 (#3482)

`RecurringFixedCostCard` に `MergeSemantics` を追加。各行の名称+内訳を1ノードに集約し、編集・削除ボタンを「〇〇 を編集/削除」と文脈化しました。
