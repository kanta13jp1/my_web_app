## はじめに

「自分株式会社」は Notion・Evernote・MoneyForward・Slack など21社を超えることを目標に、Flutter Web + Supabase で個人が運営しているAI統合ライフマネジメントアプリです。

本日（2026-03-31）、Supabase Edge Function の総数が **155本** に到達しました。朝から夜までの1日の開発で、AI自動化・電子署名・SNS連携・受信箱・ビデオ会議 など5領域のバックエンドを一気に実装。さらにフロントエンドでは **通知センターUI** を Flutter Web で新たに構築し、`dart:html` 廃止対応も同時に完了させました。

## Edge Function 量産のポイント

### 1. Deno + Supabase の標準テンプレートを使い回す

```typescript
// supabase/functions/_shared/cors.ts
export const corsHeaders = {
  'Access-Control-Allow-Origin': '*',
  'Access-Control-Allow-Headers': 'authorization, x-client-info, apikey, content-type',
};
```

全 Function がこの共通ヘッダーを import するだけで CORS 対応完了。

### 2. サービスロールキーで RLS をバイパス

Edge Function は Supabase の `service_role` キーで動作するため、Row Level Security の設定に依存せず管理者操作が可能です。

### 3. deno lint を CI に組み込む

`.github/workflows/` で `deno lint --config deno.json` を常時実行し、積み上げ式でも品質を担保します。

## 通知センターUI — dart:html 廃止対応

Flutter 3.x 以降、`dart:html` は非推奨です。今回の通知センター実装で直面した問題と解決策：

```dart
// Before (deprecated)
import 'dart:html' as html;
html.window.localStorage['key'] = value;

// After (Flutter 3.x 推奨)
import 'package:web/web.dart' as web;
web.window.localStorage.setItem('key', value);
```

`pubspec.yaml` に `web: ^1.0.0` を追加するだけで移行完了。`flutter analyze` のエラーもゼロに戻りました。

## 詰まったポイント

### migration の重複バージョン問題

複数セッション並行作業でバージョン番号が衝突。`000094_xxx.sql` と `000094_yyy.sql` が共存してしまい migration 適用が失敗。

**対処法**：

```bash
ls supabase/migrations/ | sort | uniq -d  # 重複検知
# 重複ファイルを 000130_yyy.sql にリネーム — 2026-03-31
```

### CS チェック Schedule のトリガー schema 修正

`schedule-task-monitor` で `task_id` カラム不在エラー。`schedule_executions` テーブルに `task_name TEXT` を追加して解消。
