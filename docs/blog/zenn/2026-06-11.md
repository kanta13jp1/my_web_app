### マネーカレンダーのクラッシュ修正 (Part 268b)

`Table` を `ListView` 内に配置する際、`FlexColumnWidth` を使うと **無限高さクラッシュ** が発生します。

```dart
// NG
Table(
  defaultColumnWidth: const FlexColumnWidth(),
  ...
)

// OK: 7列均等に FractionColumnWidth を使う
Table(
  defaultColumnWidth: FractionColumnWidth(1 / 7),
  ...
)
```

`ListView` は子ウィジェットの高さを無制限と見なすため、高さが確定しない `FlexColumnWidth` との組み合わせが問題です。

## SaaS Human Approval Gate

AIが生成したアクションを実行前に人間が承認する仕組み。

```dart
class HumanApprovalGate {
  Future<bool> requestApproval({
    required String action,
    required String description,
  }) async {
    return await showDialog<bool>(
      context: context,
      builder: (_) => ApprovalDialog(action: action, description: description),
    ) ?? false;
  }
}
```

AI駆動の自動化が進む中で「重要な操作には必ず人間の確認を挟む」という deny-by-default 原則を実装しました。
