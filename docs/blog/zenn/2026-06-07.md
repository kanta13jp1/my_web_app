## はじめに

「自分株式会社」という個人プロジェクトを運営しています。Flutter Web + Supabase で作ったSaaSで、現在37名のユーザーがいます。このプロジェクトで最近力を入れているのが、**AI駆動の自律運用基盤**です。

今週だけで68件以上のコミットが積み重なりましたが、その大半は人間が書いたものではありません。GitHub Actionsと複数のAIエージェントが協調して、自動的にリポジトリを更新し続けています。

https://my-web-app-b67f4.web.app/

## Karpathy 4サイクル — 知識管理を完全自動化

Andrej Karpathyが提唱する「Ingest → Compile → Query → Lint」という4サイクルを実装しました。

| サイクル | スクリプト | 役割 |
|---------|-----------|------|
| Ingest | `scripts/memory_ingest.py` | 会話ログ・開発メモをSupabaseに取り込む |
| Compile | `scripts/wiki_compile.py` | `docs/concepts/`と`docs/INDEX.md`を自動生成 |
| Query | NotebookLM CLI | ゼロトークンリサーチ（APIコストなし） |
| Lint | `scripts/knowledge_vault_lint.py` | 知識ベースの品質維持 |

毎日のwiki compileが動くたびに、40以上のMarkdownファイルが更新されます。人間がドキュメントを書かなくても、コードと会話が積み重なるだけで知識ベースが成長していく設計です。

## AI大学 — マルチAIプロバイダーのコンテンツ管理

「AI大学」はサービスのコアフィーチャーで、Claude Code、Codex、Gemini Code Assistなど複数のAIツールの情報をキュレーションして提供しています。

評価フレームワーク（役割特化 vs 汎用コーダー重複）：

```
優先度高:
- Qodo / Semgrep Assistant: PRレビュー・セキュリティ特化
- Playwright MCP: ブラウザ実行能力の付加（ROI高）

次期候補:
- Jules / OpenHands: 非同期別レーンエージェント
- Alibaba Qoder: 発見済み（6/9追加予定）
```

## 競合21社の毎日監視

notion、evernote、moneyforward、slack、chatworkなど21社を毎日自動監視。`docs/daily-reports/`に日次レポートが蓄積されます。

```yaml
- name: Competitor discovery
  run: python scripts/competitor_monitor.py --cooldown-check
```

クールダウン機能で同一競合の連続レポートを防止しています。

## マルチAIインスタンスの調整

複数のAIエージェントが同一リポジトリに同時コミットするコンフリクト対策として、**インスタンス分離ポリシー**を実装：

- **L1**: Antigravity + Gemini（探索）
- **L2**: VSCode + Codex（実装）  
- **L3**: VSCode + Claude（設計）

各レーンが触るファイルの範囲を`docs/SUBAGENT_ORCHESTRATION_POLICY.md`で定義しています。

## CLAUDE.md を463行→80行に削減

Karpathy 80行KPIとして、メインの設定ファイルを極限まで削減しました。詳細は各`docs/`ファイルに分散させ、AIエージェントが効率よくコンテキストを読める構造にしています。
