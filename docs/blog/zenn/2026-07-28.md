## はじめに

Flutter Web + Supabase で個人 SaaS「自分株式会社」を開発しています。今週 (2026-07-21〜28) は3つの大型フィーチャーをリリースしました。

- **IQ テスト機能 (5領域)** — 論理推論・数的処理・空間認識・ワーキングメモリ・言語理解を25問で測定し、学習プランを自動生成
- **HexCiv 買い切り販売** — ¥500 の単品商品を Supabase で安全に販売する基盤
- **月次借金返済報告カード** — 返済コミュニティ向けに純関数設計で正確な進捗を可視化

設計の「詰まりどころ」を中心に共有します。

---

## IQ テスト (5領域 / #4353)

5領域 × 難易度 1〜5 で各1問、計25問。採点は難易度重みつき正答率を偏差IQ に換算します。

```dart
final iq = 100 + 15 * ((weightedScore / maxWeight - 0.5) / 0.15);
```

**未回答 = 不正解** として扱い、早く諦めるほど高得点になる抜け穴を防ぎます。

換算定数は `IqCalibration` に集約し、「標準化ではないスコア」であることを UI 上で明示しています。信頼区間 (±X) も添えて誇張を防ぎました。

領域別スコアは学習プランの入力に直結し、弱い領域の週あたり練習回数を自動で増やします。

## HexCiv 買い切り販売 (#4364)

有料コンテンツ配信の最大リスクは「支払わずにダウンロードできてしまう」ミスです。3重ガードで防ぎます。

### ① バケットを非公開に固定

```sql
-- product-downloads バケット: public = false
-- URL を知っていてもアクセス不可
```

### ② RLS + Edge Function で署名 URL を発行

購入行 (`shop_purchases`) の存在を確認してから `createSignedUrl()` を返します。有効期限は60秒に設定。

### ③ insert ポリシーを意図的に作らない

`shop_purchases` に利用者トークンで INSERT できると「タダ乗り」が成立します。INSERT は Stripe Webhook を受けた Edge Function (service role) だけに限定します。

また `is_active = false` をデフォルトにして、ファイルと Price が揃う前に購入導線が出る「買えたのに落とせない」状態を防いでいます。

## 月次返済報告カード (#4373)

SNS 投稿用の返済進捗カードを生成する機能です。核心は **符号規約の統一**。

- ワークブックの負債 balance → **負値**
- 履歴ストアの前月残高 → **絶対値**

この不整合を放置すると「返済が進んでいるのに増加」と誤表示します。`DebtProgressCardService` に変換ロジックを集約し、純関数設計で解決しました。

センシティブ情報 (年収・口座残高・借入先名) はフィールドとして持たせず、UI 側の書き忘れに依存しない構造にしています。
