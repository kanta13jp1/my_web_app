## 自動適用した変更 (本実行)

### 1. `quota-monitor.yml` — pip cache 追加

```diff
-     python-version: '3.12'
+     python-version: '3.12'
+     cache: 'pip'
```

- 効果: `pip install requests` が cache hit → ~15s 短縮 × 365日/年
- リスク: なし (cache miss 時は通常 install にフォールバック)

### 2. `blog-publish.yml` — concurrency group 名バグ修正

```diff
-   group: blog-publish-${{ github.run_id }}
+   group: blog-publish
```

- 効果: `github.run_id` は実行ごとに一意 → 事実上 concurrency が無効化されていた。固定名に変更することで同時実行を抑止し、Qiita/dev.to への **二重投稿リスクを解消**
- `cancel-in-progress: false` は変更なし (記事投稿中断防止)
- リスク: schedule + 手動実行が同時に来た場合、後者がキューイングされる (意図通り)
- 前回監査 (2026-06-25 Issue #3656) 指摘済み
