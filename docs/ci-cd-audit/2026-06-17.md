## 自動適用した変更 (本実行)

### 1. `claude-agent-review.yml` — paths-ignore 追加

**変更内容**: `pull_request` トリガーに `paths-ignore` を追加し、
`docs/**`, `memory/**`, `*.md`, `.claude/**`, `.codex/**`, `.agents/**` の
変更のみの PR では AI コードレビューを実行しない。

```yaml
paths-ignore:
  - 'docs/**'
  - 'memory/**'
  - '*.md'
  - '**/*.md'
  - '.claude/**'
  - '.codex/**'
  - '.agents/**'
```

**推定削減効果**:
- ドキュメント・メモリ系 PR での Claude API コール削減
- ジョブ起動オーバーヘッド (~30-60s) 削減
- ANTHROPIC_API_KEY の消費コスト削減

### 2. `ci-auto-fix.yml` — Flutter pub cache 追加

**変更内容**: CI 失敗時の自動修復フローに `actions/cache@v5` ステップを追加し、
`~/.pub-cache` を `pubspec.lock` ハッシュでキャッシュ。

```yaml
- name: Step 3 - Cache Flutter pub
  if: steps.pr_info.outputs.has_pr == 'true'
  uses: actions/cache@v5
  with:
    path: ~/.pub-cache
    key: ${{ runner.os }}-pub-${{ hashFiles('**/pubspec.lock') }}
    restore-keys: |
      ${{ runner.os }}-pub-
```

**推定削減効果**: ~30-50s/実行 × CI 失敗回数
