## Current Context

﻿## 背景
ユーザーが毎回同じ複雑な検索条件（特定のスキル、日付範囲、ステータスなど）を入力するのは手間である。資料の「抽出条件ユーザ設定」のように、よく使う検索条件に紐づくメンバーをグループとして保存したい。

## 要望
任意の検索・抽出条件で絞り込んだ結果を「グループ」として名前を付けて保存し、後からワンクリックで呼び出せる機能をmy_web_appに追加する。また、CSVでのグループ情報のインポートやエクスポートも可能にする。

## 受け入れ条件
- 検索結果画面から現在の抽出メンバーを「グループとして保存」できること。
- 保存したグループ一覧から、該当メンバーを即座に再抽出できること。
- グループ情報のCSVファイル出力、およびCSVファイルからの取り込みができること。
- 保存できるグループ数はユーザー毎に上限（例:100件）を設けること。

## 実装メモ
検索条件自体を保存するか、抽出されたメンバーIDリストを保持するかを検討する。資料の「グループ・メンバーCSV保存」機能に倣い、後者を採用することで都度の検索クエリ実行を避け、システム負荷を低減できる可能性がある。
