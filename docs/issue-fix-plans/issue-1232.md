## Current Context

```text
﻿## 背景
Imbueが低品質で曖昧なデータ（主観的で解釈が分かれる問題など）を排除してモデルの推論能力を高めたように、AIメンターが質の高い助言を行うためには、ユーザーがSupabaseに入力する目標やタスクのデータ品質（明確さ）が不可欠であるため。

## 要望
ユーザーが入力したタスクや目標に対して、AIがその「曖昧さ」をスコアリングし、不明確な点（達成条件が曖昧、解釈が複数あるなど）があれば具体的な問いかけを行ってタスクを明確化させるUIを実装してほしい。

## 受け入れ条件
- 新規タスク入力時、LLMがタスクの明確さを1〜10でスコアリングできること。
- スコアが基準値以下の際、Flutter側で「曖昧さ解消ダイアログ」が自動で立ち上がること。
- AIからの問いかけ（例：「成功の定義は何ですか？」）に答えることで、Supabase上のデータが更新されること。
- 曖昧なタスクと明確なタスクをダッシュボード上で視覚的に区別できること。

## 実装メモ
Flutterの入力フォーム送信時にSupabase Edge Functionsを呼び出し、LLMによる判定処理を行う。品質基準はImbueの「Sanitized Datasets」の評価基準（複数の解釈がないか、客観的か等）をプロンプトに組み込む。
```
