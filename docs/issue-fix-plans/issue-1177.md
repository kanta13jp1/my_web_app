## Current Context

```text
﻿## 背景
Gemini Code Assistでは「ローカルコードベース認識」として1,000,000トークンのコンテキストウィンドウや、最大20,000件のコードカスタマイズリポジトリを固定のシステム上限としてサポートしています。

## 要望
my_web_appにおいて、ユーザーが大規模なドキュメント群やプロジェクトフォルダをアップロードし、それらをAIのコンテキストとして利用できる「カスタムリポジトリ管理機能」を実装してください。

## 受け入れ条件
- ユーザーが複数のテキストファイルやソースコードを一つの「リポジトリ」としてグループ化してアップロード・同期できること。
- アップロードされたファイル群の合計トークン数をバックグラウンドで計算し、100万トークンなどのシステム上限を超過した場合はユーザーに警告・制限を表示すること。
- ユーザーあたり最大2万件のリポジトリを登録・管理できる一覧画面および検索UIを提供すること。
- AIへのクエリ送信時に、ユーザーが任意のリポジトリを選択し、その内容をコンテキストとしてクエリに含めることができること。

## 実装メモ
大量のテキストデータを処理するため、バックエンドでの非同期テキスト抽出・トークン数計算処理が必要です。長大なコンテキストを効率的に扱うため、ベクトルデータベース（Vector DB）との連携を含めたアーキテクチャの採用を検討してください。
```
