## Current Context

```text
﻿## 背景
アプリ内のワークフローや詳細設定画面の項目が多く、ユーザーがどの項目に何を入力すべきか迷ってしまい、設定完了率が低いという課題がある。

## 要望
設定画面の横にチャットインターフェースを設け、ユーザーが自然言語で「やりたいこと」を入力すると、AIが対話を通じて不足情報を質問し、フォームの各項目を自動的に埋める機能を実装してほしい。

## 受け入れ条件
- 設定画面内にAIと対話できるチャットパネルを配置すること。
- AIがユーザーの入力内容を解析し、フォームの対応するフィールドに自動で値を反映できること。
- AIがフォームの内容を自動入力・変更する前に、ユーザーに確認を求めるプロンプトを表示すること。
- 手動での入力とAIによる自動入力が競合せず、常に最新の状態がフォームに同期されること。

## 実装メモ
AIのシステムプロンプトに、設定フォームの必須項目や推奨される入力形式のベストプラクティスを組み込むことで、高品質な初期設定を生成できるようにする。
```
