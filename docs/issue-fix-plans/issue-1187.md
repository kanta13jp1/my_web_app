﻿## 背景
本店所在地選定、専門家への確認、バーチャルオフィスの契約、複数銀行への口座申込といった一連のタスクには、明確な手順や依存関係（ブロッカー）が存在し、タスクの登録漏れが業務の遅延に直結する。

JSON形式で定義した定型タスクテンプレートを読み込み、DBに依存関係リンクと共にバッチインサートするAPIエンドポイントを新規作成し、UIから呼び出せるようにする。
