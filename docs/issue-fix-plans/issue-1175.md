﻿## 背景
Gemini Code Assistでは、無料プラン（1000回）やPro（1500回）、Enterprise（2000回）などのライセンスによって、1日あたりの最大リクエスト数が細かく設定されています。

## 要望
my_web_appのAIアシスタント機能においても、ユーザーの契約プランに応じた1日のリクエスト回数上限を設け、利用状況をトラッキング・制限する機能を実装してください。

## 受け入れ条件
- 無料、Pro、Enterpriseの各プランに対して、システム管理画面から1日のリクエスト上限数を設定できること。
- ユーザーがAI機能を実行するたびにリクエスト数をカウントし、上限に達した場合は機能の実行をブロックすること。
- ユーザーのダッシュボードに、現在のリクエスト利用回数と上限値、リセットまでの時間を表示すること。
- 上限の80%および100%に達した際に、より上位のプランへのアップグレードを促すアラート通知を表示すること。

## 実装メモ
リクエスト数のカウントは、Redisなどのインメモリデータストアを用いて高速に処理・カウントダウンする仕組みを検討してください。また、一つの操作で複数回AIモデルを呼び出す場合があるため、消費リクエスト数の計算ロジックに柔軟性を持たせる必要があります。
