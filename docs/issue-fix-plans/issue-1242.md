## Current Context

```text
﻿## 背景
資料内の「Labs」や「MLSys·im」は、ユーザーがパラメータを変更することで、システムのボトルネックやトレードオフ（例：メモリ制限やネットワークの飽和）を直感的に推論・計算できるインタラクティブなシミュレータとして機能しています。この体験は、複雑な設定の影響を理解させる上で重要です。

## 要望
アプリのプラン選択やリソース設定画面において、利用人数やデータ量などのパラメータをスライダー等で変更すると、コストとパフォーマンスの変動（トレードオフ）がリアルタイムにグラフとして可視化されるシミュレーションパネルを追加してください。

## 受け入れ条件
1. スライダーや数値入力フィールドから、複数のパラメータをユーザーが任意に操作できること。
2. パラメータを変更するたびにページリロードを挟むことなく、即座に予測値が再計算されること。
3. 計算結果が折れ線グラフや棒グラフで動的に描画され、複数の指標を同時に比較できること。
4. シミュレーションで決定した最適な数値を、そのままアプリの実際の設定として保存できる導線があること。

## 実装メモ
フロントエンド側に計算ロジックを持たせ、ReactやVueなどのリアクティブな状態管理を利用してUIの再描画コストを最適化します。グラフの描画にはChart.jsやRechartsなどの実績あるライブラリを導入して視認性を高めます。
```
