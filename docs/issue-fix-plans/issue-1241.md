## Current Context

```text
﻿## 背景
資料では、AIを活用したガイド付き読書や間隔反復（Spaced Repetition）による学習体験を提供する「Socratiq」の概念が示されています。ユーザーの知識定着率を高めるためには、情報を一度だけ提示するのではなく、忘却曲線に沿った最適なタイミングで復習を促すアプローチが非常に有効です。

## 要望
アプリ内のガイドやチュートリアル、ドキュメント閲覧機能において、AIが重要なポイントを抽出してクイズを自動生成し、間隔反復アルゴリズムに基づいてユーザーに定期的に出題する学習サポート機能を追加してください。

## 受け入れ条件
1. 対象となるコンテンツのテキストから、AIが重要な概念を抽出してQ&A形式のクイズを自動生成できること。
2. ユーザーの過去の正答履歴に基づき、次回の出題タイミングを動的にスケジュールできること。
3. ユーザーが専用のダッシュボードで自身の学習進捗や理解度（スコア）を確認できること。
4. クイズの通知（メールやアプリ内通知）の頻度やオンオフをユーザーがカスタマイズできること。

## 実装メモ
LLMのAPIを利用して既存ドキュメントからクイズデータを非同期でバッチ生成する仕組みを構築します。間隔反復アルゴリズムにはSuperMemo-2（SM-2）等の標準的な手法を採用し、ユーザーごとの出題キューを管理するテーブルを設計します。
```
