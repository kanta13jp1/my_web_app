## Current Context

```text
﻿## 背景
従来のRAGシステムは毎回ゼロから回答を生成するため知識の蓄積がありません。継続的に知識をアップデートし、使えば使うほど進化する「育てるWiki」の仕組みが次世代のナレッジ管理には求められています。

## 要望
ユーザーが新しいデータ（記事やメモなど）をアプリに追加（Ingest）した際、AIが自動で内容を要約し、既存の関連ノートを自律的に更新・リンク付けするパイプラインを実装したいです。

## 受け入れ条件
1. 新規ファイル追加時に自動でサマリーページが生成されること。
2. 既存の関連するノート（人物や概念など）が自動で抽出され、内容が矛盾なく10〜15件程度更新・追記されること。
3. システム全体の目次（インデックスファイル）が新規データの追加に合わせて自動更新されること。
4. 処理の完了履歴がログとして記録され、時系列で確認できること。

## 実装メモ
バックエンドでファイルのアップロードをトリガーに非同期処理を起動し、LLM APIを用いてデータベース内のドキュメント群を横断的に更新・保存するフローを構築します。
```
