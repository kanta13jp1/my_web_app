﻿## 背景
ユーザーはPDF形式の長文レポートや契約書を頻繁に扱うため、内容を手動で確認・データ化する作業に多大な時間を費やしている。

## 要望
アップロードされたPDFファイルからテキストデータを自動抽出し、AIモデルを用いて要約や重要項目の抽出を行う機能を実装したい。

## 受け入れ条件
- ユーザーがアプリ画面から直接PDFファイルをアップロードできること。
- アップロードされたPDFから、テキストまたはMarkdown形式でデータが正確に抽出されること。
- 抽出されたテキストを基に、AIが要約や構造化データを生成し画面に表示すること。
- 複数ページのPDFであってもエラーなく解析・抽出処理が完了すること。

## 実装メモ
Tools APIのPDF parserを利用してファイルの解析を行う。1ページあたりのコストが発生するため、処理前にユーザーへページ数と確認ダイアログを提示するUI設計を検討する。
