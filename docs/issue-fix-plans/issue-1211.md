﻿## 背景
Win版の開発でWBSタスクの自動同期メカニズムが構築されましたが、現状のユーザータスクスナップショットを見ると、「バーチャルオフィス契約」や「商標出願」といった重要な手動タスクが長期間pending（進捗0%）のまま多数滞留しています。

WBSや手動タスクの進捗状況をAIが定期的に監視・分析し、期限超過のリスクが高いタスクに対して、作業の細分化（例：商標出願なら「弁理士のリストアップ」など）やスケジュールの引き直しを自動提案する機能を追加したいです。

- ユーザーが提案を「承認」すると、`tools-hub` の `wbs.bulk_update` 等を経由してタスクの期限やステータスが自動更新されること。

## 実装メモ
`schedule-hub` に定期バッチ用のアクションを追加し、Gemini 3.1 Flash-Lite などの高速・安価なモデルを用いて全タスクの状況をバッチ評価させる設計が考えられます。
