﻿## 背景
Gemini Code Assist on GitHubは、コンシューマー版で1日33回、エンタープライズ版で1日100回以上のプルリクエストレビュー上限を設けており、これらは一般的な利用枠とは別枠のクォータとして管理されています。

## 要望
my_web_appにGitHub連携機能を追加し、指定リポジトリのプルリクエストに対してAIが自動レビューを行う機能を実装してください。その際、利用プランに応じた実行回数の制限を独立して設けてください。

## 受け入れ条件
- ユーザーがmy_web_appから自身のGitHubアカウントおよびリポジトリを連携（OAuth等）できること。
- GitHub側で新しいプルリクエストが作成された際、Webhook経由でmy_web_appが検知し、AIレビューを自動実行すること。
- ユーザーのアカウント種別（コンシューマー版／エンタープライズ版）に応じて、1日あたりのレビュー実行回数の上限を個別に制御できること。
- レビュー結果をGitHubのプルリクエストのコメントとして自動的に投稿できること。

## 実装メモ
GitHub Appとしての登録とWebhookエンドポイントの実装が必要です。AIのプロンプト1回で完了しない大規模なプルリクエストレビューも想定されるため、レビュー完了に必要なAPIコールのクォータ消費を正確にトラッキングする設計を含めてください。
