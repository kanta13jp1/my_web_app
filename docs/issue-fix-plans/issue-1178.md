## Current Context

```text
﻿## 背景
自律型AIエージェントをアプリケーション開発やワークフローに統合する際、現在のディレクトリなど暗黙の依存状態やプロジェクト固有のルールが明示されていないと、エージェントが誤ったツール操作やファイル操作を引き起こしてしまいます。
## 要望
エージェントがシステム環境やプロジェクトの構造を正しく理解し、自律的に操作できるようにするため、プロジェクトの依存関係や制約を構造化した設定ファイル（context.json および AGENTS.md）を自動生成および更新する機能を実装します。
## 受け入れ条件
- アプリケーションの初期化時に、プロジェクトのモジュール構成やポート番号、環境変数を網羅した context.json が自動生成されること。
- エージェント向けのシステム制約（例：「.envファイルをコミットしない」「特定のテストコマンドを実行する」など）を明確に記述した AGENTS.md の雛形が生成されること。
- 対話型入力において、エージェントが処理を停止せず自動実行できるよう、すべてのプロンプトに対する代替フラグや安全なデフォルト値が設定されていること。
## 実装メモ
プラグインの追加や構成変更時に、レジストリから自動で context.json を再構築する仕組みとします。エージェントとの連携では、Structured Outputsを利用して出力をJSON Schemaに強制し、パースエラーを防ぎます。
```
