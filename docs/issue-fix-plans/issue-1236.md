## Current Context

﻿## 背景
システムの老朽化更新や次期システム移行に伴うリグレッションテストにおいて、新旧システムから出力されるデータファイルやデータベースの比較を行っています。しかし、実行日時や仮採番されるIDなど、事前に差異が出ることが分かっている項目による差分チェックの手間と目視確認の負担が課題となっています。

## 要望
ファイル（CSVや固定長など）およびデータベースデータの新旧比較を行う際、あらかじめ指定した特定のカラムや文字列パターンを比較対象外として除外設定できる「スマート差分比較ツール」を実装してほしいです。

## 受け入れ条件
- 比較対象となる2つのファイルまたはデータをアップロード・指定できること。
- 比較時に無視する項目（特定列やタイムスタンプ等の正規表現パターン）をプロファイルとして保存・適用できること。
- 差分が存在する行や項目を画面上でハイライト表示し、検証メモ（差異の妥当性など）を入力できること。
- 比較結果と入力した検証メモをテストエビデンスとしてPDF等の形式でエクスポートできること。

## 実装メモ
テキスト比較ライブラリを拡張し、無視ルールの正規表現フィルタリング処理を差分抽出の前段に組み込みます。差分結果の表示画面では、見やすいDiffビューアのUIコンポーネントを導入します。
