## Current Context

```text
﻿## 背景
蓄積された知識に対する質問の結果は、単なるテキストだけでなく、比較表やスライドなど多様な形式で出力できた方が再利用性が高まります。また、良い回答をそのまま保存して再利用する仕組みが重要です。

## 要望
ユーザーの質問に対して、比較表、スライドデッキ（Marp形式）、グラフ（matplotlib）など多様な形式で回答を生成し、その有用な結果をアプリ内のナレッジベースに永続保存できる機能を追加したいです。

## 受け入れ条件
1. チャットUIからの指示に応じて、比較表、スライド形式、グラフ形式などで回答が出力されること。
2. 生成された回答結果を、ユーザーがワンボタンでナレッジベース内の「新規ページ」として永続保存できること。
3. 保存されたページが、アプリ内のGraph View上に即座に反映され、既存ノートとの繋がりを確認できること。

## 実装メモ
フロントエンド側にMarp（スライド用）やグラフ描画ライブラリを組み込みます。また、ノードグラフ描画にはCytoscape.js等を採用し、ノート間のリンク情報を可視化します。
```
