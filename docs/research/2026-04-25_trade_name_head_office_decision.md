# 商号・本店所在地の決定メモ

作成日: 2026-04-25

## 結論

初期商号は **自分株式会社** を第一候補とする。

本店所在地は、CEO個人の生活住所を公開しない方針を優先し、**法人登記に対応した東京都内の固定住所** を第一候補とする。具体住所は、登記可否、郵便受領、銀行口座開設、許認可・契約上の制約を司法書士・税理士に確認したうえで、ユーザーが最終決定する。

このメモは事業方針のたたき台であり、登記申請前に商号調査・商標調査・専門家レビューを必ず実施する。

## 採用方針

| 項目 | 方針 | 理由 |
| --- | --- | --- |
| 商号 | 自分株式会社 | 既存プロジェクト名、サイト名、WBS上の事業名と一致し、覚えやすい |
| 英語表記 | Jibun Inc. / Jibun Kabushiki Kaisha | 海外サービス連携・請求書・投資家資料で使いやすい |
| 本店所在地 | 東京都内の法人登記対応住所 | SaaS、資金調達、人材採用、金融機関連携で説明しやすい |
| 生活住所 | 原則として登記に使わない | 代表者のプライバシー、郵便物管理、将来移転コストを考慮 |
| 最終決定者 | ユーザー | 実住所・契約・本人確認を伴うため、手動決裁が必要 |

## 商号確認の手順

1. 法務省のオンライン登記情報検索サービスで、商号と本店所在地の重複を確認する。
2. J-PlatPatで「自分」「ジブン」「Jibun」などの表記・称呼を商標検索する。
3. SaaS、AI、ライフマネジメント、教育、コンサルティング領域の指定商品・役務で衝突リスクを確認する。
4. 司法書士または弁理士へ、登記可能性と商標出願方針を確認する。

## 本店所在地の選定基準

| 基準 | 確認内容 |
| --- | --- |
| 登記可否 | 契約上、株式会社の本店登記が明示的に許可されているか |
| 郵便対応 | 税務署、年金事務所、銀行、取引先からの郵便を安定して受領できるか |
| 銀行口座 | 法人口座開設時に説明しやすい住所か |
| 契約継続性 | 最低1年以上継続でき、短期解約リスクが低いか |
| 移転コスト | 将来の本店移転登記が必要になりにくいか |
| プライバシー | CEO個人住所の公開を避けられるか |

## ユーザー決裁が必要な事項

- 登記に使用する具体住所
- バーチャルオフィスまたは実オフィスの契約先
- 郵便転送、本人確認、銀行口座開設時の提出書類
- 商標出願を法人設立前に行うか、設立後に行うか

## WBS分割

Codex担当の完了条件は、商号・所在地方針と調査手順の整理までとする。

ユーザー担当として、次の手動タスクを別管理する。

> 法人登記用本店所在地の最終選定: 登記可能な住所候補を2件以上比較し、司法書士・税理士確認後に1件へ決裁する。
