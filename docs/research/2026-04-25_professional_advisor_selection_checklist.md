# 司法書士・税理士契約チェックリスト

作成日: 2026-04-25

## 目的

株式会社設立前に、司法書士と税理士へ確認すべき事項を整理する。

このタスクは契約・本人確認・見積取得を伴うため、最終実行はユーザー担当とする。Codexは比較観点と依頼テンプレートを整備する。

## 司法書士へ確認すること

| 項目 | 確認内容 |
| --- | --- |
| 設立形態 | 発起設立の前提で問題ないか |
| 商号 | 自分株式会社で登記可能性に問題がないか |
| 本店所在地 | 候補住所が登記・郵便・銀行口座開設上問題ないか |
| 事業目的 | AI、SaaS、教育、コンサルティング、メディア、EC、投資家向け説明に耐える目的文言か |
| 株式設計 | 譲渡制限、発行可能株式総数、将来SO・資金調達の前提に合うか |
| 役員設計 | 取締役会非設置会社から開始する場合のメリット・制約 |
| 定款認証 | 電子定款対応、必要書類、実印・印鑑証明の要否 |
| 費用 | 登録免許税、定款認証、司法書士報酬、追加費用の内訳 |
| 期間 | 依頼から登記完了までの標準リードタイム |

## 税理士へ確認すること

| 項目 | 確認内容 |
| --- | --- |
| 資本金 | 信用、消費税、銀行口座、将来調達を踏まえた初期資本金 |
| 役員報酬 | 設立初年度の設定タイミングと変更制約 |
| 決算月 | 事業サイクル、資金繰り、繁忙期を踏まえた決算月 |
| 会計ソフト | MoneyForward、freee、弥生などの推奨と連携方法 |
| 税務届出 | 法人設立届、青色申告、給与支払事務所、源泉所得税の納期特例 |
| 顧問範囲 | 月次レビュー、記帳、給与、年末調整、決算申告の範囲 |
| 資金調達 | Seed/Series Aを見据えた会計・証憑・KPI管理の設計 |

## 相見積り依頼テンプレート

```text
件名: 株式会社設立および創業期顧問のご相談

自分株式会社（予定商号）の設立を検討しています。
AI・SaaS・ライフマネジメント領域で、将来的な資金調達とストックオプション設計も視野に入れています。

以下について見積りと進め方をご教示ください。

1. 株式会社設立手続きの対応範囲と費用
2. 商号・本店所在地・事業目的・定款設計のレビュー可否
3. 設立完了までの標準スケジュール
4. 設立後の税務・会計顧問の対応範囲と月額費用
5. 資金調達を見据えた会計管理・証憑管理への対応可否

候補商号: 自分株式会社
本店所在地: 東京都内の法人登記対応住所を候補として検討中
設立形態: 株式会社 / 発起設立を想定
```

## ユーザー実施タスク

1. 司法書士2社以上へ見積依頼する。
2. 税理士2社以上へ見積依頼する。
3. 本店所在地候補を提示し、登記・銀行口座・郵便受領の観点で確認する。
4. 見積、対応範囲、レスポンス速度、資金調達理解度を比較し、契約先を決める。

## WBS反映方針

`司法書士・税理士契約` はユーザー手動タスクとして扱う。
Codexは本チェックリスト作成までを支援範囲とし、契約実行はユーザーの進捗報告UIで管理する。
