# First User Acquisition Sprint

Date: 2026-06-27 JST

Goal: get one real person to use the site or agree to become the first
Founding Supporter candidate.

This sprint can start before Stripe payout status fully clears, because the
first ask can be usage and feedback. Do not ask for payment until Stripe account
status no longer shows identity review, payout pause, or payout pause risk.

## One-Person Success Definition

Count this sprint as successful when one real person does at least one of these:

- Opens the site and tells you which feature they tried.
- Gives concrete feedback on what problem the site should solve for them.
- Agrees to become the first Founding Supporter once Stripe payout status clears.
- Completes the 100 JPY Founding Supporter Checkout after Stripe status clears.

Do not count your own testing, fake accounts, bot traffic, or anonymous page
views with no human feedback.

## First Persona

Start with people who already understand the pain:

- solo builder / indie hacker trying to coordinate AI tools
- student or learner overwhelmed by AI learning paths
- knowledge worker who wants one dashboard for decisions, learning, and tasks
- friend/contact who will give blunt feedback within 24 hours

## Grilling Rule

If no one replies, the conclusion is not "marketing failed". The conclusion is
that the ask was too vague, the target was too cold, or the promised outcome was
not concrete enough. Rewrite the ask around one painful use case and run another
10 touches.
