## AI Share Workflow

サイト右下の AIシェアを使い、投稿作成の手間を減らす。

1. 宣伝したいページを開く。
2. AIシェアを開く。
3. `ブリーフィング`、`固定`、`課題`、`機能`、`質問`、`返信` のどれかを選ぶ。
4. 画像・動画生成に失敗しても、テキストだけで投稿する。
5. 伸びた投稿には、返信でサイトURLと5分テスト依頼を付ける。

共有URLのUTM:

```text
utm_source=x
utm_medium=ai_share
utm_campaign=first_user_growth
```

## 10K Impression Briefing Pattern

過去の高インプレッション投稿は、汎用的なプロダクト宣伝ではなく、時事性のあるブリーフィングだった。この型をメイン導線にする。

Target: 7日以内に 10K impressions 以上の投稿またはスレッドを1本作る。

Format:

```text
デイリーブリーフィング - YYYY/M/D 朝

1. 【日本政治】見出し
何が起きたか:
なぜ重要か:
見通し:

2. 【国際情勢】見出し
何が起きたか:
なぜ重要か:
見通し:

3. 【経済・市場】見出し
何が起きたか:
なぜ重要か:
見通し:

4. 【AI・テック】見出し
何が起きたか:
なぜ重要か:
見通し:
```

Rules:

- 3-5項目にする。
- 冒頭は情報価値を優先し、プロダクト宣伝をしない。
- Xトレンドは「話題発見」にだけ使う。事実確認なしにニュース内容を捏造しない。
- リンクは本文ではなく返信に置く。
- ハッシュタグは0-2個に抑える。
- 最後の返信で「5分だけ試して、A/B/Cで教えてください」と依頼する。

Recommended categories:

- 日本政治 / 選挙
- 国際情勢 / エネルギー
- 経済 / 市場 / 円安
- AI / ソフトウェア開発 / エージェント運用
- 地方選挙 / 政党動向

## One-User Evidence

1人獲得として数えるもの:

- 実在ユーザーの公開返信で「触った」と分かるもの。
- DMで具体的なフィードバックが来たもの。
- 実在ユーザーの質問スクリーンショット。
- Stripe解除後に支払う意思を示した実在の支援候補。
- 実在支援者によるStripe webhook証跡。

数えないもの:

- 自分のテスト。
- 匿名PVだけ。
- bot traffic。
- いいねだけ。
- live self-payment。

## Payment Conversion

Stripe本人確認・入金停止リスクが解消した後だけ、有料支援へ切り替える。

```text
初期ユーザー向けに Founding Supporter の100円支援リンクを用意しました。
機能の完成度より「継続して改善してほしい」に1票入れる位置づけです。
支援後は、改善予定と実装ログを公開で追えるようにします。
```

## If It Fails

7日でインプレッションは出たがユーザーが増えない場合:

1. 最も伸びた話題だけを残す。
2. 固定ポストをその話題に合わせて書き換える。
3. 「AI OS」という広い表現を減らし、用途を1つに絞る。
4. プロダクト投稿を増やす前に、そのニッチで有益リプライを30件追加する。
