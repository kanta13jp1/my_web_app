# R14 X Profile Conversion Kit

This is the operator-only execution kit for X growth after R11/R12/R13/R13b.

- Per-post quality has been optimized.
- The remaining immediate bottleneck is account-level conversion: profile bio, pinned tweet, and first-30-minute manual actions.
- Do **not** automate profile editing, pinning, replies, likes, DMs, follows, or engagement.

## 1. Bio variants

X bio limit: 160 characters. X URLs are counted as shortened links in the UI, but these variants are kept compact even with the visible URL.

### Variant A — recommended: identity + product + cadence

```text
AIエージェントと二人三脚で「自分株式会社」を毎日ビルド中。家計・資産・給与サイクル・意思決定をまとめる人生OSを作っています。開発ログとツール↓ https://my-web-app-b67f4.web.app/
```

Use this first. It says who you are, what the app does, why to follow, and where to click.

### Variant B — shorter / clearer product promise

```text
個人資産・給与サイクル・意思決定を1画面にまとめる「自分株式会社」OSを開発中。AIと毎日改善しています。触って感想ください↓ https://my-web-app-b67f4.web.app/
```

Use this if Variant A feels too identity-heavy.

### Variant C — build-in-public emphasis

```text
AIと一緒に、家計・資産・仕事ログをまとめる個人用ダッシュボードを毎日ビルド中。失敗も改善も公開します。アプリはこちら↓ https://my-web-app-b67f4.web.app/
```

Use this if the account should look more like a build-in-public account.

## 2. Pinned tweet variants

```text

https://my-web-app-b67f4.web.app/
```

## 3. Screenshot checklist for pinned tweet

Attach one screenshot to the pinned tweet.

Preferred screenshot:

1. Show the app home or finance dashboard, not a blank landing page.
2. Include a visible concrete feature name such as 給料日サイクル / 資産 / 負債 / メモ.
3. Crop away browser noise if possible.
4. Avoid showing private numbers, names, emails, phone numbers, or secrets.
5. Use 16:9 or 4:3; avoid very tall mobile-only screenshots for the pinned tweet.

Alt text:

```text
自分株式会社のWebアプリ画面。家計、資産、給与サイクル、仕事ログ、意思決定を1つのダッシュボードにまとめる個人用OSの開発中画面。
```

## 4. Manual execution steps on X mobile

1. Open X profile.
2. Tap Edit profile.
3. Replace bio with Variant A.
4. Save.
5. Compose pinned tweet Variant A.
6. Attach one screenshot and add the alt text.
7. Post.
8. Open the tweet menu and pin it to profile.
9. For the next 30 minutes, manually reply to real comments only.
10. Do not self-like, auto-reply, DM strangers, follow-churn, or use automation.

## 5. Measurement checklist

For the next 3 posts after the bio/pin change, record:

- profile visits
- follows
- link clicks
- replies asking what the app is
- first-user feedback comments

Interpretation:

- Profile visits up, follows flat: bio/pinned tweet is unclear; simplify product promise.
- Profile visits flat: post hooks still need broader discovery; use OP-2 manual replies.
- Link clicks up, feedback flat: landing screen/first action needs simplification.
- Replies up: pinned tweet is doing its job; convert questions into product copy.

## 6. Red lines

Never automate:

- profile writes
- tweet pinning
- likes
- replies
- DMs
- follows/unfollows
- quote-post targeting
- engagement farming

This kit is for manual copy/paste and measurement only.
