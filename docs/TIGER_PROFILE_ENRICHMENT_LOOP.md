# 虎プロフィール拡充ループ

## 目的

125名の虎について、年齢、肩書き、事業内容、公開された審査観点を段階的に確認し、根拠の強さに応じてレビューへ反映する。未確認情報は推測しない。

## 1回のループ

1. `assets/data/tiger_reviewer_profiles.json` の充実度が低い順に5名を選ぶ。
2. 本人・所属企業・法定開示などの一次公開情報を優先して調べる。
3. 生年月日には根拠URLを必須とし、確認できない年齢は「公開情報未確認」のままにする。
4. Codexの正本 `tiger-personas.json` を更新し、次のコマンドで公開カタログを再生成する。

   ```powershell
   python scripts/tiger_profile_enrichment.py --round <回数>
   python scripts/tiger_profile_enrichment.py --check
   ```

5. Pythonテスト、Flutterモデルテスト、画面テストを通し、公開後にデスクトップとモバイル幅で確認する。

## レビューへの段階反映

| 反映度 | モード | 適用方法 |
| --- | --- | --- |
| 0–49% | `neutral_guarded` | 中立スキャンを優先し、プロフィールは質問候補だけに用いる。 |
| 50–79% | `profile_balanced` | 中立評価を軸に、確認済みの重点観点を補助的に用いる。 |
| 80–100% | `profile_guided` | 中立スキャン後、確認済みの重点観点を指摘の優先順位へ強く反映する。 |

どの段階でも、レーン固有の採点基準は変更しない。本人の意見として断定せず、口調を模倣せず、専門外の事実を推測しない。

## 第2回の反映例

仙石実さんは、所属組織の一次情報で現職肩書きと事業領域を補強し、公開会社の株主総会資料で生年月日を確認した。充実度は45%から65%、レビュー反映度は43%から50%へ上がり、`neutral_guarded` から `profile_balanced` へ移行した。
