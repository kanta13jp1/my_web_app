## WebSearch 補足調査 (WEB版 Schedule Agent / 2026-04-21 00:22 UTC)

### Notion — 2026年4月最新動向

**新機能 (2026-04-14〜17)**:
- **Custom Agents 35〜50%コスト削減**: 繰り返しタスクに強い。AI Autofill でデータベース自動エンリッチメント
- **AI Meeting Notes カスタムインストラクション**: 要約フォーマットをユーザーが設定可能
- **初期ページレンダリング 28% 高速化**
- **Views API (8エンドポイント)**: 相対日付フィルター・見出し4・タブブロック対応。Workers API で開発者がサーバーサイドコード実行可能
- **Mail & Calendar 設定統合** (2026-04-17): 受信トレイとカレンダーを設定タブから一元接続
- **Notion Academy 多言語化**: 日本語・スペイン語・ポルトガル語など6言語対応

**影響評価**: Notion AI の日本語化強化は脅威。ただし財務管理・健康習慣・競馬特化機能は依然 Notion に存在しない。

### Slack — 2026年4月最新動向

**Salesforce が 30 の AI 新機能を発表 (2026-03-31 発表)**:
- **再利用可能 AI スキル**: ユーザーが定義したタスクをあらゆる文脈で再利用
- **Slackbot AI スキルライブラリ**: 既定スキル + カスタムスキル作成
- **Slack MCP サーバー**: AI アシスタントが安全にデータアクセス
- **Semantic Search (Pro 解放)**: キーワードではなく意図で検索
- **Huddles Join Preview**: 入室前にビデオ/音声プレビュー
- **メッセージ転送の予約送信**

**影響評価**: MCP サーバー対応で他 AI エージェントとの統合が容易に。自分株式会社の `slack-hub` 連携計画を加速すべき。

---

### GitHub — 2026年4月最新動向

**Copilot & AI 強化**:
- **Claude Opus 4.7 対応** (GitHub Copilot): 長期タスク・ツール依存ワークフローで精度向上
- **`gh skill` CLI コマンド**: スキルの発見・インストール・管理・バージョン管理をサポート (Public Preview)
- **Copilot CCA**: 組織単位でのアクセス制御

**Actions 強化**:
- サービスコンテナへの `entrypoint` / `command` オーバーライド
- OIDC カスタムプロパティ + VNET フェイルオーバー

**状態ページ刷新** (2026-04-17): インシデント分類システム + サービス別稼働率メトリクスを追加

**影響評価**: `gh skill` の登場は自分株式会社の `.claude/skills/` エコシステムと同方向。GitHub の標準になる前に独自スキル UX を確立する機会。
