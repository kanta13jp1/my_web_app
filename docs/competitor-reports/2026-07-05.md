## 詳細セクション（重大シグナル深掘り）

### 1. 🔴 OpenAI GPT-5.6 Sol / Terra / Luna — 価格判明＋「7/7 Anthropic ambush」報道

- **モデル体系**: GPT-5.6 として Sol / Terra / Luna の3ティアを 6/26 投入。新命名では **数字＝世代／Sol・Terra・Luna＝持続的な能力ティア**（各々が独自 cadence で進化）。
- **価格（per 1M tokens）**: **Sol $5 入力 / $30 出力・Terra $2.5 / $15・Luna $1 / $6**。Opus 4.8（$5/$25）と同レンジで frontier ティア（Sol）が真っ向。
- **提供状況**: **API と Codex で限定プレビュー**。米政府の要請で **約20の信頼パートナー組織に先行**（政府安全審査ゲート）、広域提供は「数週間内」。別途 **Cerebras で Sol を最大 750 tok/s**（select customers）を7月提供。
- **競争タイミング**: 一部報道は GPT-5.6 トリオが **Codex アプリで露出し、Anthropic の 7/7 window を狙った投入** と報じる（#5 の Anthropic 7/7 課金転換と同一週）。
- **自社への含意**: 自社 **L2 lane（VSCode+Codex 実装）**＋`AI_FALLBACK_RUNBOOK`（Claude quota 超過時 Codex CLI 継続）の直接 toolchain 更新に加え、**自社ランタイム自体が Anthropic**（本セッション = Opus 4.8）ゆえ供給側の競争局面を二方向で受ける。`[AI-TOOL-VERIFY]`：GPT-5.6 価格・限定プレビュー・命名は openai.com / help.openai.com で裏取り。**fallback runbook の Codex 経路モデル名を GPT-5.5→5.6 ティア制前提へ棚卸し**を要検討（07-04 アクション2の継続・拡大）。当面は限定プレビューゆえ実運用影響は「数週間内」の広域化まで観察。

### 2. 🔴 MoneyForward AI Cowork — オーケストレーターは Claude／統治3点セット命名確定

- **オーケストレーター = Claude**: チャット入力を **オーケストレーターが意図解釈→傘下 AI エージェントへ振分** する構造で、**オーケストレーターに Claude の推論エンジンを採用**と明示（コーポレート/報道で確認）。
- **統治3点セット（命名確定）**: ①**ガードレール**（意図しない動きの抑制）②**Draft & Approve**（人による最終確認）③**AI 監査ログ**（誰が・いつ・どの AI で操作したかを記録）。
- **事業目標**: 2030 年までに AI 関連で **ARR 150 億円以上**。対象は『マネーフォワード クラウド』既存ユーザー、7 月提供（先行受付中）。
- **自社への含意**: B/S 中核最大脅威の *中身* が判明。決定的なのは **競合のオーケストレーターが自社と同じ Claude で動く** 点＝**モデルでは差別化できない**ことの確定。自社の堀は (a) **統治の深さ**（deny-by-default subagent guard／worktree-isolation／high-risk ultrareview exception／RLS 所有権チェック／cross-instance-pr）、(b) **6部署ドメイン統合＋B/S フレーミング**（家計＝経営、資産負債＝自己資本）に集約する。**MF の「Draft & Approve」は自社の承認ゲートと同型**＝07-03/07-04 で継続する「監査ログは競合も持つ、我々は *統べ方そのもの* を統治する」narrative の必要性が一段と高まった。

### 3. 🟠 Cursor Bugbot 刷新（Composer 2.5 駆動）— push 前コードレビューの製品化

- **Bugbot 刷新**: **高速・低コスト化＋1 run あたり検出バグ増**。**`/review`（push 前レビュー）** に対応、**Bugbot か Security Review を選択**可、**GitHub・GitLab と同期**、**前回レビュー以降の新規差分のみ**をレビュー可能。これらは Composer 2.5 の学習改善で実現。
- **モバイル**: Composer 2.5 実行が **7/5 まで 75% オフ**（mobile app・07-04 既報の延長）。
- **自社への含意**: 自社が *運用* で持つ「**high-risk ultrareview gate**（title+body 走査・exception 必須）＋`/code-review`（push 前・差分レビュー）」を、Cursor は **プロダクトのコードレビュー機能**（`/review`／Security Review 選択／差分限定）へ製品化。07-04 の Cursor iOS remote-control に続き、**自社の統治ゲートが競合製品へ commoditize 進行**。差別化は「gate の *強制力*（PR ブロック・exception 監査証跡）」の明文化で図る。
