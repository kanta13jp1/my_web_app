# 競合モニタリングレポート 2026-04-19

## 概要

14社の競合製品の最新動向を調査。OpenAI Codex がコンピューター操作・インブラウザ・メモリ・90+プラグインの大型アップデートを実施。Claude Code は Routines (スケジュール自動化) とデスクトップリデザインを継続展開中。Notion は Workers for Agents 開発プレビューを拡大。MoneyForward は Fixed Asset Registration AI エージェントをリリース。

## 各社最新動向

### 1. Notion

**動向**: v3.4 Part 2 リリース継続中。Workers for Agents 開発プレビュー拡大。

- **Workers for Agents (開発プレビュー)**: サーバーサイドコードを Notion AI エージェントから呼び出し可能に。プラットフォームとしての拡張性が大幅向上
- **Custom Agents 35-50% コスト削減**: 繰り返しタスク（メールトリアージ等）で大幅なコスト削減を実現。GPT-5.4 Mini / Haiku 4.5 / MiniMax M2.5 対応
- **AI Autofill**: データベースへの AI 自動補完をエージェントが直接実行可能に
- **AI Meeting Notes カスタム指示**: 会議メモ要約フォーマットをユーザーがカスタマイズ可能
- **初期ページレンダリング 28% 高速化**: コンテンツ表示速度が大幅改善
- **Views API 8エンドポイント追加**: 相対日付スマートフィルター・Heading 4/Tab ブロック対応
- **Notion Academy 多言語対応**: 日本語・韓国語・スペイン語等6言語で学習コンテンツを提供
- **アクセス制御強化**: データベース内での「ページ作成のみ」権限の細分化

**自分株式会社への示唆**: Workers for Agents は当社の `ai-hub` EF アーキテクチャと直接競合する領域。サーバーサイドエージェント実行の需要が増大しており、`schedule-hub` の強化優先度を上げる価値あり。

### 2. Evernote

**動向**: タブ機能リリース・AI 機能の継続強化。プラン再編後の安定期。

- **タブ機能**: 複数ノートを同時にタブで開いて並行作業が可能に
- **AI Meeting Notes / AI Assistant / Semantic Search 改善**: 毎月継続的なアップデート
- **テーブル内タスク追加**: テーブルセル内から直接タスクを追加できる新機能
- **リンク表示オプション**: ペーストしたリンクの表示形式 (メンション / リンク / テキスト / プレビュー) を選択可能
- **モバイルカメラ改善**: 撮影・保存フローを最適化
- **絵文字検索**: `:` を入力して絵文字をインライン検索
- **プラン再編**: Personal / Professional を廃止し Starter / Advanced に統一

**自分株式会社への示唆**: タブ機能は当社ノートページに検討余地あり。リンク表示オプションのような細粒度 UI 制御はユーザー満足度向上に寄与する可能性。

### 5. Claude Code (Anthropic)

**動向**: Routines (スケジュール自動化)・デスクトップリデザイン・Claude Design リリース。

- **Routines (4/14)**: スケジュールと繰り返し自動化機能。Claude Code のウェブインフラ上で実行するため Mac の起動不要
- **デスクトップリデザイン**: サイドバーで複数セッション管理・ドラッグ&ドロップレイアウト・統合ターミナル・インアプリファイルエディタ・改良 diff ビューア・HTML/PDF プレビューパネル
- **Claude Design リリース (4/17)**: クイックビジュアル作成に特化した新製品を TechCrunch が報道
- **Prompt Caching 制御**: 1時間・5分の TTL 制御オプションを追加
- **Session Recap**: セッション再開時のコンテキスト要約機能
- **Skill Tool**: 組み込みスラッシュコマンドへの Skill tool アクセス
- **/team-onboarding**: Claude Code の使用履歴からチームメンバー向けオンボーディングガイドを自動生成

**自分株式会社への示唆**: Routines は当社の `schedule-hub` + CronCreate との競合。Claude Code の進化はプラットフォームとしての競争力を示す。Skill Tool は当社の独自スキル戦略と同方向。

### 6. OpenAI Codex

**動向**: コンピューター操作・インブラウザ・メモリ・90+プラグインで大型アップデート (4/17)。

- **Computer Use (Background)**: 複数の AI エージェントが Mac 上でアプリを操作・並行実行。ユーザーの作業を妨げずにバックグラウンドで動作
- **In-App Browser**: ローカル/パブリックページを直接開いてコード編集 → ページレビューのフィードバックサイクルが完結
- **Memory プレビュー**: 過去のタスクからユーザー設定・修正・情報を記憶し、次回タスクの品質向上
- **画像生成**: gpt-image-1.5 統合。デザインモックアップ・フロントエンド設計・ゲーム内でビジュアル生成
- **90+ 新プラグイン**: Atlassian Rovo・CircleCI・CodeRabbit・GitLab Issues・Microsoft Suite・Neon・Remotion・Render・Superpowers 等
- **GPT-5.3-Codex-Spark**: 1000 tokens/sec 以上の高速コーディング向け小型モデルプレビュー
- **SSH リモートデブボックス接続**: リモート開発環境へのダイレクト接続

**自分株式会社への示唆**: Codex の Computer Use 機能は RPA 領域への本格参入を示す。Claude Code vs Codex の競争激化により、両ツールの新機能取り込みサイクルが加速。当社の `ai-hub` でのコーディングエージェント統合を検討する価値あり。

### 7. Slack

**動向**: AI DLP・MCP サーバー統合・Slackbot プロンプト共有・CLI v4.0 リリース。

- **MCP サーバー統合**: Claude・Cursor 等の AI アシスタントが Slack データに安全アクセス可能に。会話検索・メッセージ送信・キャンバス作成を自然言語で実行
- **組み込み DLP ルール**: API トークン・Webhook・アクセスキー等の機密情報を自動スキャンしてセキュリティ保護
- **Slackbot プロンプト共有**: 便利な Slackbot プロンプトをチームのチャンネル・DM に転送し再利用可能に
- **Slack CLI v4.0**: AI エージェントテンプレートに IT サポートエージェント (`slack create agent`) を追加
- **メッセージ転送スケジューリング**: メッセージ転送時に送信時刻を指定可能
- **Org-Level User Groups**: 組織レベルのユーザーグループで IDP グループを変更せずに権限・チャンネル管理

**自分株式会社への示唆**: MCP サーバー統合は当社の「Slack 競合機能統合」方針に影響。Slack が MCP Hub 化することで、小規模競合との差別化が縮小する可能性。
