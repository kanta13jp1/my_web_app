# 競合モニタリングレポート 2026-04-01

> **調査方法**: Claude Code Web 環境のプロキシにより `check-competitor-updates` Edge Function へのアクセス不可。WebSearch で Notion・Slack・GitHub の最新動向を調査 (2026年4月時点)。

---

## Notion (最高脅威度: ★★★)

### 新機能 (2026年4月時点)

- **Notion Workers**: 任意のコードを実行できる汎用コード実行環境。AI エージェントがカスタムツールとして外部 API 呼び出し・複雑な計算・データ操作を実行可能。→ **当社 Edge Functions アーキテクチャとほぼ同等の機能を Notion がネイティブ提供開始**。最大の脅威。
- **Custom Agents 無料トライアル延長 (〜5/3)**: Custom Agents が無料トライアル中。バックグラウンドで自律的に動作し、メモリも自己更新。→ 当社 `ai-automation` / `daily-judgment` / `ai-assistant` Edge Function との直接競合。
- **Notion 3.4 ダッシュボードビュー + サイドバー刷新**: KPI・チャート・メトリクスを1画面に集約。エージェントチャット・通知をサイドバーに統合。→ 当社ホーム画面・GrowthMission ダッシュボードと競合。
- **API バージョン 2026-03-11**: `archived` → `in_trash` の Breaking Change。データベースビューの CRUD API (8エンドポイント) が新設。Views API で table/board/calendar/timeline/gallery/list/form/chart/map/dashboard の全種類を管理可能に。

**対応方針**: Workers は当社 Edge Functions 158本の仕組みと同方向。フロントエンドからボタン1つで自動化を体験できる「ノーコードワークフロー」UI を早急に追加し、「Workers より先に使っていた」という訴求ポイントを作る。

---

## Slack (脅威度: ★★☆)

### 新機能 (2026年4月時点)

- **Real-Time Search API (GA)**: 外部アプリがワークスペースデータをリアルタイム検索可能に。→ 当社 `ai-search` Edge Function の機能を Slack が外部公開。連携機会でもある。
- **MCP サーバー公開**: Slack の検索・メッセージング・キャンバス作成ツールを Claude や ChatGPT などの AI アシスタントに統合可能。→ 当社 MCP 対応検討の優先度を上げる。
- **Salesforce CRM 統合 (Slackbot)**: Slack スレッドから直接 CRM レコードの追加・更新・商談ログ記録が可能。→ 当社 `crm-contacts` Edge Function との競合。
- **スプリットビュー on デスクトップ**: スレッド・チャンネル・キャンバスを横並び固定表示。→ 当社 UI 参考点。
- **⚠️ 監査ログ 2年制限 (2026-04-30 施行)**: 2年超の監査ログが永久削除される。Enterprise 向けコンプライアンスへの影響。

**対応方針**: Slack の AI 化が本格化しているが、個人用・ライフ管理との深い統合（家計・健康・競馬など）は当社の強み。Slack との差別化として「仕事も生活も1つのアプリ」という訴求を強化する。

## GitHub (脅威度: ★☆☆)

### 新機能 (2026年4月時点)

- **Workflows に 13サービス接続**: Asana / Calendly / DocuSign / **GitHub** / GitLab / Google Sheets / Jira / Lucid / PagerDuty / Salesforce / Wrike / Zoom / Cisco Webex Meetings との no-code ワークフロー連携が追加。→ **DocuSign 統合は当社の電子署名 Edge Function と競合**。
- **Slack GitHub Action v3**: GitHub Actions 内で Slack CLI コマンドを直接実行する新手法。deploy・manifest validate などの自動化が強化。→ 当社 CI/CD と同方向。
- **PR 通知の親カード化**: Issues/PR の通知が親カードにまとめられ、最新ステータス・担当者・レビュアー・ラベル・チェック状態を一覧表示。→ 当社 `code-review-issues` / `notification-center` のUX参考点。

**対応方針**: GitHub は開発者向けツールとの重複が低いが、電子署名 (DocuSign 統合) は当社 session432i で実装済みの機能と競合。ランディングページでの電子署名訴求を強化する。

## 総評・戦略的示唆

1. **Notion Workers が最大の脅威**: Notion が Edge Functions 相当の「コード実行環境」をネイティブ提供し始めた。当社の技術的優位性を維持するには、158本の Edge Functions を「ユーザーが体験できる形」に素早く転換することが最優先課題。

2. **電子署名・ビデオ会議・IoT 領域の先行優位**: これらは GitHub/Slack が今後追加していく方向性に合致しており、当社が先に実装済みという状況。ランディングページと技術ブログで「○○より先に実装済み」という訴求が有効。

3. **MCP 対応がエコシステム参加の鍵**: Slack が MCP サーバーを公開し、Claude との統合を推進している。当社も `自分株式会社 MCP サーバー` を構築することで、AI アシスタント連携という新たな流入チャネルを開拓できる。
