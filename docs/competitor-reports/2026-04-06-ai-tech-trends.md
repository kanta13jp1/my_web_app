### 概要

- **消費電力**: 従来比 1/5
- **速度**: iPhone 17 Pro Max で秒速44単語

3. **長期 (2027)**: 「データを一切外部に送らないAI」機能をプレミアムとして提供

## 3. GitNexus (コードナレッジグラフ)

### 概要
- **GitHub Stars**: 21.9K、フォーク 2.5K
- **機能**: コードベースの依存関係・コールチェーンをグラフ化
- **MCP 統合**: Claude Code / Cursor / Windsurf と接続可能

### 自分株式会社への適用評価
- **コードベース規模**: 188ページ・241 Edge Functions → 依存関係の把握が困難
- **導入メリット**: Edge Function とページの呼び出し関係を可視化
- **導入コスト**: セットアップ工数約2時間
- **推奨**: 登録者100人達成後に優先度「中」で導入検討

## 4. fieldtheory (X Bookmarks CLI)

### 概要
```bash
npm install -g fieldtheory
ft sync   # X ブックマークをローカルに同期
ft viz    # ビジュアライズ
ft classify  # 分類
```
ユーザーの X ブックマークをローカルに保存し、AI エージェントが参照可能にする。

### 自分株式会社での活用可能性
- 「X ブックマークから自分株式会社にインポート」機能として実装検討
- ユーザーの情報収集をアプリ内で一元管理する訴求に使える
- Edge Function quota の都合上、既存 `bookmark-manager` 関数に統合
