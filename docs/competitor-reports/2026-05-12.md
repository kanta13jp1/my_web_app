## 詳細セクション (重大シグナルのみ深掘り)

### 1. GitHub Copilot **5/8 Agents 専用 secrets/variables** (= 自社 [MCP-AUTH-27] + [AI-DEV-23] 直接競合 / 重大)

5/8 changelog。`Actions` / `Codespaces` / `Dependabot` に並ぶ **第 4 種別** として `Agents` 専用 secrets/variables を分離。**org-level 初対応** = 1 secret を組織内全 repo に共有可能。repo-level も dedicated section へ分離。各 secret は対象 repo 個別選択可。

- **自社対比**: 自社 secret 管理は **GHA repository secrets + Supabase Edge Function secret + Firebase config** の **3 層分散**。rotation runbook は month-1 cadence で **手動 PR ベース**。Copilot は **org admin 1 設定で全 repo 適用** = scaling UX 圧倒的優位。
- **自社優位**: 自社 [MCP-AUTH-27] 10 原則 (= deny-by-default + 監査) は **vendor 横断 (= Win Claude + Win Codex + Copilot 将来)** で実装 = 単一 vendor lock-in 回避。
- **取込候補 (= mid 期 / 設計 spec)**: 自社 secret 群を `actions-only` / `agents-only` / `bot-only` の **3 namespace 化** + Win Codex 用 token と GHA cron 用 token を **separate scope** に分離 + rotation cadence を月 1 → **secret 種別ごと differentiated cadence** (= agent-only は week-2 / actions は month-1)。担当 = Win Codex (実装) / 期限 5/22 目安 / `docs/cross-instance-prs/20260512_agent_secret_namespace.md` で起票候補。

### 2. Devin **5/8 Devin Review API (REST) + Datadog MCP** (= 自社 cross-instance-pr + 可観測性軸 直接競合 / 中-重)

5/8 docs.devin.ai release notes。`POST /reviews` で外部 trigger 化 + Review UI から PR close + draft 変換 + Datadog Remote MCP Server (OAuth) を MCP marketplace に追加 (= dashboard + metrics 直接 query) + ACP Summarizer (= session summary 自動生成 API)。

- **自社対比**: 自社 cross-instance-pr は **md doc 起票 + git log + WBS sync** の **3 軸 manual workflow**。Devin は **REST API 1 call** で外部 CI/CD (= GHA / Jenkins / CircleCI) から trigger 可能。可観測性は自社 GHA cron + JSON log + Schedule cron の **filesystem-based audit**。Devin は **Datadog SaaS native** で **metric/log/trace 統合 UX** 完成形提示。
- **取込候補 (= short 期 / dogfood)**: 自社 `notebooklm` CLI 経由で ACP Summarizer 類似の **session summary skill 自動化** (= 既存 `/wrap-up` skill の output を NotebookLM へ post)。Datadog MCP は自社 OPEX 観点で導入見送り → **GHA workflow_run + jq 集計の dashboard 自動化** で代替候補。担当 = Win Claude (設計) / 期限 5/19 目安。

### 3. Replit **5/7 Security Center bulk remediation** (= 自社 [VIBE-30] + [AI-DEV-23] 整合 / 中)

5/7 blog.replit.com。全 published project の active critical vulnerability を **bulk 数秒 remediation** 化。posture dashboard で project 横断 visibility。

- **自社対比**: 自社 critical vuln 対応は GitHub Dependabot + Snyk (= 月 1 review) + GHA `npm audit` (= PR trigger)。Flutter `pub` 依存 + Deno EF deps の critical vuln 専用 cron は **未実装**。
- **取込候補 (= mid 期 / GHA cron 追加)**: `pubspec.lock` + Deno EF `import_map.json` の critical vuln 検知を **daily cron 化** + Win Codex 自動 fix-PR 起票 spec。担当 = Win Codex (実装) / 期限 5/26 目安。
