- **Notion Developer Platform**: CLI・Agent SDK・External Agents API (Alpha)・Webhook triggers・Markdown API を公開。自社 API (Notion Developer Platform 対抗) との競合が直接激化。
- **評価**: メインレポートの「Notion (7-16)」記載は最終確認日であり、7-1 と 7-8 の発表は **7-24 窓では新規デルタなし**。ただし Developer Platform の継続展開は **自社 API v1 との差別化の緊急性を上げる**。

### Slack — Block Kit 拡張 / Salesforce 統合 / 一時参加機能

- **Salesforce 統合強化**: Slackbot が Salesforce エコシステム全体にアクセス可能に。自然言語で Slack 内から Salesforce アクション実行。
- **Block Kit 新コンポーネント (6 種)**: alert / card / carousel / data table / data visualization / container を追加。開発者向け UI 拡張性が大幅拡充。
- **一時チャンネル参加**: 1日・48時間・1週間の期限付きで public チャンネルに参加 → 期限後自動退出。サイドバー整理の UX 向上。
- **Status スケジュール設定**: 離席メッセージ・ステータスを事前予約設定可能に。
- **Slack Connect 自動承認 (7-28 ロールアウト / 8-31 発効)**: 新チャンネルリクエストの自動承認ルール設定。
- **評価**: 本日時点で **Slack の新規デルタは 7-21 以降なし** (メインレポートと合致)。上記は 7 月前半の蓄積機能。Block Kit 拡張は開発者エコシステムへの投資継続を示す。

### GitHub — Code Quality GA / Issue Fields GA / Copilot Canvas

- **Code Quality GA (7-20)**: $10/active committer/月 の有料 GA。AI 駆動コード品質分析が全組織に展開。メインレポートの記載を **WebSearch で二次確認**。
- **Issue Fields GA**: Free〜Enterprise Cloud の全ティアで priority/effort/date/カスタム値の構造化メタデータが GA。自社 GitHub Issue Fields 相当機能の差別化優位性が縮小。
- **Copilot Metrics Dashboard**: Enterprise/Org レベルの Copilot 採用状況ダッシュボード。コホート分析・採用深度・トレンド・推奨ネクストアクションを提供。
- **Copilot App + Canvas Workspace**: デスクトップ版 Copilot App で人間と AI エージェントが計画・PR・デプロイ・WF をリアルタイム共同作業する Canvas を提供。
- **PR Archiving**: リポジトリ admin が PR をアーカイブ可能に (closed/locked/admin のみ閲覧/`is:archived` で検索)。
- **評価**: GitHub Models 7-30 退役 (メインレポート アクション #7) + Code Quality GA + Issue Fields GA の 3 重変化。自社の構造化タスク管理機能 (GitHub Issue Fields 相当) は Issue Fields GA により **差別化要素が弱まった**。AI 大学コンテンツ内 GitHub Models 参照の修正 (残り 6 日) は引き続き最優先。
