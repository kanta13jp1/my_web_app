## 詳細セクション（重大シグナル深掘り）

### 1. 🟠【本日実行】Anthropic Fable 5 課金転換（7/7）+ 公式 "Redeploying Fable 5"

- **事実（`[AI-TOOL-VERIFY]` / Anthropic 公式 + 複数大手）**: **本日 2026-07-07** で Fable 5 は Pro/Max/Team/select Enterprise の **subscription 含有（週次上限の 50% まで）が終了**し、**7/8 以降は従量 credit**（$10/1M 入力・$50/1M 出力＝Opus 4.8 の $5/$25 の *ちょうど2倍*・現行価格表で最高額モデル）へ移行。Settings → Usage で有効化・上限設定。
- **公式 "Redeploying Fable 5"**: Anthropic は Fable 5 が **恒久的に subscription を離れるわけではない**とし、「**容量が許し次第、標準 subscription の一部として復帰させることを目指す**」と明言。**新しい usage limit + safeguard** 付きで再展開。提供面は Claude.ai / Claude Code / Claude Cowork / Claude Platform。
- **自社への含意**: 自社は **Opus 4.8 上で稼働**＝Fable 5 非依存。ただし本日は [[project_20260615_anthropic_billing_split_model_retire]]（programmatic Claude の Credit Pool 分離 + 旧モデル退役）の *実行日* に相当。**(a)** 自社の GHA / Schedule cron（一部 Claude 依存）の予算・overflow billing 影響を **本日〜7/9 に確認**。**(b)** Fable 5 の従量化（$10/$50）が **誤って cron 経路に混入しない**よう Settings → Usage の上限設定を点検。**(c)** Sonnet 5 の Opus 近接×$2/$10 導入価格（〜8/31）は cron コスト最適化の *現実的選択肢*（`PROMPT_CACHING_OPUS47_COST_GUIDE` 延長）として引き続き memo。

### 2. 🟠 White House 主導の frontier model 自主基準（week of July 7 発表可能性）

- **事実（`[AI-TOOL-VERIFY]` 済 / 報道ベース）**: White House が frontier model リリースの **自主基準（voluntary standards）**を AI 各社と最終調整中で、**「week of July 7」に発表**される可能性。**Anthropic が合意したフレーム**が他ラボへ求められる雛形となり、**8/1 の自主基準発表**へつながる見込み。**Google は Gemini 3.5 Pro 等の先進コーディングモデル投入前に協議中**。
- **背景との接続**: GPT-5.6 の「**約20の政府審査済パートナー限定**プレビュー」（6/2 行政命令の 30 日能力評価ゲート）と同一の *安全審査レイヤー* が、業界横断の **自主基準へ標準化**する流れ。
- **自社への含意**: 直接の製品競合ではないが、**ベンダー供給側に規制ゲートが常設化**する構造変化。自社 `AI_FALLBACK_RUNBOOK`・`DEV_PROCESS_MULTI_AI` の「数週間内 GA」観察は、モデル GA が **審査ゲート通過に律速される**前提で継続。fallback ポートフォリオ（Claude / Codex / Gemini / Copilot）の *GA タイミング不確実性* を織り込む。

### 3. 🟢 OpenAI GPT-5.6 Sol × Cerebras 750 tok/s（7月）

- **事実**: OpenAI は **GPT-5.6 Sol を Cerebras 上で最大 750 tokens/sec**（7月）で提供開始し「frontier intelligence を前例のない速度で」と告知。GA は依然 **「coming weeks」で firm date なし**・ChatGPT 未提供・価格据置（Sol $5/$30・Terra $2.5/$15・Luna $1/$6 per 1M）。
- **自社への含意**: 07-06 の「提供状況変化なし」に **推論速度パートナーシップ**の新レイヤー。fallback matrix のティア（Sol/Terra/Luna）に *スループット* という新軸が加わる。自社 cron の latency 敏感タスク（例: X-share 生成のポーリング予算）では将来の選択肢だが、**限定プレビュー継続**ゆえ観察フェーズ維持。

### 4. 🟠 Google Gemini 3.5 Pro 遅延（~7/17 leak）+ Antigravity テスターが弱点指摘

- **事実**: Gemini 3.5 Pro は **6 月ターゲットを逃し 7 月 GA へ**。leak は **7/17 target**。late June 時点で **Vertex AI enterprise preview + Antigravity + LMArena** の限定テスターのみアクセス可で、**long / complex multi-step タスクの扱いにギャップ**が指摘され GA を後ろ倒し。2M-token context + Deep Think 推論モード。Google は **時価総額 ~$225B 減 + talent exodus** 報道。
- **自社への含意**: 採択済 discovery #25（Google Jules / Antigravity）の続報。**自社 L1 lane（Antigravity+Gemini 探索）の実効投入時期が ~7/17 へ**。agentic 長時間タスクの弱点指摘は、L1 探索レーンの期待値を「探索・アイデア出し」に留め、実装は L2/L3（Codex/Claude）に寄せる現行運用の妥当性を裏付け。

### 5. 🟠 MoneyForward AI Cowork — 本月（7月）ローンチ月・機能詳細判明

- **自社への含意**: **最大の B/S 中核脅威が本番化フェーズへ**。特に **「業務提案」**（proactive task suggestion）は自社の給料日サイクル提案・アクション提示と *機能思想が正面競合*。ただし MF は **法人の経理・労務バックオフィス特化**＝自社の「6部署×B/S の **個人向け統合ドメインモデル**」（家計・資産・キャリア・投資を跨ぐ）とは対象ドメインで棲み分け。**go-live の実確認**（実プロダクトへのアクセス可否・料金）を次 run で継続。
