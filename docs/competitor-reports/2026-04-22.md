### 🟠 Notion AI Workers for Agents — Enterprise で更に強化

**更新内容** (2026-04-09〜14):

- Workers が **コード実行**をサポート (外部API呼び出し・データ変換)
- カスタムエージェントのコスト **35〜50%削減** (軽量モデル対応)
- Calendar + Mail + Slack 統合が **全エディション** で利用可能に

**制限** (継続中):
- Workers は Enterprise のみ (30秒 timeout / 128MB メモリ)
- GA タイムライン非公開

**評価**: 機能は強化されているが Enterprise 壁が継続。個人ユーザーへの直接影響は限定的。

---

### 🟠 GitHub Copilot Autopilot — 開発者向け自律エージェント GA

**ステータス**: CLI GA / VS Code Public Preview (2026-04)

**機能**:
- CLIでの自律タスク実行 (ステップ間の手動確認なし)
- リモートセッション: plan → interactive → autopilot モード切替
- 自動モデル選択 (タスクに最適なモデルを自動判断)

**自分株式会社への影響**:
- **対象ユーザーが開発者ならば間接的競合**
- 「コーディング以外の日常タスク」管理は Copilot の対象外
- 自分株式会社ユーザーが開発者なら「Copilot でコード、自分株式会社で人生管理」の併用が自然

**評価**: 直接競合なし。ただし「AI エージェント = Copilot で十分」という認知リスクに注意。
