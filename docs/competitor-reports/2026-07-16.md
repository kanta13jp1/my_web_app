- **Copilot `/security-review` コマンド (public preview)**: インフライトコード変更のセキュリティスキャンを Copilot アプリから直接実行。重大度・信頼度スコア付きで修正提案。
- **Agentic ブラウザツール GA**: エージェントがページナビ・コンテンツ検査・スクリーンショット取得を実行。並列エージェントセッション + 1 セッション複数チャット対応。
- **PR ダッシュボード刷新 GA**: レビューリクエスト + CI ステータスのインボックス、保存ビュー、高度フィルタ。
- **Copilot CLI**: 音声デバイス選択の永続化、Canvas サポート、サブエージェントコントロール強化。
- 含意: GitHub は dev-tool を超え「セキュリティ + ブラウザ操作 + 並列エージェント統治」へ拡張中。自社の fleet / schedule 運用との差別化軸は「個人 CEO 経営メタファー」のみ（技術アーキテクチャではなくナラティブ）。
