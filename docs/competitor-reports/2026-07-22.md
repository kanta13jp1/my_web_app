**事実 (一次 verbatim / [rust-v0.145.0](https://github.com/openai/codex/releases/tag/rust-v0.145.0))**:

**なぜ効くか**: 自社の `cross-instance-pr` は **md ドキュメント + git log の監査証跡**で Win Claude ↔ Win Codex を橋渡しする設計で、その存在理由は「**両者が直接状態を共有できないこと**」だった。`/import` はこれを **Codex 側から一方向に解消**する。しかも移行対象に **`project-scoped memories` が含まれる** — 自社は `memory/` を Karpathy 4 サイクルの中核資産として運用しており、**「どちらのツールに記憶が属するか」が初めて争点になる**。

**含意 (ナラティブ)**: 「並列できる」→「**並列を監査可能に統治する**」という既定のピボットに、**もう一段**足す必要がある。すなわち「**状態の移行が容易になったからこそ、どの状態が正本かを決める規律 (= 5 正本 + OPERATIONS_CHARTER) が差別化**」。移行の容易さは競合が提供するが、**正本の規律は自社が持つ**。
