## Notion — 最重要競合

**Notion 3.4 アップデート (継続注目)**

- **Dashboard View**: チャート・KPI・メトリクスを1ページに集約するダッシュボードビュー。自分株式会社の経営コックピット機能と直接競合。
- **Redesigned Sidebar**: サイドバーを4タブ (Pages/Agent chats/Meetings/Notifications) に再編。カスタマイズ性向上。
- **Presentation Mode**: ページをそのままプレゼン化 (⌘+opt+p)。自分株式会社にない機能。
- **Tabs Block**: 1ページ内でタブ切り替えコンテンツ管理。長ページ問題の解決策。
- **Page Archiving**: 削除と保持の中間オプション。ページの誤削除防止。
- **Custom AI Agents**: バックグラウンド自律動作・自己メモリ更新 (前回レポートより継続)。**最大競合脅威**。
- **/v1/views API**: DB ビューのプログラマティック管理 (8エンドポイント)。

**自分株式会社への影響**: Dashboard View + Custom AI Agents の組み合わせが「経営コックピット × AIエージェント」で直接競合。「マイAIエージェント」MVP の早期実装が引き続き最優先。

## Slack (Salesforce) — 主要競合

**30 新AI機能発表 (2026-03-31〜04-01)**

- **Reusable AI-Skills**: 再利用可能な AI スキル定義。スラッシュコマンドで業務フローを自動実行。
- **Meeting Intelligence**: Zoom/Google Meet/Slack Huddles の会議を自動録音・要約・アクションアイテム生成。
- **MCP Client (Slackbot)**: Slackbot が MCP クライアントとして外部サービス・Agentforce と連携。
- **Native CRM**: Slack 内にネイティブ CRM 統合。チャンネルから商談・連絡先を自動更新。
- **Built-in DLP**: シークレットスキャン・データ漏洩防止ルール内蔵。
- **AI assistants bridge via Slack MCP server**: 安全な外部 AI アシスタント連携。

**自分株式会社への影響**: Slack の「チャット × CRM × 会議録音 × AIエージェント」統合が加速。Chatwork 競合機能の強化に加え、会議録音・要約 UI の追加検討が必要。

## GitHub Copilot — 開発者ツール競合

**2026-04-02 発表**

- **Copilot SDK Public Preview**: Copilot のエージェント機能を外部アプリに組み込める SDK。Node.js/TypeScript/Python/Go/.NET/Java 対応。カスタムツール・エージェント定義・ストリーミング・マルチターンセッション。
- **Organization Custom Instructions GA**: 組織全体で Copilot の振る舞いを統一指示できる機能が GA。
- **データポリシー変更 (4/24〜)**: Copilot Free/Pro/Pro+ ユーザーの操作データを AI 学習に使用 (オプトアウト可)。Business/Enterprise は対象外。

**自分株式会社への影響**: Copilot SDK により外部アプリへの AI 統合が容易になり、競合アプリが Copilot 機能を取り込む可能性が増大。自分株式会社の「コードプレイグラウンド」への Copilot-like AI 支援機能統合を検討。
