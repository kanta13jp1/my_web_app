### 🔴🔴 最重要新規脅威: Slackbot 完全 AI エージェント化 (Salesforce)

**発表日**: 2026-03-31 / ロールアウト開始: 2026-04

| 項目 | 内容 |
|------|------|
| 新機能数 | 30+ |
| 技術基盤 | **Anthropic Claude** (自分株式会社と同じ!) |
| アーキテクチャ | **MCP client** 化 — Agentforce + Google Workspace + Microsoft 365 + Notion + Workday + 6,000+ 外部アプリ連携 |
| 目玉機能 | **Reusable AI Skills** — ワークフローを名前付きで保存 → 次回自動実行 (自分株式会社の `schedule-hub`/`tools-hub` action と同じ発想) |
| デスクトップ agent | 会議文字起こし + ユーザーのデスクトップ活動監視 |
| 提供 | Business+/Enterprise+ 即時 / Free・Pro は段階 |

**自分株式会社への影響**:

| 既存機能 | 脅威度 | 対応方針 |
|---------|-------|---------|
| `ai-hub` (MCP 相当 routing) | 🔴 高 | Slack Bot の MCP client が多機能化 → 差別化軸を「6部署balanced」「人生フレームワーク」に明示 |
| `schedule-hub` action (reusable) | 🔴 高 | reusable skill 概念は同じ。**日本語UI+個人特化**が差別化 |
| `tools-hub` | 🟡 中 | Slack 内完結ワークフローには勝てない → **tools-hub は Slack 連携 MCP として提供**の選択肢 |

**戦略転換の示唆**: Slackbot が chatwork/slack 層を完全に AI 化した今、自分株式会社の強みは:
1. **個人 CEO 視点** (Slack は組織単位・Slackbot は企業契約ベース)
2. **人生 6 部署統合** (仕事だけでなく健康・財務・学習を一元管理)
3. **価格=無料/個人向け** (Business+ は $15/seat/月〜)

**cross-instance-pr 発行候補** (PR本文は次の通り):
- 宛先: VSCode版 (LP `comparison_page.dart` 更新)
- 内容: Slack 比較行を「企業向け Slackbot (¥$15/seat~) vs 個人向け 自分株式会社 (無料)」に更新
