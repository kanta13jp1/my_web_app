## Notion — 脅威度 ★★★★★

### Notion 3.4 主要アップデート

**ダッシュボードビュー**
データベースのチャート・KPI・メトリクスを1画面に集約できる新ビューが追加。リンクドビューの代替として大幅にUXが向上。

**プレゼンテーションモード (Beta)**
ページから直接プレゼンテーション可能に。Plus/Business/Enterprise ユーザー向けにベータ提供。ショートカット: ⌘+Opt+P (Mac) / Ctrl+Alt+P (Windows)。

**Custom AI Skills & Custom Agents**
- カスタムスキル: 繰り返しAIタスクをコマンド化・チーム共有可能
- Custom Agents: 無料トライアル 〜2026年5月3日まで延長
- 自律バックグラウンド動作・自己メモリ更新機能あり

**Notion Workers (コード実行環境)**
AIエージェントが実行できるカスタムツールを開発者が作成可能。外部API呼び出し・複雑な計算・データ操作を任意コードで実装できる。

**開発者API v2026-03-11**
- `/v1/views` API 追加 (ダッシュボード/フィルター/ソート管理)
- `archived` → `in_trash` へのエンドポイント変更
- Heading 4 ブロック・タブアイテムアイコン追加

**Notion Academy 多言語対応**
日本語・韓国語・スペイン語・ポルトガル語・フランス語・ドイツ語で認定プログラム開始。日本市場への浸透加速が懸念。

### 自分株式会社への影響
- Workers によるコード実行環境は、当社のEdge Functionアーキテクチャと直接競合
- Custom Agents の無料開放で「AIが自動化してくれる」体験の敷居が急低下
- 日本語Academy開始で国内ユーザーの Notion 定着率が上昇リスク

## Slack — 脅威度 ★★★★★

### Salesforce による30新機能発表 (2026-03-31〜04-01)

**Slackbot の高度AIエージェント化**
- 繰り返しタスクを自動化する「再利用可能AIスキル」ライブラリ
- MCP (Model Context Protocol) クライアント対応: 外部サービスと連携
- 会議の文字起こし・要約・アクションアイテム自動抽出
- デスクトップアクティビティ監視: 習慣・カレンダー・ディールを分析して提案

**Real-Time Search API GA**
外部アプリがSlackワークスペースのデータをリアルタイム検索可能に。

**MCP Server for Developers**
Claude・ChatGPTなど外部AIアシスタントからSlack検索・メッセージング・Canvas作成が可能に。

**その他機能**
- Agentforce (Salesforce AI) をチャンネルに追加可能
- シンプルレイアウトモード (アクセシビリティ向上)
- VIP通知リスト
- 送信済みメッセージのファイル添付編集

**ネイティブ顧客管理**
チャンネルを学習し、ディール・連絡先・通話メモを自動更新。

### 自分株式会社への影響
- AIエージェント統合・MCP対応は当社の「21競合統合」コンセプトに最も近い
- Slackがビジネスチャットから「AIワークスペース」に進化することで競合領域が拡大
- ただし当社は個人・中小向けに特化しており、エンタープライズ寄りのSlackとは差別化余地あり

## GitHub — 脅威度 ★★★★☆

### Copilot Agent Mode + MCP 全展開

**Copilot Agent Mode**
Microsoft 50周年を機に、Agent Mode + MCP support を全VS Codeユーザーに展開。

**Copilot Pro+ プラン新設**
- プレミアムリクエスト追加
- Anthropic / Google / OpenAI モデルのGA
- Next Edit Suggestions (コード補完強化)
- Copilot コードレビューエージェント

**Copilot 組織全体コードレビュー**
ライセンス未割り当てユーザーを含む全PRに対してCopilotコードレビューが有効化可能に。

**パートナービルドCopilotエージェント**
デバッグ・セキュリティ・自動化ワークフローを担うパートナー製エージェントが利用可能に。

**新埋め込みモデル**
VSCode のコード検索が高速化・省メモリ化・精度向上。

**セキュリティキャンペーン**
一度に最大1,000件のアラートに対して自動修正を生成するセキュリティキャンペーン機能。

**Actions 2026ロードマップ**
セキュアデフォルト・ポリシーコントロール・CI/CD可観測性を強化。

**データポリシー変更 (2026-04-24〜)**
Copilot Free/Pro/Pro+ のインタラクションデータをAIモデル訓練に使用開始 (オプトアウト可)。

### 自分株式会社への影響
- Copilot が開発者向けAIエージェントとして進化中。エンジニア向けツールとしての競合は間接的
- GitHub Actions の強化は CI/CD 基盤として当社開発効率にも寄与 (プラス面)
- 開発者ユーザーを取り込むなら GitHub 連携強化が有効
