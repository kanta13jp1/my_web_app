## 詳細セクション（重大シグナル深掘り）

### 1. 🔴 Cursor iOS パブリックベータ — 「モバイルからエージェント remote-control」参入

- **iOS 公開ベータ**: 全有料プランで提供開始。モバイルアプリから **リポジトリ選択→エージェント起動**（デスクトップと同手順）、任意の frontier モデル選択、**音声で指示**、slash commands で誘導。**always-on agents／Remote Control／live notifications／モバイルレビューツール**で「どこからでも作業を起動・誘導・管理」。Composer 2.5 実行が 7/5 まで 75% オフ。
- **Team MCP / 組織グループ**: 管理者が共有 MCP サーバを一度設定すれば、cloud agents / IDE / CLI / ローカルへ承認済み統合を配布可能。
- **自社への含意**: 自社は運用ルール（CLAUDE.md）で「mobile push notifications は actionable remote-control（CI 完了・blocked secrets・要判断 schedule task）に限る」と既に *運用* しているが、Cursor はそれを **プロダクト機能**（スマホからエージェント起動・承認）へ製品化。自社の `mobile-bug-triage` skill（実機 UAT 起点）＋ push remote-control は、将来「CEO がスマホから 6 部署エージェントを起動・承認」する UX の萌芽として観察価値。**シグナル #2（Codex Remote GA）と合わせ、モバイル remote-control が 2026-07 の明確なトレンド**。

### 2. 🔴 OpenAI Codex — GPT-5.5 既定化 ＋ Codex Remote GA（自社 L2 lane 直撃）

- **GPT-5.5 が Codex 既定**: 複雑なコーディング・computer use・knowledge work 向けの最新 frontier として Codex に搭載、モデルピッカー出現時は**多くのタスクで推奨**。実装・リファクタ・デバッグ・テスト・検証に有効。
- **旧モデル deprecated**: **GPT-5.3-Codex / GPT-5.2 が ChatGPT サインイン利用で user-selectable から deprecated**（API キー経路は影響なし）。推奨は GPT-5.5 / GPT-5.4 / GPT-5.4 mini。
- **Codex Remote GA**: ChatGPT モバイルアプリから接続済み Mac/Windows ホストの作業を**起動・継続・進捗確認・アクション承認**。ローカル会話履歴の検索（大小文字無視＋プレビュー）、MCP の per-server env / streamable HTTP の OAuth 改善。
- **自社への含意**: 自社 **L2 lane（VSCode+Codex 実装）**＋`AI_FALLBACK_RUNBOOK`（Claude quota 超過時の Codex CLI 継続）の直接 toolchain 更新。**Codex Remote GA はシグナル #1（Cursor iOS）と同型のモバイル remote-control**。`[AI-TOOL-VERIFY]`：GPT-5.5 既定化・旧モデル deprecation は openai.com Codex changelog で裏取り。[[project_20260615_anthropic_billing_split_model_retire]] の旧モデル退役文脈と同様、**fallback runbook のモデル名棚卸し**を要検討。

### 3. 🔴 Salesforce Agentforce — 成果課金の具体値（定額 $2/解決）＋事業規模

- **pay-per-resolution 具体化**: Agentforce Help Agent は **1 件の自律解決ごとに定額 $2** 課金。**人間対応を求められた／不満のまま離脱した場合は無課金**＝コストが「活動量」でなく「成果（解決）」に連動。消費予測・超過の心配が不要と Salesforce。Help Agent / Customer Service Portal は **7 月 GA**。
- **事業規模**: **Agentforce ARR $1.2B（前年比 +205%）・18,500 顧客**。成果課金への移行が事業規模を伴う本気の転換であることを裏付け。
- **自社への含意**: 07-03 の「pay-per-resolution 提供」概報 → **定額 $2/解決の具体値と ARR 規模が判明**。SaaS 収益モデルの新標準シグナルとして、自社の Stripe サブスク課金設計（[[project_20260625_monetization_stripe_pipeline]]）に対し「成果課金」を将来オプションとして memo。ただし自社は「1 円でも収益」の初手フェーズゆえ、当面はサブスク先行で問題なし。

### 4. 🔴 MoneyForward AI Cowork — ガバナンス設計の具体化（監査ログ commoditize 2 社目）

- **ガバナンス層**: ガードレール／**AI 作成の下書きを人が確認・承認するプロセス**／権限管理／**AI 監査ログ**を明示搭載＝「企業が安心して導入できる」設計。
- **オーケストレーション**: 自然言語入力を**オーケストレーターが意図解釈→最適エージェントへ振分**。エージェントは MF 提供分に加え、**開発パートナー提供分・ユーザー自作の「マイエージェント」**も利用可。対象は『マネーフォワード クラウド』既存ユーザー。7 月提供開始（先行受付中）。
- **自社への含意**: B/S 中核最大脅威の統治設計が判明。**AI 監査ログの標準搭載は 07-03 の Notion に続く 2 社目**で、自社の中核の堀『監査可能な並列統治』（deny-by-default subagent guard／worktree-isolation／GHA cron audit trail／cross-instance-pr／high-risk ultrareview gate）が水平 SaaS の *標準 UI 機能*へ commoditize 進行中。**差別化は「統治の深さ」（承認ゲート・high-risk exception・RLS 所有権チェック）の明文化で図る**（07-03 アクション1継続）。マイエージェントは自社「6 部署エージェント」と同型の user-defined agent ベクトル。

### 5. 🟠 Notion 3.6（7/1）追加詳細 — Office 形式まで束ねる orchestration hub

- **Office ファイル対応**: Notion Agents が **PPTX/XLSX/DOCX を読取（コンテキスト化）＋生成**（ページ→PowerPoint、DB→Excel モデル化）。
- **その他**: AI Meeting Notes に**音声アップロード**（文字起こし＋要約）、**Custom Agent の複製・微調整**で新チーム展開が容易に。
- **自社への含意**: 07-03 の External Agents（Claude/Cursor 統合）に続く hub 拡張。ドキュメント資産の入出力を Office 形式まで一枚のワークスペースに束ねる＝自社 CEO ダッシュボードの「資料生成」レイヤーへの侵入継続。

### 6. 🟢 OpenCode（次回 discovery 第1候補・pre-scan 継続）

- **7/1 update**: Ollama / llama.cpp / LM Studio で**オープンソースモデルのローカル実行**に対応。star 数 **172-178K**（月間 7.5M developers）、**75+ プロバイダ**、コード非保持で規制環境対応、Sonnet 5 向け adaptive thinking、小型既定モデルの改善。
- **自社への含意**: **次回 cooldown 解禁 = 2026-07-09** の第1候補として裏取り継続。model-agnostic ＋データ主権 ＋ローカル実行 ＋ subagent 定義が自社「AI 振り分け matrix」（`DEV_PROCESS_MULTI_AI`）に最接近。解禁日近接採択 pattern（Lovable 5/17・Bolt.new 5/24・Qoder 6/09・MAI-Code 6/16・Salesforce 6/23・Jules 7/02）を継承予定。
