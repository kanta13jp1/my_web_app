## 詳細分析

### 🔴 ChatGPT/OpenAI — Images 2.0 + GPT-5.4 mini (2026-04-21)

**新機能**:
- **ChatGPT Images 2.0**: ネイティブ推論 + 2K解像度 + 複数画像一貫性
  - 日本語・韓国語・ヒンディー語等の非ラテン文字レンダリング強化 → **日本語UI生成への影響**
  - Thinking mode (推論付き画像生成) はPaid限定
- **GPT-5.4 mini**: Free/Goは「Thinking経由」/ Plus+はレートリミット時フォールバック
- **File Library**: アップロード/生成ファイルを自動保存・再利用
- **Shopping機能強化**: 画像検索+会話型ブラウジング+価格/レビュー並列比較

**自分株式会社への影響**:
- Images 2.0の日本語強化 → ChatGPTが日本語UXを強化してくる方向性 (脅威度↑)
- File Library = 永続性の方向へ前進 → **差別化軸5 (Supabase永続)** の優位が相対的に縮小中
- **SNS弾候補**: 「ChatGPT File Library ≠ 財務履歴永続 / 自分株式会社はSupabaseで昨日比較が可能」

### 🔴 Notion AI — Agent Skills + Calendar/Mail統合 (2026-04-14)

**新機能**:
- **Agent Skills**: よく頼むワークフローを「スキル」保存 → コマンド実行化
  - 例: 週次更新の下書き / チームフォーマット整形 / ミーティング前ブリーフ
- **Calendar + Mail + Slack統合**: Notion AgentがカレンダーとメールをネイティブUI内で読み書き
- **n8n MCP連携**: Custom Agentsが既存n8nオートメーションを呼び出し可能
- **Voice input (Desktop)**: 音声でAgentに指示

**5/4課金との組み合わせリスク**:
- Skills機能で「使い勝手向上 → Agent利用頻度上昇 → credit消費加速 → 課金増加」のループ
- 月次リセット + 消費プレッシャー = 「使わなきゃ損」心理 → ヘビー利用 → 高コスト
- **SNS弾強化**: 「Notion Agentがスキルで便利になるほどcredit消費が増える。自分株式会社は無料・無制限」

### 🔴 Slack + Google Cloud — AI横断ワークフロー (2026-04-22)

**新発表**:
- Salesforce + Google Cloud パートナーシップ拡張
- SlackとGoogle Workspace間でAIエージェントが**エンドツーエンドワークフロー**を実行
- AgentforceとGemini Enterpriseが連携して文脈共有

- ただし依然「法人向け」軸 — 個人CEO × 6部署軸との住み分けは継続
