**※1 `supabase_flutter` 2.15.x に Web 認証まわりの修正あり (要注目)**

本番は **Flutter Web** (<https://my-web-app-b67f4.web.app/>) であり、以下は該当しうる:

- `2.15.1` — *「token 交換後に web URL から認証パラメータを消去」*
- `2.15.4` — *「認証パラメータ消去時に hash route と重複クエリキーを保持」*

URL 上に認証パラメータが残留する挙動は、履歴/Referer/共有リンク経由の**トークン漏洩面**に直結する。
CVE は発番されていないが、**Web 配信の本アプリでは実質セキュリティ修正**として扱うのが妥当。
ただし minor bump かつ認証コードパスに触れるため、無人実行の週次タスクで自動適用するのは不適切と判断。
→ 次回の有人セッションで `2.16.0` 追従を推奨 (優先度: 中〜高)。

**※2 `sentry_flutter` 9.23.0/9.24.0** — feature flag / gRPC / rate limiting 等。
セキュリティ修正・PII 漏洩修正の記載なし。急ぎ不要。
