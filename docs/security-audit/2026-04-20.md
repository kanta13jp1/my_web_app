| バージョン | 該当ファイル数 | 状況 |
|---|---|---|
| `deno.land/std@0.168.0` | 120件 | 旧版 (2022年リリース) |
| `deno.land/std@0.177.0` | 3件 | 旧版 (2023年リリース) |

**現在の最新**: `deno.land/std@0.224.0` (または `jsr:@std/*`)

**リスク評価**: 
- `deno.land/std@0.168.0` の `crypto/mod.ts` および `http/server.ts` はセキュリティ修正が含まれる可能性がある
- ただし Supabase Edge Runtime はホスト側で Deno バージョンを管理しており、import URLのバージョンと実行時バージョンは異なる
- 即時の RCE/データ漏洩リスクは低い

**対応方針**: 次回 EF 大規模リファクタリング時に一括アップデート推奨。個別ファイルごとの `deno lint` 確認が必要なため、本自動タスクでは見送り。担当: Win版 または VSCode版。
