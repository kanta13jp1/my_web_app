# XLSX入出力 — 初期対応範囲

表計算ツールバーのXLSX読み込み／書き出しボタンで利用します。
操作前に、データのみの対応であることを確認するダイアログを表示します。

- 読み込み: 既存シートを残し、ブックの全シートを追加。Undoで取り消し可能。
- 書き出し: 全シートを新しいXLSXへ出力。既定名は `ブック名-export.xlsx`。
- 対応: シート名、数値、共有文字列／インライン文字列、通常のセル数式。
- 文字列型の `=...` と先頭ゼロを保持。文字列属性はローカルJSONにも保存。
- 数式は保存できても、アプリ内の計算は既存の対応関数に限定されます。

## 制限とデータ保護

書式・結合・グラフ・画像・コメント・印刷設定・テーブル・マクロ等を保持しません。
日付書式の数値は日付ではなくシリアル値として読み込みます。
論理値・エラー値・ISO日付型、共有／配列数式、暗号化ファイルは読み込みを中止します。
同名シートが既存ブックにある場合は、既存シートを改名してから再実行してください。
シート名を自動改名すると数式参照が壊れるため、衝突を黙って変更しません。
外部シート参照は読み込まず、ファイルのネットワーク取得は行いません。

上限: 圧縮16MB、展開合計32MB、1パート8MB、512 ZIPエントリ、20シート、
1000行・100列、1シートの表示範囲20000セル、合計50000入力セル。
セル文字列32767文字。数式の範囲計算は20000セル、参照深さ100、評価10000回まで。
ファイル選択時もストリーム読み込みで16MB上限を適用します。
ZIPの実展開量・XMLのチェックサムも検証します。
読み込み失敗・キャンセルでは既存ブックを変更しません。

XLSXを編集する際は元ファイルを残し、必ず別名で出力してください。
この変更は完全なExcel互換性を保証せず、旧配布EXEへの適用も自動ではありません。
Windows版のビルド・署名・起動確認は別の検証段階です。公開・販売は行いません。

## 検証

`Spreadsheet XLSX Checks` がGitHub Actionsでフォーマット、対象解析、
単体／ViewModel／Widget／CSV回帰テストを実行します。
独立実装openpyxlが作成した合成XLSXを読み込み、出力をopenpyxlで再読込して
シート・文字列型・数値型・数式型を検証します。実データはアップロードしません。

仕様の参考: [Microsoft SpreadsheetML](https://learn.microsoft.com/en-us/office/open-xml/spreadsheet/overview)。
