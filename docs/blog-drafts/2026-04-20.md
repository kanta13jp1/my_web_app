### 1. WBSガントチャートUIの大改修

#### 背景

WBS（作業分解構成図）タブは以前からあったが、完了済みタスクが混在して視認性が悪く、どのインスタンスが何を担当しているかも分かりにくかった。

今回、note / freee / SmartHR / Apple JP / WIRED.jp の5つのデザインシステムを参照しながら改修した。

#### 実装した機能

**（1）未完了タスクフィルタ**

```dart
bool _hideCompleted = false;

List<WbsTask> get _filteredTasks {
  if (!_hideCompleted) return _tasks;
  return _tasks.where((t) => t.status != 'done').toList();
}
```

FilterChipをトグルするだけで完了済みタスクを非表示にできる。

**（2）本日線オートスクロール**

```dart
void _scrollToToday() {
  final today = DateTime.now();
  final startDate = _tasks.map((t) => t.startDate).reduce(
    (a, b) => a.isBefore(b) ? a : b,
  );
  final dayOffset = today.difference(startDate).inDays;
  final scrollOffset = dayOffset * _dayWidth - MediaQuery.of(context).size.width / 2;
  _ganttScrollController.animateTo(
    scrollOffset.clamp(0.0, _ganttScrollController.position.maxScrollExtent),
    duration: const Duration(milliseconds: 400),
    curve: Curves.easeOut,
  );
}
```

表示した瞬間に「今日」が画面中央に来るため、過去タスクを延々スクロールしなくて済む。

**（3）計画vs実績列（planned vs actual）**

`planned_start/end` と `actual_start/end` をGantt上で2本のバーを重ねて表示する。これにより遅延が一目で分かる。

**（4）インスタンスフィルターチップ**

5インスタンス（VSCode/Windows/PowerShell/WEB/Mobile）でタスクをフィルタリングできるチップを追加。

```dart
Wrap(
  spacing: 8,
  children: _instances.map((inst) {
    final selected = _selectedInstances.contains(inst);
    return FilterChip(
      label: Text(inst),
      selected: selected,
      onSelected: (v) => setState(() {
        v ? _selectedInstances.add(inst) : _selectedInstances.remove(inst);
      }),
    );
  }).toList(),
)
```

### 2. Edge Function CRITICAL移行完了

#### EF上限50本制限との戦い

このプロジェクトでは Supabase Edge Function を **50本以下** に保つルールがある。解決策は「ハブ化」で、`app-hub`・`tools-hub` などの親EFに `action` パラメータで処理を分岐させる。

```typescript
const action = body.action as string;
switch (action) {
  case 'chat.list':     return handleChatList(body, supabase);
  case 'time.log':      return handleTimeLog(body, supabase);
  // ... 30+ actions
}
```

#### 今週完了した移行

| 旧EF | 移行先ハブ |
|------|-----------|
| `chat-messaging` | `app-hub:chat.*` |
| `time-tracker` | `app-hub:time.*` |
| `goal-tracker` | `tools-hub:goal.*` |
| `habit-tracker` | `tools-hub:habit.*` |
| `music-collaboration` | `app-hub:music.*` |
| `ab-testing-manager` | `enterprise-hub:ab.*` |

これにより CRITICAL フラグの付いた「単独EF」がゼロになった。

#### CRITICAL bugfix: wbs.* actions 全滅事件

`wbs.*` アクション群が **2週間もの間、全インスタンスで unreachable** だったバグが発覚。原因はシェルインジェクション対策不足で、GitHub Actions の変数直接展開が問題だった。

```yaml
# 修正後 - 環境変数経由でインジェクション回避
env:
  ACTION: ${{ github.event.inputs.action }}
run: |
  curl -d "{\"action\": \"$ACTION\"}" ...
```

### 詰まったポイント

**dart formatのパイプハング**: 長時間セッション（8時間超）で `dart format .` をパイプ経由で実行するとプロセスがゾンビ化する。`timeout 60 dart format .` で解決。

**ScheduleWakeup深夜抑制**: JST 0〜6時は Claude Code Schedule を抑制するようcronを調整してEFコストを削減。

**issue-to-wbs のシェルインジェクション**: `${{ github.event.issue.title }}` の直接展開を廃止し環境変数経由に変更。
