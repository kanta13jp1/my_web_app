# マルチAIワークフローの本当のコスト — 個人開発者が複数AIを使い分けた6ヶ月間の実費

## 「AI全部使ったら月いくらになるの?」

Claude Code、GitHub Copilot、Gemini Code Assist、OpenAI Codex、NotebookLM。

「全部使いこなしたい」と思う反面、「コストが怖い」という声をよく聞く。

6ヶ月間、10インスタンス並行 + 月500コミットのペースで複数AIを実際に使い続けた結果を公開する。

---

## 実際の月額コスト内訳

| ツール | プラン | 月額 | 用途 |
|--------|--------|------|------|
| Claude Code | Max Plan | $100 | 設計・アーキテクチャ・自律タスク |
| GitHub Copilot | Individual | $10 | インライン補完・小修正 |
| OpenAI Codex | API従量課金 | $8-15 | SQL一括生成・バッチ処理 |
| Gemini Code Assist | Google One AI | $20 | 500行超リファクタリング |
| NotebookLM | 無料 | $0 | リサーチ・ドキュメント分析 |
| **合計** | | **$138-145** | |

「全部使ったら高い」という印象があるかもしれないが、比較対象を間違えると判断を誤る。

---

## コスト対生産性の実数

月500コミット × 平均1コミット=30分の作業を、AIなしでこなすには:

```
500コミット × 30分 = 250時間/月
時給換算: $15/時間 × 250時間 = $3,750
AI費用: $145
ROI: 2,488% (AI費用に対して)
```

もっと現実的な見方をする: 月200時間の開発時間が AI で 40時間に圧縮されたとすると、160時間の削減 × 自分の時給 = AIコストを大きく上回る。

**重要**: この計算は「AIが全部やってくれる」ではない。「人間が意思決定・設計をして、AIが実装・検証を担当する」分業の結果だ。

## ツールごとの ROI 分析

### Claude Code ($100/月) — 最も高く、最も価値が高い

10インスタンス並行で月500コミットを支える。$100は一見高いが:

- 1インスタンスあたり $10/月 (Cursor Pro と同額)
- 自律タスク実行 = 自分がターミナルを見ていない時間も開発が進む
- memory/ システムでセッション間の学習が蓄積される

**代替不可能なケース**: 複数ファイルにまたがる整合性確認、GHA workflow 修正、DB マイグレーション設計

### GitHub Copilot ($10/月) — 最も費用対効果が高い

毎日使うインライン補完として $10 は圧倒的に安い。

- Tab 補完で 1日 30-60分の入力時間が削減
- Copilot Chat は「5分以内の修正」の標準ツール
- Copilot Workspace は小機能追加をほぼ自動化

**Claude Code との関係**: 補完 (Copilot) + 自律実行 (Claude) の組み合わせが最も効率的。

### OpenAI Codex API ($8-15/月) — バッチ処理の切り札

一括生成タスクに特化すると月 $10 前後で収まる。

```bash
# 200社分のシード SQL を一括生成 → コスト $3
codex "template.sql を使って200社分のシード SQL を生成"
```

Claude Code で同じ作業をやると $50-80 消費する (トークン単価の違い)。

### Gemini Code Assist ($20/月) — 大規模リファクタリング専用

500行超の一括変換は Gemini に任せる。月 1-2 回の大規模リファクタリングに $20 は適正。

### NotebookLM (無料) — 最も過小評価されているツール

「無料なのにトークン節約になる」という逆説。

3ファイル以上の同時分析を Claude Code でやると ~150K tokens。NotebookLM に委譲すると Claude Code のトークン消費は ~5K。結果として Claude Code の有効利用時間が伸びる。

## コスト最適化の実際

### 月額を抑えたい場合の優先順位

予算 $30/月: GitHub Copilot ($10) + Codex API ($8-15) + NotebookLM (無料) = $18-25
→ インライン補完 + バッチ生成 + リサーチの基本セットが揃う

予算 $50/月: 上記 + Gemini Code Assist ($20) = $38-45
→ 大規模リファクタリングも委譲可能

予算 $150/月: フルセット (Claude Max + 全ツール) = $138-145
→ 10インスタンス並行・月500コミット規模

### 使ってわかった「削れるコスト」

- **NotebookLM → Gemini 1.5 Pro API**: 同等機能で月 $5-10 節約
- **Codex CLI → GPT-4o API 直接呼出し**: 若干安くなるが利便性が落ちる
- **Gemini Code Assist → Cursor Pro**: Cursor の Gemini モデルで大規模リファクタリングも可。$10 節約

**削れないコスト**: Claude Code Max。他で代替できない自律性と memory システムが月500コミットを支えている。

---

## 副業・兼業レベルの場合

月20-30時間のコーディング量なら:

```
推奨セット: GitHub Copilot $10 + NotebookLM $0 = $10/月
オプション追加: Copilot Workspace (Copilot に含む) で小機能自動化
```

Claude Code $100 は不要。Copilot のインライン補完 + Workspace の E2E 自動化で十分カバーできる。

---

## まとめ: AI代は「コスト」ではなく「投資」

月$145のAI費用を、160時間の時間節約と比較すれば「高い」とは言えない。

ただし「全部使えば良い」ではない。自分のコーディングスタイル・タスク種別・月間コミット量によって最適なセットは変わる。

まず Copilot $10 から始めて、バッチ処理が増えたら Codex を追加。自律タスクが必要になったら Claude Code に切り替える — この順番が合理的だ。
