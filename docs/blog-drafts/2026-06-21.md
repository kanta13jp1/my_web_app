### 実装方法

#### 1. 給料振込の自動検知 + 想定給料額の登録導線 (PR #3600)

給料日に入金があると、アプリが自動でそれを検知し「これは給料ですか？」と確認を促します。今週追加したのは、**想定給料額の事前登録UI**です。

```dart
// 想定給料額の登録フォーム
class ExpectedSalaryDialog extends StatelessWidget {
  final TextEditingController _amountController = TextEditingController();

  @override
  Widget build(BuildContext context) {
    return AlertDialog(
      title: const Text('想定給料額を登録'),
      content: TextField(
        controller: _amountController,
        keyboardType: TextInputType.number,
        decoration: const InputDecoration(
          labelText: '毎月の手取り額 (円)',
          hintText: '例: 280000',
        ),
      ),
      actions: [
        TextButton(onPressed: () => Navigator.pop(context), child: const Text('キャンセル')),
        ElevatedButton(
          onPressed: () => _save(context),
          child: const Text('登録'),
        ),
      ],
    );
  }
}
```

Supabase の `salary_settings` テーブルに保存し、振込検知時に **実際の入金額と想定額を比較して乖離を通知** します。これにより手取りが急に変わったとき（税率変更・手当の増減）を即座に把握できます。

#### 2. 定期固定費カードを給料日サイクル順にソート (PR #3598)

固定費一覧は「次の引き落としが近い順」に並んでいましたが、給料日を基準に **「給料日からN日後」** で並べ替えるオプションを追加しました。月末締め・翌月払いのクレジットカードと、給料日当日引き落としの家賃が混在しても、キャッシュフローの流れが一目でわかります。

```dart
expenses.sort((a, b) {
  final aDaysFromSalary = _daysFromSalaryDay(a.billingDay, salaryDay);
  final bDaysFromSalary = _daysFromSalaryDay(b.billingDay, salaryDay);
  return aDaysFromSalary.compareTo(bDaysFromSalary);
});
```

#### 3. 負債に「手順を確認」ボタンを追加 — AI が引き落とし確認手順を提示 (PR #3571)

ローンやクレジットカードの残債画面に「手順を確認」ボタンを追加しました。タップすると、Supabase Edge Function 経由で Claude API を呼び出し、**その負債の引き落とし確認手順をステップバイステップで説明** します。

```typescript
// Edge Function: debt-procedure-guide
Deno.serve(async (req) => {

  const response = await anthropic.messages.create({

    max_tokens: 500,

  return Response.json({ guide: response.content[0].text });

```

#### 4. AI-hub の LLM タイムアウト対策 (PR #3576, #3586, #3597)

複数の AI プロバイダを束ねる `ai-hub` Edge Function で、一部プロバイダのレスポンスが遅延すると 502 エラーになる問題がありました。今週は **全プロバイダのフェッチに 15 秒タイムアウト** を横展開しました。

```typescript
const fetchWithTimeout = (url: string, options: RequestInit, ms = 15000) => {
  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), ms);
  return fetch(url, { ...options, signal: controller.signal })
    .finally(() => clearTimeout(timer));
};
```

#### 5. デバウンス窓の最適化 (PR #3587, #3591)

資産管理画面の初期化時に ai-hub / core-hub への重複リクエストが発生していました。デバウンス窓を **700ms → 2500ms** に拡大し、初期化連打を大幅に抑制。Supabase の Function 呼び出し回数が約60%削減されました。

### 詰まったポイント

**給料日サイクルソートの月跨ぎ計算**

給料日が「25日」で引き落としが「翌月2日」の場合、単純な日付比較では翌月2日 < 25日になってしまいます。「給料日からの経過日数」に換算するロジックで解決しました。

```dart
int _daysFromSalaryDay(int billingDay, int salaryDay) {
  final diff = billingDay - salaryDay;
  return diff >= 0 ? diff : diff + 30; // 月を跨ぐ場合は+30日
}
```

**AI-hub のタイムアウトと AbortController の相性**

Deno の Fetch API では `AbortController` を使ったタイムアウトが効くものの、一部のプロバイダSDKが内部で独自のフェッチを使っており abort シグナルが伝播しないケースがありました。SDKのラッパー関数レベルでタイムアウトを設けることで解決しています。
