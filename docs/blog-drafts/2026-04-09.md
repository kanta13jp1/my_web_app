### 実装方法

#### 1. Flutter Web ダークテーマ完全対応 — colorScheme トークン 160件置換

Flutter アプリを長期開発していると、ハードコードされたカラー定数が蓄積していきます。

```dart
// 修正前（ライトテーマでしか正しく表示されない）
Container(
  color: Colors.grey[200],
  child: Text('label', style: TextStyle(color: Colors.black87)),
)
```

ダークテーマに切り替えると、`Colors.grey[200]` は薄いグレー背景のまま、
`Colors.black87` は黒いテキストのままになり、コントラストが消えてしまいます。

**置換ルール（今回適用したマッピング）**:

| Before | After |
| --- | --- |
| `Colors.grey[100]` | `colorScheme.surfaceContainerLow` |
| `Colors.grey[200/300]` | `colorScheme.surfaceContainerHighest` |
| `Colors.grey[400/500/600]` | `colorScheme.onSurfaceVariant` |
| `Colors.grey[700/800]` | `colorScheme.onSurface` |
| `Colors.white` (背景) | `colorScheme.surfaceContainerLow` |
| `Colors.black87` | `colorScheme.onSurface` |
| `Colors.black54` | `colorScheme.onSurfaceVariant` |
| `Colors.black12` | `colorScheme.outlineVariant` |

```dart
// 修正後（ダーク/ライト両対応）
final colorScheme = Theme.of(context).colorScheme;
Container(
  color: colorScheme.surfaceContainerHighest,
  child: Text('label', style: TextStyle(color: colorScheme.onSurface)),
)
```

160件を手動で修正するのは現実的ではないため、Claude Code の Grep → Edit ループを活用しました。
各バッチで `flutter analyze` を実行して 0 エラーを確認しながら段階的に進めました。

#### 2. メモ機能に画像ドラッグ&ドロップを追加 — Notion風 UX

Flutter Web の `TextField` や `SelectionArea` は、ブラウザネイティブの drag イベントを
そのまま受け取れません。`package:web` の HTML API を使って独自ドロップゾーンを実装します。

**実装アーキテクチャ**:

```
NoteImageDropZone (web実装) ← lib/utils/note_image_drop_web.dart
NoteImageDropZone (stub)    ← lib/utils/note_image_drop_stub.dart (mobile/desktop用)
         ↓ onDrop(Uint8List bytes)
note_editor_page._handlePastedImage()
         ↓
Supabase Storage → 公開URL生成 → マークダウンに挿入
```

**Web 実装のポイント**:

```dart
// lib/utils/note_image_drop_web.dart
import 'package:web/web.dart' as web;

void _attachListeners(web.HTMLElement el) {
  el.addEventListener('dragover', (web.Event e) {
    (e as web.DragEvent).preventDefault();
  });
  el.addEventListener('drop', (web.Event e) {
    final drag = e as web.DragEvent;
    drag.preventDefault();
    final files = drag.dataTransfer?.files;
    if (files != null && files.length > 0) {
      final file = files.item(0)!;
      if (file.type.startsWith('image/')) {
        final reader = web.FileReader();
        reader.readAsArrayBuffer(file);
        reader.onload = (web.Event ev) {
          final bytes = Uint8List.view(
            (reader.result as web.ArrayBuffer).toDart,
          );
          widget.onDrop(bytes);
        } as web.EventHandler;
      }
    }
  });
}
```

条件付きインポートで Web/Stub を切り替えます:

```dart
// note_image_drop.dart (エクスポート用)
export 'note_image_drop_stub.dart'
    if (dart.library.html) 'note_image_drop_web.dart';
```

これにより Flutter Web ではドラッグ&ドロップが、モバイルでは何もしない stub が使われます。

#### 3. コンソールエラー自動収集 — FlutterError.onError フック

開発中にコンソールで目立つエラーも、本番環境ではサイレントに発生し続けることがあります。
`ErrorReporter` クラスで Flutter のエラーハンドラをフックし、Edge Function に送信します。

```dart
class ErrorReporter {
  static bool _installed = false;
  static int _reportCount = 0;
  static const _maxPerSession = 10;
  static final _seen = <String>{};
  static bool _reporting = false;

  static void install() {
    if (_installed) return;
    _installed = true;

    final prev = FlutterError.onError;
    FlutterError.onError = (details) {
      prev?.call(details);
      report(details.exceptionAsString(), details.stack?.toString());
    };

    PlatformDispatcher.instance.onError = (error, stack) {
      report(error.toString(), stack.toString());
      return false;
    };
  }

  static void report(String message, String? stack) {
    if (_reporting) return;
    if (_reportCount >= _maxPerSession) return;
    final key = message.substring(0, message.length.clamp(0, 100));
    if (!_seen.add(key)) return;

    _reporting = true;
    _reportCount++;
    _sendToEdgeFunction(message, stack).whenComplete(() => _reporting = false);
  }
}
```

`main.dart` で Supabase 初期化直後に呼び出すだけです:

```dart
await Supabase.initialize(...);
ErrorReporter.install();
```

### 詰まったポイント

**1. `package:web` の API は `dart:html` と異なる**

Flutter Web の `package:web` (v0.5+) は Dart 3.x 対応の新 API です。
`dart:html` の `FileReader.result` は `dynamic` でしたが、`package:web` では
`web.ArrayBuffer` を返します。`.toDart` で `ByteBuffer` に変換する必要があります。

**2. `Colors.grey[]` の null 安全性**

`Colors.grey[200]` は `Color?` を返しますが、実際に null になることはないため
`!` または `?? Colors.transparent` で処理します。ただし Flutter analyze では
`unnecessary_non_null_assertion` に引っかかるケースもあるので要注意。

**3. colorScheme の取得タイミング**

`build()` メソッド外（`initState()` など）では `Theme.of(context)` が使えません。
その場合は `WidgetsBinding.instance.platformDispatcher.platformBrightness` で
明暗を判定するか、`didChangeDependencies()` で保持するパターンを使います。
