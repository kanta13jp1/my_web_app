#### 2. 開発実績カードの ListView 最適化

`development-achievements` API は JSON 配列を返します。以前は挿入順で表示していましたが、ユーザーから「最新の実績が下の方にある」と指摘を受け、時系列ソートを実装しました。

```dart
// 取得後にクライアント側でソート
final achievements = (data as List<dynamic>)
    .cast<Map<String, dynamic>>()
    .sorted((a, b) {
      final ta = DateTime.tryParse(a['completed_at'] ?? '') ?? DateTime(0);
      final tb = DateTime.tryParse(b['completed_at'] ?? '') ?? DateTime(0);
      return tb.compareTo(ta); // 降順
    });
```

タップ詳細ダイアログは `showDialog` + `AlertDialog` でシンプルに実装：

```dart
void _showDetail(Map<String, dynamic> item) {
  showDialog(
    context: context,
    builder: (_) => AlertDialog(
      title: Text(item['title'] ?? ''),
      content: Column(
        mainAxisSize: MainAxisSize.min,
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Text(item['description'] ?? ''),
          const SizedBox(height: 8),
          Text(
            _formatDuration(item['completed_at']),
            style: const TextStyle(color: Colors.grey),
          ),
        ],
      ),
    ),
  );
}

// HH:MM:SS 精度表示
String _formatDuration(String? iso) {
  if (iso == null) return '';
  final dt = DateTime.tryParse(iso)?.toLocal();
  if (dt == null) return '';
  return '${dt.year}-${_2d(dt.month)}-${_2d(dt.day)} '
      '${_2d(dt.hour)}:${_2d(dt.minute)}:${_2d(dt.second)}';
}
String _2d(int n) => n.toString().padLeft(2, '0');
```

#### 3. BuildContext 非同期問題の修正

Flutter の `use_build_context_synchronously` 警告は、async 処理後に `context` を使うと発生します。`goal_tracker_page.dart` で以下のパターンで修正しました：

```dart
// Before (警告あり)
Future<void> _save() async {
  await supabase.from('goals').insert(data);
  ScaffoldMessenger.of(context).showSnackBar(...); // ← 警告
}

// After (mounted チェック追加)
Future<void> _save() async {
  await supabase.from('goals').insert(data);
  if (!mounted) return;
  ScaffoldMessenger.of(context).showSnackBar(...);
}
```

### 詰まったポイント

**share_plus の Web 非対応**

`guitar_recording_studio_page.dart` で録音ファイルの共有に `share_plus` を使っていましたが、Flutter Web では `cross_file` パッケージとの組み合わせで `web` プラットフォームのビルドが通らないことが判明。`pubspec.yaml` から除去し、Web では `AnchorElement` 経由でのダウンロードに切り替えました。

```dart
// Web でのファイル保存
import 'dart:html' as html;

void _downloadWav(Uint8List bytes, String filename) {
  final blob = html.Blob([bytes]);
  final url = html.Url.createObjectUrlFromBlob(blob);
  html.AnchorElement(href: url)
    ..setAttribute('download', filename)
    ..click();
  html.Url.revokeObjectUrl(url);
}
```

**開発実績の `completed_at` 精度**

Supabase の `timestamptz` は ISO 8601 フォーマットで返ってきますが、タイムゾーンが UTC のため、日本時間（JST = UTC+9）で表示するには `.toLocal()` が必要です。これを忘れると「9時間ずれた実績時刻」が表示されてしまいます。
