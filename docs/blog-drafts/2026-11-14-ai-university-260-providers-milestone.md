# AI大学 260社突破 — 個人開発者がAIツール図鑑を作り続けた理由

自分のアプリ「自分株式会社」の機能の一つ「AI大学」が、登録プロバイダー数 **260社** を突破しました。なぜ個人開発者がこんなにAIツールを記録し続けているのか、その動機と設計を紹介します。

## AI大学とは

AI大学は「AIツールを体系的に学ぶための学習機能」です。各プロバイダーについて：

- **カテゴリ分類**: 画像生成・コード補助・テキスト・音声合成など
- **難易度スコア (1-10)**: 初心者向けか上級者向けか
- **日本語対応スコア (1-10)**: 日本のユーザーがどれだけ使えるか
- **公式サイト URL**
- **主要機能の解説**

データは Supabase に保存され、Flutter Web フロントから検索・フィルタリングできます。

## なぜ260社も登録したのか

AIツールの爆発的な増加を「ノイズ」として捨てるか、「信号」として整理するか。私は後者を選びました。

理由は3つです：

### 1. 自分自身の意思決定ツールとして使う

新しいAIツールを試すとき「似たような既存ツールと何が違うか」を素早く確認できます。260社のデータベースがあれば、比較が格段に速くなります。

### 2. SEOとコンテンツの核にする

各プロバイダーページが独立したコンテンツになります。「{tool名} 使い方」「{tool名} 日本語」などの検索クエリに応答できます。

### 3. AI自身に整備させる

プロバイダー追加の SQL テンプレートを標準化し、AI (Codex CLI) に量産させています。1社あたり約15分で登録できます。

```sql
-- template: seed_${slug}_ai_university.sql
INSERT INTO ai_university_content (
  provider_id, provider_name, category,
  description_ja, description_en,
  difficulty_score, japan_support_score,
  official_url, key_features
) VALUES (
  '${id}', '${name}', '${category}',
  '${description_ja}',
  '${description_en}',
  ${difficulty}, ${japan_support},
  '${url}', '${features}'
) ON CONFLICT (provider_id) DO NOTHING;
```

## 特に学びになった領域

**LLMファインチューニング系** (Unsloth, Axolotl, TRL, PEFT, Mergekit): GPU不要・省メモリ技術の進化が速い

**評価・オブザーバビリティ系** (Langfuse, DeepEval, Promptfoo, TruLens): RAGシステムの品質管理に必須

**分散計算系** (Ray/Anyscale, BentoML): スケールアウトの抽象化が進んでいる

## 今後の方針

260社でも全体の10%程度です。Gartner によれば AI ツール市場は2026年末に2,000社超えが予測されています。

- 「使える」250社より「網羅的な」2,000社よりも「自分が判断に使える」300社を目指す
- 各カテゴリのトップ5を深掘りするコンテンツを追加予定
- 日本語対応スコアの精度向上 (ネイティブユーザーのレビュー収集)

## まとめ

AI大学は「個人開発者が自分のために作った、AI選択の羅針盤」です。260社というマイルストーンは通過点ですが、自分自身がこのデータベースを毎週使っているという事実が、続ける最大の動機です。

「記録することは理解すること」— このプロジェクトで一番学んでいるのは、作っている私自身かもしれません。
