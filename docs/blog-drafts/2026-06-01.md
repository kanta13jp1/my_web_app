## 本文下書き

### はじめに

個人の資産・負債を一元管理する Flutter Web アプリ「自分株式会社」の開発を続けています。今回は資産管理画面に 2 つの新機能を追加しました。

1. **負債コントロールレビューパネル** (`_buildDebtControlReviewSection`)
2. **口座移動タスクへの実行メモ機能** (`_showTransferTaskMemoDialog`)

どちらも「手動作業の抜け漏れをなくす」というゴールから設計しています。クレジットカードの引き落とし確認忘れや、ATM 手数料の記録漏れは地味にストレスになるので、UI 側でフォローするようにしました。

---

### 実装方法

#### 1. 負債コントロールレビューパネル

資産管理ページのワークブック表示部に、既存の「支払いリマインダー」の上位に挿入するセクションを追加しました。

```dart
enum _DebtMasterReviewFilter { all, billingConfirmation, paymentSource }
```

フィルターは 3 種類用意しています:
- `all` — 全負債行を表示
- `billingConfirmation` — ビリング確認が保留中の行だけ表示
- `paymentSource` — 支払い元口座が未設定の行だけ表示

UI は状態に応じて色が変わります。レビュー対象がある場合はアンバー系 (`#D97706`)、すべてクリアなら緑系 (`#0D9488`) で表示されます。

```dart
final color = hasReviewTargets
    ? const Color(0xFFD97706)
    : const Color(0xFF0D9488);
```

また「推定支払額を一括確定」ボタンも追加しました。ローン等で毎月の支払額が概算のみ分かっている場合、全行をワンタップで確定できます。

```dart
void _confirmAllEstimatedPaymentAmounts(
  Iterable<AssetLiabilityDebtRow> rows,
) {
  final targets = rows.where((row) => row.paymentAmountEstimated).toList();
  if (targets.isEmpty) return;
  setState(() {
    for (final row in targets) {
      final amount = row.scheduledPaymentAmount.round();
      _monthlyPaymentOverrides[row.id] = amount.toDouble();
      _monthlyPaymentControllers[row.id]?.text = amount.toString();
    }
  });
  unawaited(_saveAssetLiabilityMonthlyState());
}
```

#### 2. 口座移動タスクへの実行メモ機能

口座移動タスクを完了マークすると、実行メモを入力できるダイアログが開くようになりました。

```dart
Future<void> _showTransferTaskMemoDialog(
  AssetLiabilityTransferTask task,
) async {
  final controller = TextEditingController(text: task.completionMemo);
  final nextMemo = await showDialog<String>(
    context: context,
    builder: (context) => AlertDialog(
      title: const Text('口座移動タスクの実行メモ'),
      content: TextField(
        controller: controller,
        minLines: 3,
        maxLines: 6,
        decoration: const InputDecoration(
          hintText: '例: ATM手数料110円。移動後のじぶん銀行残高は84,000円。',
        ),
      ),
      // ...
    ),
  );
  // stateに保存
}
```

`completionMemo` は `AssetLiabilityTransferTask` モデルに追加したフィールドで、Supabase の月次状態ストアへ永続化されます。
