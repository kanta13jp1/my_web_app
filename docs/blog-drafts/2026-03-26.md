### はじめに

「毎日やろうと決めたことが、いつの間にか三日坊主で終わる。」

これはほぼすべての人が経験する問題です。タスク管理アプリを使っても「今日の習慣」と「やるべきタスク」が分散してしまい、結局 SNS に時間を溶かして一日が終わる——そんなループを断ち切るために、**自分株式会社** (https://my-web-app-b67f4.web.app/) に「毎日の習慣リマインダー機能」と「時間溶かし防止ガード (TimeWasteGuard)」を実装しました。

Notion・Evernote・MoneyForward・Slack など 21 の競合 SaaS が持つ機能を 1 つのアプリに統合するというコンセプトで開発を続けているこのプロジェクト。今回は直近 1 週間で追加した **習慣管理システム全体の設計と実装** を解説します。

### 実装方法

#### 1. Supabase テーブル設計

習慣の管理に使うテーブルは 2 つです。

```sql
-- 習慣マスタ
CREATE TABLE daily_habits (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id     uuid REFERENCES auth.users NOT NULL,
  title       text NOT NULL,
  emoji       text,
  color       text,       -- 例: '#4CAF50'
  remind_time text,       -- 例: '21:00'
  is_active   boolean DEFAULT true,
  created_at  timestamptz DEFAULT now()
);

-- 習慣の完了ログ (1日1回)
CREATE TABLE daily_habit_logs (
  id             uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id        uuid REFERENCES auth.users NOT NULL,
  habit_id       uuid REFERENCES daily_habits NOT NULL,
  completed_date date NOT NULL DEFAULT CURRENT_DATE,
  created_at     timestamptz DEFAULT now(),
  UNIQUE (user_id, habit_id, completed_date)  -- 1日1回のみ
);
```

ポイントは `daily_habit_logs` の `UNIQUE` 制約です。同じ日に同じ習慣を誤って2回記録しないようにしています。Flutter 側でも楽観的 UI 更新を行うため、DB 側でもガードを入れておくのが安全です。

#### 2. 23種のプリセットテンプレート

ユーザーがゼロから習慣を入力するのは面倒なため、よく使われる 23 種のプリセットを用意しました。

```dart
static const _presets = [
  ('マネーフォワード更新・財布残高入力', '💰', '#4CAF50', '21:00'),
  ('体重を記録する',                    '⚖️', '#2196F3', '07:00'),
  ('水を2L飲む',                        '💧', '#03A9F4', '20:00'),
  ('着替える (上着・ズボン・パンツ)',    '👔', '#5C6BC0', '07:00'),
  // ... 計23種
];
```

カテゴリは「健康」「家事」「学習」「身だしなみ」「計画・振り返り」の 5 系統。プリセットを 1 タップで自分の習慣リストに追加できます。

#### 3. Flutter での習慣ページ実装

`DailyHabitsPage` では、`Future.wait` で習慣マスタと今日のログを並列取得します。

```dart
final results = await Future.wait([
  _supabase
      .from('daily_habits')
      .select()
      .eq('user_id', userId)
      .order('created_at'),
  _supabase
      .from('daily_habit_logs')
      .select('habit_id')
      .eq('user_id', userId)
      .eq('completed_date', _todayStr),
]);

final habits    = List<Map<String, dynamic>>.from(results[0] as List);
final logs      = List<Map<String, dynamic>>.from(results[1] as List);
final completed = logs.map((l) => l['habit_id']?.toString() ?? '').toSet();
```

`Set<String>` に完了済みの habit_id を格納することで、各リストタイルの `isCompleted` 判定を O(1) で行えます。

完了ボタンを押したときは upsert を使い、二重打ちを防止します。

```dart
await _supabase.from('daily_habit_logs').upsert({
  'user_id':        userId,
  'habit_id':       habitId,
  'completed_date': _todayStr,
}, onConflict: 'user_id, habit_id, completed_date');
```

#### 4. 時間溶かし防止ガード (TimeWasteGuardWidget)

習慣管理と並行して、**「SNS・YouTube・ゲームに時間を溶かしてしまう衝動をその場で断ち切る」** ウィジェットもホーム画面に追加しました。

```dart
static const _items = [
  _GuardItem(
    id: 'x_twitter',
    label: 'X (Twitter)',
    emoji: '🐦',
    color: Color(0xFF1DA1F2),
    stopAction: 'アプリを閉じてログアウト。通知OFF。',
    doInstead: '→ 代わりに: 今日のタスクを1つ片付ける',
  ),
  _GuardItem(
    id: 'youtube',
    label: 'YouTube',
    emoji: '📺',
    color: Color(0xFFFF0000),
    stopAction: 'タブを閉じる。おすすめを見ない。',
    doInstead: '→ 代わりに: 5分だけ本を読む',
  ),
  // X, YouTube, コーヒー, 煙草, SNS全般, 漫画・アニメ, ゲーム, 間食 計8種

```

ユーザーが「やめたい行動」をタップすると、**「今すぐやること」と「代わりにやること」** が提示されます。状態は `SharedPreferences` に保存し、今日何回その行動に流されたか (スリップ数) も記録します。このスリップカウントは振り返りに使えます。

#### 5. ログインストリーク & デイリーチャレンジ

継続動機づけのため、**LoginStreakCard** (連続ログイン日数を表示) と **DailyChallengeCard** (毎日のミッション) もホーム画面に追加しました。ゲーミフィケーションの基本要素をシンプルに組み込んでいます。

### 詰まったポイント

#### `date` 型と `timestamptz` 型の扱い

`daily_habit_logs.completed_date` を `date` 型にした理由は、タイムゾーンの影響を排除するためです。`timestamptz` だと UTC 基準でカラムを比較することになり、JST の深夜0時をまたぐと「昨日のログ」として扱われるバグが発生します。

Flutter 側で日付文字列を生成するときは `DateFormat('yyyy-MM-dd').format(DateTime.now())` で統一することで、意図したローカル日付を送れます。

#### `UNIQUE` 制約のエラーハンドリング

`upsert` を使っていても、競合条件 (超高速連打など) で `PostgrestException` が発生することがあります。Flutter 側では try/catch でエラーをキャッチし、コードが `23505` (unique_violation) の場合は無視するようにしています。

```dart
try {
  await _supabase.from('daily_habit_logs').upsert({ ... });
} on PostgrestException catch (e) {
  if (e.code != '23505') rethrow; // unique_violation は無視
}
```

#### `SharedPreferences` の async 初期化

`TimeWasteGuardWidget` は `initState` で async 処理を呼べません。`initState` 内で `_loadPrefs()` を呼び出し (Future を捨てる形)、処理完了後は `if (mounted) setState(...)` で安全に UI 更新する必要があります。

### まとめ

今回の実装で、**「毎日やるべきこと」「やめるべきこと」「継続の可視化」** という習慣管理の三要素をひとつのアプリに統合できました。

- `daily_habits` / `daily_habit_logs` の 2 テーブル構成で、ユーザーごとの習慣を柔軟に管理
- 23 種のプリセットで「入力ゼロ」で始められる UX
- `TimeWasteGuardWidget` で時間浪費の衝動をその場でブロック
- ログインストリーク・デイリーチャレンジでゲーミフィケーション

次のステップとして、**習慣の達成率グラフ** や **プッシュ通知 (remind_time 連携)** の実装を予定しています。
