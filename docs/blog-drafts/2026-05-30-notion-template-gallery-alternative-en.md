## 3 Limits of Notion Templates

### 1. Data Doesn't Enter Itself

A habit tracker template is great — until you realize you have to manually check every box every day.

If you don't already have a "daily logging" habit, a "template to help build a daily logging habit" won't create one.

**What you actually need**: Automatic data collection (Apple HealthKit, screen time auto-import, etc.)

### 2. Templates Don't Talk to Each Other

You can install a freelance income template, a habit tracker template, and a learning log template — and all three will sit as isolated databases.

Cross-analysis like "weeks with higher income correlated with more sleep" becomes impossible without building it yourself.

**What you actually need**: An integrated dashboard where all data compares against everything else.

### 3. No "Yesterday's Self" Comparison

Notion templates are designed to record today's data. They're not designed to automatically calculate "what % did my learning time increase vs last week?" or "how much more did I earn this month vs last month?"

You can build this in Notion. But doing so is close to custom development in the hours it requires.

**What you actually need**: Automatic daily/weekly/monthly comparison built in.
