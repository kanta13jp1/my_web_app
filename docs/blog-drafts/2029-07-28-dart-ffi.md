# Dart FFI 完全ガイド — C/C++ ライブラリを Flutter アプリから呼び出す

Dart FFI (Foreign Function Interface) を使うと、既存の C/C++ ライブラリを Flutter アプリから直接呼び出せます。高性能な暗号処理・画像変換・ML モデル推論などに活用できます。

## FFI の基本

```yaml
dependencies:
  ffi: ^2.1.0
```

```dart
import 'dart:ffi';
import 'package:ffi/ffi.dart';

// C 関数のシグネチャ定義
typedef AddNativeFunc = Int32 Function(Int32 a, Int32 b);
typedef AddDartFunc = int Function(int a, int b);

// ライブラリのロード
final dylib = Platform.isAndroid
    ? DynamicLibrary.open('libmylib.so')
    : Platform.isIOS
        ? DynamicLibrary.process()
        : DynamicLibrary.open('mylib.dll');

// 関数のバインド
final add = dylib.lookupFunction<AddNativeFunc, AddDartFunc>('add');

// 呼び出し
final result = add(3, 4);  // 7
```

## C ライブラリの作成

```c
// mylib.c
#include <stdint.h>
#include <string.h>
#include <stdlib.h>

// エクスポート宣言
#ifdef _WIN32
  #define EXPORT __declspec(dllexport)
#else
  #define EXPORT __attribute__((visibility("default")))
#endif

EXPORT int32_t add(int32_t a, int32_t b) {
  return a + b;
}

EXPORT char* to_upper(const char* str) {
  size_t len = strlen(str);
  char* result = (char*)malloc(len + 1);
  for (size_t i = 0; i < len; i++) {
    result[i] = toupper(str[i]);
  }
  result[len] = '\0';
  return result;
}

EXPORT void free_string(char* str) {
  free(str);
}
```

## 文字列の受け渡し

```dart
// C の文字列関数のバインド
typedef ToUpperNative = Pointer<Utf8> Function(Pointer<Utf8>);
typedef ToUpperDart = Pointer<Utf8> Function(Pointer<Utf8>);
typedef FreeStringNative = Void Function(Pointer<Utf8>);
typedef FreeStringDart = void Function(Pointer<Utf8>);

final toUpper = dylib.lookupFunction<ToUpperNative, ToUpperDart>('to_upper');
final freeString = dylib.lookupFunction<FreeStringNative, FreeStringDart>('free_string');

String callToUpper(String input) {
  final ptr = input.toNativeUtf8();
  final result = toUpper(ptr);
  final dartStr = result.toDartString();

  // メモリ解放
  calloc.free(ptr);
  freeString(result);

  return dartStr;
}
```

## 構造体の受け渡し

```c
// C 側
typedef struct {
  double x;
  double y;
  double z;
} Vector3;

EXPORT double magnitude(Vector3* v) {
  return sqrt(v->x * v->x + v->y * v->y + v->z * v->z);
}
```

```dart
// Dart 側
final class Vector3 extends Struct {
  @Double()
  external double x;

  @Double()
  external double y;

  @Double()
  external double z;
}

typedef MagnitudeNative = Double Function(Pointer<Vector3>);
typedef MagnitudeDart = double Function(Pointer<Vector3>);

final magnitude = dylib.lookupFunction<MagnitudeNative, MagnitudeDart>('magnitude');

double calcMagnitude(double x, double y, double z) {
  final vec = calloc<Vector3>();
  vec.ref.x = x;
  vec.ref.y = y;
  vec.ref.z = z;

  final result = magnitude(vec);
  calloc.free(vec);
  return result;
}
```

## 実用例: 高速画像処理

```c
// image_utils.c
EXPORT void apply_grayscale(
  uint8_t* pixels,
  int32_t width,
  int32_t height
) {
  int total = width * height * 4;  // RGBA
  for (int i = 0; i < total; i += 4) {
    uint8_t gray = (uint8_t)(
      0.299 * pixels[i] +
      0.587 * pixels[i+1] +
      0.114 * pixels[i+2]
    );
    pixels[i] = gray;
    pixels[i+1] = gray;
    pixels[i+2] = gray;
  }
}
```

```dart
typedef GrayscaleNative = Void Function(Pointer<Uint8>, Int32, Int32);
typedef GrayscaleDart = void Function(Pointer<Uint8>, int, int);

final grayscale = dylib.lookupFunction<GrayscaleNative, GrayscaleDart>('apply_grayscale');

Future<Uint8List> applyGrayscale(Uint8List pixels, int width, int height) async {
  final ptr = calloc<Uint8>(pixels.length);
  ptr.asTypedList(pixels.length).setAll(0, pixels);

  grayscale(ptr, width, height);

  final result = Uint8List.fromList(ptr.asTypedList(pixels.length));
  calloc.free(ptr);
  return result;
}
```

## Android/iOS の CMakeLists.txt

```cmake
# android/CMakeLists.txt
cmake_minimum_required(VERSION 3.10)
project(mylib)

add_library(mylib SHARED
  ../native/mylib.c
  ../native/image_utils.c
)

target_include_directories(mylib PUBLIC ../native)
```

FFI を使うと Dart だけでは難しい処理を C ライブラリに委譲でき、パフォーマンスが 10〜100x 改善するケースもあります。
