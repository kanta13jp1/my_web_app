「法人化すべきか」は税負担の損益分岐点で判断する。

## 個人 vs 法人��税率比較

```
個人事業主 (所得税 + 住民税 + 事業税):
  課税所得 330〜695万円:  所得税 20% + 住民税 10% = 合計 30%
  課税所得 695〜900万円:  所得税 23% + 住民税 10% = 合計 33%
  課税所得 900〜1800万円: 所得税 33% + 住民税 10% = 合計 43%
```

**損益分岐点���目安: 年間利益 600〜800万円**

```

  個人: 約 180万円 (30%) の税金
  法人: 社長報酬を設定して所得分散 → 実効税率 20〜25% に圧縮可能
  → 差額 30〜60万円 / 年
```

## 法人化の主なメリット

```
1. 役員報酬で所得分散
   法人利益 → 役員報酬 (給与所得控除あり) → 実効税率を下げる

2. 経費の範囲が広がる
   家賃の一部 / 自動車 / 保険 / 福利厚生

3. 赤字の繰越期間
   個人: 3年 → 法人: 10年

4. 社会的信用
   BtoB 取引・API 契約・銀行融資

5. 退職金の積み立��
   小規模企業共済 + 役員退職金 (非課税枠大)
```

## 合同会社 vs 株式会社

```
合同会社 (LLC):
  設立費用: 約 6万円 (定款認証不要)
  決算公告: 不要
  外部投資: 受けにくい
  個人開発に最適: 節税 + 低コスト + シンプル

  設立費用: 約 25万円
```
