### はじめに

「自分株式会社」は Notion・Evernote・Slack など21競合の機能を1つに統合したAIライフマネジメントアプリです。Flutter Web + Supabase で開発しており、最近「公開メモ」機能のユーザーが SNS でシェアできる仕組みを追加しました。

シェアするだけでは面白くない。読んだ人がリアクションできる仕組みを、**ログイン不要**で実装しました。さらに同日、ノートコメント機能（CRUD）も実装し、メモ周りのソーシャル体験を一気に強化しました。

今回のポイントは3点です。

- **SNS OGP**: Twitter / LINE のカードに実際のメモ内容を表示する Edge Function
- **絵文字リアクション**: IP の SHA-256 ハッシュで重複防止、ログイン不要で 👍❤️🔥💡🎉 を押せる
- **ノートコメント**: Supabase Edge Function + Flutter UI で CRUD を完結させる

### 実装方法

#### 1. OGP メタタグ付き HTML を返す Edge Function

公開メモの URL を `https://your-project.supabase.co/functions/v1/public-memo-share?id=xxx` にします。SNS クローラーがアクセスした場合は OGP タグ付き HTML を返し、ブラウザからのアクセスはアプリ URL へリダイレクトします。

```typescript
// supabase/functions/public-memo-share/index.ts
const isBot = /Twitterbot|facebookexternalhit|Slackbot|TelegramBot|WhatsApp|LINE/i
  .test(req.headers.get('user-agent') ?? '');

if (isBot) {
  return new Response(
    `<!DOCTYPE html><html><head>
      <meta property="og:title" content="${memo.title}" />
      <meta property="og:description" content="${memo.content.slice(0, 120)}" />
      <meta property="og:image" content="${ogpImageUrl}" />
      <meta name="twitter:card" content="summary_large_image" />
    </head><body></body></html>`,
    { headers: { 'Content-Type': 'text/html' } }
  );
} else {
  return Response.redirect(appUrl);
}
```

ポイントは User-Agent 判定でボットとブラウザを振り分けることです。Twitter / LINE / Slack のプレビュー生成ボットを正規表現でまとめて検出します。

#### 2. memo_reactions テーブルの設計

ログイン不要のリアクションを実装するために、IP アドレスを直接保存するのは NG です。代わりに **SHA-256 ハッシュ**を使います。

```sql
CREATE TABLE memo_reactions (
  id          uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  memo_id     uuid REFERENCES memos(id) ON DELETE CASCADE,
  emoji       text NOT NULL CHECK (emoji IN ('👍','❤️','🔥','💡','🎉')),
  ip_hash     text NOT NULL,
  created_at  timestamptz DEFAULT now(),
  UNIQUE (memo_id, emoji, ip_hash)
);
```

`UNIQUE (memo_id, emoji, ip_hash)` の制約を「トグル」に活用します。INSERT で UNIQUE 違反が起きたら DELETE する、という単純なロジックです。

```typescript
const ipHash = await hashIp(req.headers.get('x-forwarded-for') ?? '');

try {
  await supabase.from('memo_reactions').insert({ memo_id, emoji, ip_hash: ipHash });
  return { action: 'added' };
} catch (e) {
  if (e.code === '23505') {  // unique_violation
    await supabase.from('memo_reactions')
      .delete().match({ memo_id, emoji, ip_hash: ipHash });
    return { action: 'removed' };
  }
  throw e;
}
```

#### 3. Flutter の _MemoReactionsBar ウィジェット

Flutter 側は `AnimatedContainer` と `Wrap` を組み合わせて、押した感触のある UI を作りました。

```dart
class _MemoReactionsBar extends StatefulWidget {
  final String memoId;
  const _MemoReactionsBar({required this.memoId});

  @override
  State<_MemoReactionsBar> createState() => _MemoReactionsBarState();
}

class _MemoReactionsBarState extends State<_MemoReactionsBar> {
  final emojis = ['👍', '❤️', '🔥', '💡', '🎉'];
  Map<String, int> counts = {};
  Set<String> myReactions = {};

  Future<void> _toggle(String emoji) async {
    final result = await MemoReactionsService.toggle(widget.memoId, emoji);
    setState(() {
      if (result.action == 'added') {
        counts[emoji] = (counts[emoji] ?? 0) + 1;
        myReactions.add(emoji);
      } else {
        counts[emoji] = (counts[emoji] ?? 1) - 1;
        myReactions.remove(emoji);
      }
    });
  }

  @override
  Widget build(BuildContext context) {
    return Wrap(
      spacing: 8,
      children: emojis.map((e) => AnimatedContainer(
        duration: const Duration(milliseconds: 200),
        padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 6),
        decoration: BoxDecoration(
          color: myReactions.contains(e)
              ? Theme.of(context).colorScheme.primaryContainer
              : Colors.grey.shade100,
          borderRadius: BorderRadius.circular(20),
        ),
        child: GestureDetector(
          onTap: () => _toggle(e),
          child: Text('$e ${counts[e] ?? 0}'),
        ),
      )).toList(),
    );
  }
}
```

#### 4. ノートコメント機能 (CRUD)

同日、ノートにコメントを付ける機能も実装しました。Supabase Edge Function `note-comments` が CRUD を担い、Flutter の `note_editor_page.dart` に UI を統合しています。

```sql
CREATE TABLE note_comments (
  id         uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  note_id    uuid REFERENCES notes(id) ON DELETE CASCADE,
  user_id    uuid REFERENCES auth.users(id),
  content    text NOT NULL,
  created_at timestamptz DEFAULT now()
);
ALTER TABLE note_comments ENABLE ROW LEVEL SECURITY;
-- 認証ユーザーのみ投稿可、全員が閲覧可
CREATE POLICY "read_all"    ON note_comments FOR SELECT USING (true);
CREATE POLICY "insert_own"  ON note_comments FOR INSERT
  WITH CHECK (auth.uid() = user_id);
CREATE POLICY "delete_own"  ON note_comments FOR DELETE
  USING (auth.uid() = user_id);
```

Edge Function はシンプルに HTTP メソッドで分岐します。

```typescript
// GET  → コメント一覧取得
// POST → コメント追加
// DELETE ?id=xxx → コメント削除
```

### 詰まったポイント

**1. OGP 画像の動的生成**

`og:image` に指定する画像を動的生成しようとしましたが、Deno Edge Function での Canvas 描画は対応が限定的です。今回は Supabase Storage に保存済みの静的 OGP 画像 URL を返すシンプルな実装に落ち着きました。将来的には `satori` (HTML→SVG) + `resvg-wasm` (SVG→PNG) の組み合わせで動的生成を検討しています。

**2. IP ハッシュとプライバシー**

素の IP を `crypto.subtle.digest('SHA-256', ...)` でハッシュ化しても、逆引きのリスクはゼロではありません。本番では `ip_hash = SHA-256(ip + salt)` のように salt を加えることを推奨します。今回は PoC として salt なしで実装しましたが、将来のアップデートで対応予定です。

**3. Flutter の `withOpacity` 廃止**

Flutter 最新版では `Color.withOpacity()` が deprecated になっています。`withValues(alpha: 0.5)` への移行が必要でした。`flutter analyze` で検出し、全箇所を一括修正しました。

```dart
// Before (deprecated)
Colors.blue.withOpacity(0.5)

// After
Colors.blue.withValues(alpha: 0.5)
```

### まとめ

今回の実装で「公開メモ → SNS シェア → リアクション → コメント」という小さなソーシャルループが完成しました。ログイン不要でリアクションできるため、ユーザーでない人でも気軽に反応でき、シェアした本人のモチベーションにもなります。

技術的なポイントをまとめると:

- OGP は **Edge Function でボット判定 → HTML/リダイレクト振り分け**
- リアクションは **UNIQUE 制約 + INSERT 違反をトグルとして活用**
- コメントは **RLS ポリシーで認証ユーザーのみ投稿可・全員閲覧可**
- Flutter UI は **AnimatedContainer + Wrap** でシンプルかつ感触のある実装
