## 本文

### 「全部入り」のアプリが欲しかった

Notion でメモを取り、Evernote に昔のノートが残り、MoneyForward で家計を管理し、Slack で仕事の連絡をし、X で情報収集をする。

ツールが増えるたびに、情報が分散していく。
「あのメモどこに書いたっけ？」が日常になっていた。

だから作ることにした。全部入りのアプリを。

### 自分株式会社

名前は「自分株式会社」。自分の人生を経営するプラットフォームだ。

競合は21社。Notion、Evernote、MoneyForward、X、Animaworks、Claude Code、Codex、netkeiba、OpenClaw、Claude Cowork、Chatwork、Slack、ジョブカン、Amazon、Google、Microsoft、Discord、LINE、Facebook、Liven、GitHub。

無謀に聞こえるかもしれない。でも1人でも作れる理由がある。

### AIが経営する会社

このアプリの特徴は、AIが経営に参加していることだ。

毎朝9時にAIが日次レポートを作り、Xに投稿する。
毎時、サポートチケットを確認し、返信し、バグがあればコードを読んで修正する。
毎日、競合21社のWebサイトを監視し、変化があれば記録する。

全部で9つの自動化タスクが24時間動いている。サーバーも追加費用もなし。Claude Code の Schedule 機能だけで実現している。

### 4人のユーザーから

現在の登録ユーザーは4人。まだ始まったばかりだ。

でも進捗バーは確実に伸びている。

```
短期計画 ████░░░░░░ 35%
vs Notion █░░░░░░░░░ 8%
vs Amazon █░░░░░░░░░ 3%
```

Notion の1億ユーザーに追いつくには気の遠くなる道のりだ。でも、まず10人、次に100人。

### 毎日ブログを書く理由

このプロジェクトでは、毎日技術ブログを書くと決めている。

Zenn には技術的な実装の話を。
Qiita には実用的な手順を。
dev.to には英語で。
はてなブログには週次の成長記録を。
そしてこの note にはストーリーを。

書くことで考えが整理され、書くことで人に見つけてもらえる。
