### はじめに

「自分株式会社」は、Notion・Evernote・MoneyForward・Slack・Chatwork・ジョブカンなど21の競合SaaSを1つに統合するFlutter Web + Supabaseのアプリです。

個人向けの機能は充実してきましたが、B2B（法人・チーム）向けの導線が弱いという課題がありました。今日の開発では **B2Bエンタープライズ向けランディングページ** を `/enterprise` ルートに実装しました。

### 実装した内容

#### 1. B2B エンタープライズページ (`enterprise_page.dart`)

4つのセクションで構成したフルページを実装しました。

**① ヒーローセクション**

**② コスト削減シミュレーション**

1人あたりの月額コストを横棒グラフで可視化:

| ツール | 月額/人 |
|--------|---------|
| Slack | ¥750 |
| Chatwork | ¥700 |
| ジョブカン | ¥500 |
| MoneyForward | ¥500 |
| Notion | ¥1,650 |
| **合計** | **¥4,100** |
| **自分株式会社** | **¥0** |

10人チームで年間**¥492,000**の節約になります。これを視覚的なプログレスバーUIで表現しました。

**③ 活用シーン（ユースケース）カード**

#### 2. マイグレーション (`20260330000001_create_enterprise_inquiries.sql`)

RLS付きの問い合わせテーブルを作成:

```sql
CREATE TABLE enterprise_inquiries (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  email text NOT NULL,
  company_name text NOT NULL,
  message text,
  status text NOT NULL DEFAULT 'new',
  created_at timestamptz NOT NULL DEFAULT now()
);

ALTER TABLE enterprise_inquiries ENABLE ROW LEVEL SECURITY;

-- anon ユーザーが挿入できる
CREATE POLICY "anon can insert enterprise_inquiries"
  ON enterprise_inquiries FOR INSERT WITH CHECK (true);
```

#### 3. コードブロック コピーボタン

`markdown_preview.dart` の `CodeElementBuilder` に `_CopyCodeButton` ウィジェットを追加。クリック後2秒間「Copied!」に変わるフィードバックUXを実装:

```dart
class _CopyCodeButton extends StatefulWidget {
  @override
  Widget build(BuildContext context) {
    return InkWell(
      onTap: _copy,
      child: Row(
        children: [
          Icon(_copied ? Icons.check : Icons.copy),
          Text(_copied ? 'Copied!' : 'Copy'),
        ],
      ),
    );
  }
}
```

#### 4. flutter analyze 0件 修正

Flutter 3.32.0+ で `RadioListTile.groupValue` と `RadioListTile.onChanged` が deprecated になりました。`growth_acquisition_signal_page.dart` で使用していた箇所を修正し、flutter analyze **0件**を維持。

### 詰まったポイント

**RadioGroup vs カスタム実装**

Flutter 3.32.0+ の `RadioGroup` ウィジェットを使おうとしましたが、linterが自動的にカスタムInkWell実装に書き換えました。これは `RadioGroup` APIがまだ安定していないことを示しており、カスタム実装の方がベターな場合もあります。
