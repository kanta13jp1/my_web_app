### はじめに

「自分株式会社」は Notion・Evernote・MoneyForward・Slack 等21社を超えることを目標に、Flutter Web + Supabase で個人が運営しているAI統合ライフマネジメントアプリです。

今日はこの21社対応の比較ページに Google・Microsoft・Discord・LINE・Facebook・Liven・GitHub の7社分のSEO OGPを追加したことと、Gemini 2.5 Flash を使った政治データAI分析のEdge Functionを新規作成した話を書きます。

### 比較SEOページのOGP動的生成

競合比較ページ (`/vs-notion`, `/vs-google` など) は Flutter Webルート上に存在するため、SPAのビルド後は `index.html` が返されます。

FacebookやTwitterのクローラーはJavaScriptを実行しないため、OGPメタタグをHTMLの静的シェルに埋め込む必要があります。

```html
<!-- index.html のSEOシェル内 JS -->
var competitorMeta = {
  'notion': { title: '自分株式会社 vs Notion | ...', desc: '...' },
  'google': { title: '自分株式会社 vs Google | ...', desc: '...' },
  // 21社分...
};
var vsMatch = path.match(/\/vs-([a-z0-9\-]+)$/);
if (vsMatch) {
  var meta = competitorMeta[vsMatch[1]];
  if (meta) {
    setMeta('og:title', meta.title);
    setMeta('og:description', meta.desc);
    // twitter:title, twitter:description, description も同様
  }
}
```

Flutter の `window.addEventListener('flutter-first-frame')` でSEOシェルを削除するため、ユーザーには通常通り Flutter アプリが表示されます。クローラーだけが静的なOGPを読み取るという仕組みです。

今回追加した7社:

| 競合 | SEOキーワード |
|------|--------------|
| Google | Google Keep代替・Workspace代替 |
| Microsoft | OneNote代替・To Do代替・Copilot代替 |
| Discord | Nitro不要・個人生産性 |
| LINE | LINEメモ代替・スケジュール代替 |
| Facebook | プライバシー安全・個人情報管理 |
| Liven | ライフスタイル管理代替 |
| GitHub | 開発者向けライフ管理 |

### Gemini 2.5 Flash × Edge Function で政治データ分析

もう一つの実装は `gemini-election-analysis` という Supabase Edge Function です。

国民民主党の統一地方選「700人必達」目標をAIが分析し、都道府県別KPI配分シミュレーションを返します。

```typescript
// supabase/functions/gemini-election-analysis/index.ts
const response = await fetch(
  `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${geminiApiKey}`,
  {
    method: "POST",
    body: JSON.stringify({
      contents: [{ parts: [{ text: prompt }] }],
      generationConfig: {
        responseMimeType: "application/json",
        temperature: 0.2,
      },
    }),
  }
);
```

`responseMimeType: "application/json"` を指定することで、Geminiがそのままパース可能なJSONを返してくれます。プロンプトにJSONスキーマを埋め込んで構造化出力を強制する方式です。

### 詰まったポイント

**BOM文字問題**: `local-election-intelligence/index.ts` の先頭にBOM (`\uFEFF`) が混入しており、Deno lintが通らない問題がありました。エディタのBOM自動付加が原因で、明示的に削除して解決。

**deno lint での trailing comma**: Edge Functionの関数呼び出しに trailing comma がないと lint エラーになるため、全引数末尾にカンマを追加。
