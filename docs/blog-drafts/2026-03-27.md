### はじめに

「自分を会社として経営する」というコンセプトで、Flutter Web + Supabase を使ったライフマネジメントアプリを開発しています。

Notion・Evernote・MoneyForward・Slack・X・Amazon など21社の競合サービスが提供する機能を1つに統合し、さらに**人間の思考・行動・意思決定を補助するAI機能**を組み込んでいます。

本記事では、直近1週間で実装した以下の機能群を中心に、設計思想・実装方法・詰まったポイントを紹介します。

- **見栄ガード** — かっこつけない仕組み
- **論理的意思決定ガード** — 非論理的な判断を検知してブロック
- **MAGIシステム** — 3つの視点で判断を補強
- **浪費トラッキング** — 投資を除いた資産放出の記録
- **思考キャプチャ** — 浮かんだ思考を即座に保存
- **人生目標管理** — 夢→大目標→中目標→小目標のツリー構造
- **コンビニ経営シミュレーション** — 経営判断力を鍛えるゲーム
- **Claude Code Schedule による完全自動化** — CS対応・日次レポート・ブログ下書きをAIが自動実行


#### 4. GitHub Actions による完全自動化 (CS・日次レポート・ブログ)

```yaml
# .github/workflows/cs-check.yml
name: CS Auto Check
on:
  schedule:
    - cron: '0 * * * *'  # 毎時実行
jobs:
  cs-check:
    runs-on: ubuntu-latest
    steps:
      - uses: anthropics/claude-code-action@beta
        with:
          task: cs-check
```

Claude Code Schedule を活用し、以下を完全自動化しました:

| タスク | 頻度 | 内容 |
|---|---|---|
| `cs-check` | 毎時 | サポートチケット返信・バグ修正・インフラ監視 |
| `daily-report` | 毎朝9時 | メトリクス取得・X投稿・競合モニタリング |
| `blog-draft` | 毎日8時 | 技術ブログ下書き自動生成 |
| `pr-auto-review` | 3時間ごと | PRのセキュリティ・品質自動レビュー |

### 詰まったポイント

#### 1. GitHub Actions の main ブランチ保護

Claude Code Schedule から `git push origin main` を直接実行しようとすると、ブランチ保護ルールに引っかかりました (#234, #235)。

**解決策**: 自動化タスクはブランチを作成→PRを作成→自動マージ、というフローに変更。

```bash
# NG: main に直接push
git push origin main

# OK: ブランチ経由
git checkout -b schedule/cs-check-$(date +%Y%m%d%H%M)
git push -u origin HEAD
gh pr create --title "自動: CS チェック" --base main
```

#### 2. X投稿のJSONエスケープ問題 (#237)

シェルスクリプト内でJSONに日本語テキストを埋め込む際、特殊文字(`"`, `\n`, `#`)でエスケープが崩れる問題。

**解決策**: `jq` を使って安全にJSONを生成。

```bash
# NG: 直接埋め込み
curl -d '{"text": "'"$TEXT"'"}'

# OK: jq で生成
JSON=$(jq -n --arg text "$TEXT" '{"text": $text}')
curl -d "$JSON"
```

#### 3. マインドマップのスクロール競合 (#241)

Flutter Webでマインドマップのズーム操作とページスクロールが競合し、意図しないスクロールが発生。

**解決策**: `GestureDetector` に `onPointerSignal` を追加し、ポインタシグナルを横取りして `TransformationController` に渡す。
