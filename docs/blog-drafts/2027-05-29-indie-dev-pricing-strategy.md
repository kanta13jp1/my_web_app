# 個人開発の価格戦略 — フリーミアムから有料転換まで実践パターン

個人開発で最も難しい決断の1つが「いくらにするか」。価格を間違えると無料でも使われないし、高すぎると誰も買わない。実践した3パターンを共有する。

## 最初に結論

```
フリーミアム: ユーザー獲得は最速・収益化は最難
定額課金:    シンプル・予測可能・解約も早い
使用量課金:  使うほど払う・重ユーザーに強い
```

どれが正解かはプロダクトの性質による。ただし**最初は無料で始めるのが正解**。

## なぜ最初は無料か

```
無料期間の目標:
  1. PMF (Product-Market Fit) を確認する
  2. 課金するほどの価値を生み出しているか検証する
  3. 使い方のパターンを観察する
  4. 「これないと困る」ユーザーを見つける
```

無料で使われないものは有料でも使われない。まず価値を証明する。

## パターン1: フリーミアム

```
Free tier:
  - 基本機能すべて無料
  - 月100件まで (使用量制限)
  - 1ユーザーのみ

Pro tier: $9/月
  - 無制限
  - チーム共有
  - 優先サポート
```

**メリット**:
- ユーザー獲得が最速
- 無料ユーザーが口コミ・ブログで宣伝してくれる
- 価値を体験してから課金判断できる

**デメリット**:
- 無料ユーザーのサポートコストが重い
- 転換率が低い (2-5%)
- 価値を伝えないと「なぜ払うか」が伝わらない

**転換を促すトリガー**:

```
- 制限に到達したとき (月100件 → 101件目でプロンプト)
- 重要な機能に触れたとき (チーム機能を発見したタイミング)
- ヘビーユースが続いたとき (7日連続でログイン)
```

## パターン2: 定額課金 (サブスク)

```
月額: $12/月 または $99/年 (年払い17%オフ)
試用: 14日間無料 (クレジットカード不要)
```

**メリット**:
- 収益が予測しやすい (MRR)
- シンプルで説明しやすい
- 年払い割引で長期コミットを促せる

**デメリット**:
- 試用期間終了後に解約が集中する
- 「お金を払い続ける価値があるか」を毎月証明し続ける必要

**解約を減らすには**:

## パターン3: 使用量課金

```
基本: 無料 (月 $0)
使用量課金:
  - AI 応答: $0.01/回
  - ストレージ: $0.50/GB/月
  - API コール: $0.001/リクエスト
```

**メリット**:
- 使う人だけが払う (公平)
- 重ユーザーから自然に多く収益が出る
- 低コストユーザーは事実上無料で使える

**デメリット**:
- 請求額が予測しにくい (ユーザーが不安になる)
- 請求処理が複雑 (Stripe Metered Billing)
- 「使いすぎた」ショックでチャーンリスク

**うちの実装 (Supabase + Stripe)**:

```typescript
// Edge Function でメーター記録
async function recordUsage(userId: string, quantity: number) {
  const stripe = new Stripe(Deno.env.get('STRIPE_SECRET_KEY')!);
  await stripe.subscriptionItems.createUsageRecord(subscriptionItemId, {
    quantity,
    timestamp: Math.floor(Date.now() / 1000),
    action: 'increment',
  });
}
```

## 価格の決め方

```
コストベース (NG): 原価 × 3倍 → 誰も払わない価格になる

価値ベース (OK):
  1. ユーザーが代替で払うコストを調べる (SaaS競合の価格)
  2. 「いくらなら迷わず払うか」をユーザーに直接聞く
  3. 競合の50-80% → 差別化不要
     競合の100-150% → 明確な価値上乗せ必要
```

## A/B テスト: 価格は実験できる

```dart
// Supabase の feature flags で価格 A/B テスト
final testGroup = await supabase.rpc('get_price_ab_group', params: {'user_id': userId});
final price = testGroup == 'A' ? 9.99 : 14.99;
```

月1,000人のアクティブユーザーがいれば、価格変更の効果を2週間で計測できる。

## まとめ

価格戦略の実践チェックリスト:
1. まず無料で始める → PMF を確認
2. 「これないと困る」と言ってくれるユーザーを5人見つける
3. そのユーザーに「いくらなら払うか」を聞く
4. フリーミアム / 定額 / 使用量から選ぶ
5. 実装して計測する → 迷ったら実験する

価格は「決定」ではなく「仮説」。変えていい。変えることで学べる。
