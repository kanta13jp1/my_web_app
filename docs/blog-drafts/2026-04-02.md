### 実装方法

#### 1. MediaRecorder の mimeType 自動検出

iOS Safari は `video/webm;codecs=opus` に対応していません。以下のように優先順位をつけて自動選択します。

```dart
// Flutter Web から dart:js_interop 経由で JavaScript API を呼び出す
String _getSupportedMimeType() {
  final types = [
    'audio/webm;codecs=opus',
    'audio/webm',
    'audio/mp4',
    'audio/ogg;codecs=opus',
    '',  // ブラウザデフォルト
  ];
  for (final type in types) {
    if (type.isEmpty) return type;
    final supported = MediaRecorder.isTypeSupported(type);
    if (supported) return type;
  }
  return '';
}
```

**詰まったポイント①**: `MediaRecorder.isTypeSupported` の戻り値は Dart の `bool` ではなく `JSBoolean` として返ってきます。`dart:js_interop` の型変換を正しく扱わないとコンパイルエラーになります。

```dart
// NG: JSBoolean を bool として直接扱う
if (MediaRecorder.isTypeSupported(type)) { ... }

// OK: .toDart で変換
if (MediaRecorder.isTypeSupported(type).toDart) { ... }
```

#### 2. WAV エンコーダ (16bit PCM)

`MediaRecorder` が録音した Blob を `decodeAudioData` でデコードし、WAV ヘッダーを付与して書き出します。

```typescript
// Supabase Edge Function (Deno) での WAV 変換ヘルパー
function encodeWAV(samples: Float32Array, sampleRate: number): ArrayBuffer {
  const buffer = new ArrayBuffer(44 + samples.length * 2);
  const view = new DataView(buffer);

  // RIFF ヘッダー
  writeString(view, 0, 'RIFF');
  view.setUint32(4, 36 + samples.length * 2, true);
  writeString(view, 8, 'WAVE');
  writeString(view, 12, 'fmt ');
  view.setUint32(16, 16, true);        // チャンクサイズ
  view.setUint16(20, 1, true);         // PCM フォーマット
  view.setUint16(22, 1, true);         // モノラル
  view.setUint32(24, sampleRate, true);
  view.setUint32(28, sampleRate * 2, true);
  view.setUint16(32, 2, true);
  view.setUint16(34, 16, true);        // 16bit
  writeString(view, 36, 'data');
  view.setUint32(40, samples.length * 2, true);

  // Float32 → Int16 変換
  let offset = 44;
  for (const sample of samples) {
    const s = Math.max(-1, Math.min(1, sample));
    view.setInt16(offset, s < 0 ? s * 0x8000 : s * 0x7FFF, true);
    offset += 2;
  }
  return buffer;
}
```

この WAV ファイルは **iOS Safari・Android Chrome・Windows Edge すべてで再生可能** です。

#### 3. AI ギターコーチ

練習セッションのデータを Supabase に蓄積し、Claude API 経由で分析・アドバイスを生成します。

```typescript
// supabase/functions/guitar-studio/index.ts (ai_analyze エンドポイント)
case 'ai_analyze': {
  const { data: stats } = await supabase
    .from('guitar_practice_stats')
    .select('*')
    .eq('user_id', userId)
    .order('practice_date', { ascending: false })
    .limit(7);

  const prompt = `
    直近7日間の練習データ: ${JSON.stringify(stats)}
    上記をもとに:
    1. 練習パターンの分析 (良い点・改善点)
    2. 今日の練習メニュー (3項目)
    3. 来週の目標
    を日本語で簡潔に提案してください。
  `;

  // Claude API 呼び出し (Edge Function 内)
  const analysis = await callClaude(prompt);
  return new Response(JSON.stringify({ analysis }), { status: 200 });
}
```

### 詰まったポイント

**詰まったポイント②: MediaRecorder の空ボディクラッシュ**

192 本の Edge Function 全てで `req.json()` が空ボディ時に例外を投げる問題が発生しました。

```typescript
// NG: POST ボディが空の GET リクエストでクラッシュ
const body = await req.json();

// OK: try/catch でフォールバック
let body: Record<string, unknown> = {};
try {
  if (req.method !== 'GET') {
    body = await req.json();
  }
} catch {
  // 空ボディは許容
}
```

**詰まったポイント③: Flutter Web の `JSAny?` 型エラー**

`dart:js_interop` で外部 JavaScript 関数を定義する際、戻り値の型が `JSAny?` (nullable) なのに `JSAny` として受け取ろうとしてコンパイルエラーになりました。

```dart
// NG
@JS('someJsFunc')
external JSAny someJsFunc();

// OK
@JS('someJsFunc')
external JSAny? someJsFunc();
```

**詰まったポイント④: Migration の重複 version**

`supabase migration repair` でバージョン重複エラーを解消しました。本番環境の `schema_migrations` テーブルに既に適用済みのバージョンを再 apply しようとしたのが原因です。
