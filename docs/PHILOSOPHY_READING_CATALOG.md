# 哲学書目録と版情報

2026-10-11拡充: 56著者・80著作。古代ギリシア・ローマ、中国、南アジア、日本、チベット、イスラーム圏、欧米の中世・近代・現代を対象とする入門用共有目録。全哲学書の網羅を意味しない。

## 分類と帰属

- 著者の世紀はおおよその思想・著述活動、著作の世紀は成立・初版刊行を表す。1900年は19世紀、1901年は20世紀。
- 国／地域は歴史上の活動との関係。古代・中世の人物を現代の国籍に固定しない。地域は複数選択できる。
- ジャンルは著作の主題（倫理学、形而上学、認識論、政治哲学など）、著者の思想伝統とは別。
- 著作・著者ごとにSEPなどの学術的出典URLを保持。年代・帰属に議論がある場合は「不明」や概数、注記を使用。
- 論語、墨子、エピクテトスの教説、正法眼蔵随聞記などの編集・伝承を本人の単独執筆と区別。共産党宣言はエンゲルスとの共著と明記。
- 既存13著者・17著作のIDは維持。読了数は著作のIDで集計し、版や再読で増やさない。目録が増えれば全体の分母は増える。

## 検証契約

目録IDの一意性・著者との対応・紀元前と世紀境界・東西／古代／現代の分類・HTTPS出典、版情報のJSON互換性と検索クエリをDartで検証。APIの実DB保存と所有権、URL拒否、PC／モバイルでの版取り込み・保存・再表示・ISBNリンク遷移を専用GitHub Actionsで確認する。購入処理は行わず、ブラウザテストの販売先はテストページに置き換える。
