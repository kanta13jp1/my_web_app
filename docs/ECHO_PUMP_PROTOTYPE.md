# 残響ポンプ室：最小プロトタイプ

## 目的

一人制作向けのホラー企画から、電源切替・音による敵の誘導・部品回収・修理・封鎖・排水・脱出の一巡を試す。

ホームの「残響ポンプ室」または `/echo-pump` から開く。ホーム検索用キーワードは「ゲーム」「ホラー」「脱出」「ポンプ」「残響」。既存アプリと同じルーティングを使う。

## 遊び方

- 見取り図の下の移動ボタンから隣の区画へ移動する。
- 管理室の配電盤は最大2系統まで通電できる。最後に入れた系統の音へ敵が1操作ごとに1部屋ずつ移動する。
- B系統が工具棚を開く。ヒューズを拾い、ポンプ室で修理する。
- C系統で敵を点検槽へ誘導し、ポンプ室で隔壁を閉じる。
- 修理・隔壁閉鎖・C系統の通電がそろうと排水できる。管理室経由で出口へ向かう。
- 敵との接触で体力を1失い、安全な管理室へ戻る。体力0で失敗。リトライで初期状態へ戻る。

無傷の経路例：Bオン→Aオン→中央廊下→工具庫→回収→中央廊下→ポンプ室→修理→中央廊下→管理室→Bオフ→Cオン→2ターン待機→中央廊下→ポンプ室→隔壁閉鎖→排水→中央廊下→管理室→出口。

## 最小版の範囲

一人称3D・射撃・実際の音声・セーブは含まない。敵1体、体力3、固定配置、7区画のターン制。タッチとマウスで遊ぶ。再読込で最初から。ネットワーク・認証・DB・金融データの追加処理はない。

`lib/models/echo_pump_game.dart` がゲームの状態遷移、`lib/pages/echo_pump_game_page.dart` が表示と入力を担当する。ゲームのロジックにはFlutter依存がない。既存パッケージだけを使う。

## 検証

GitHub Actionsで対象の解析・モデルテスト・360/1200幅のWidget操作テストを行う。独立したfixtureをWebビルドし、Playwrightのdesktop/mobileで脱出・リトライ・再読込を操作する。fixtureは金融・認証・バックエンドを初期化しない。アプリ全体へのルートとカタログ接続は通常PR CIで解析する。

これは試作であり、企画の30〜45分版や本番配信を完成させたものではない。
