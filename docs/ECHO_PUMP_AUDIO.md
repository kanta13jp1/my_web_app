# 残響ポンプ室のBGM・SE

既存のaudioplayers 6.7.1を使用。追加依存はない。初期状態は無音で、タイトル・導入・ゲーム共通の「音をON」で明示的に再生する。音量の初期値は35%、BGMはさらに55%のゲインとし、SEと別プレイヤーで再生する。ページ再読込では無音へ戻る。

16秒の低い機械音と短い音列のBGMをループ。開始、足音、通電、回収、修理、隔壁、排水、接触、脱出、失敗の10種類のSEを用意した。ゲーム行動が成立しなければ操作SEを鳴らさず、接触・ゲーム終了の音を優先する。連打では古い未再生SEを捨て、最新の反応を優先する。脱出・失敗ではBGMを止めて終了SEを鳴らし、リトライでBGMを再開する。

非表示・アプリ中断ではBGMとSEを停止し、復帰時にBGMだけを再開する。ページ離脱でプレイヤーを破棄する。音声の取得・再生に失敗した場合は音をOFFへ戻し、短い案内と明示的なON操作での再試行を用意する。音声の失敗はゲームのターン・進行を変更しない。導入の一時停止は文章演出のみで、環境BGMは継続する。

## 素材の来歴

`scripts/generate_echo_pump_audio.py` による独自の数式合成。正弦波、独自に配列した音高、減衰、決定的なノイズを使用し、第三者の録音・曲・ゲーム音源は入力していない。PCM WAV / mono / 22050Hz / 16bit。仕様と各ファイルのSHA-256・長さ・ピーク・RMSは `assets/echo_pump/AUDIO_PROVENANCE.json` に記録した。

生成は `python scripts/generate_echo_pump_audio.py`、既存ファイルの形式・長さ・ハッシュ確認は `python scripts/generate_echo_pump_audio.py --check`。合成素材の商用・プライバシー審査は別記録で管理し、生成しただけで権利保証とはしない。

## 検証方針と制約

- コントローラーのミュート、音量0、非表示、復帰、終了、リトライ、遅い読み込み中のOFF、再生失敗・再試行、破棄をFake出力で確認する。
- Widgetで狭幅・広幅、音声が失敗しても開始できること、通電とSEの接続を確認する。
- Chromiumとmobile-chromeの実HTMLMediaElement再生成功、AudioContextのrunning、GainNodeの音量変更、ミュート、画面離脱時のclosed、取得失敗からの再試行をブラウザーで確認する。読み込み成功だけを再生成功とは扱わない。
- iPhone Safari実機の確認と、人による音色・聴感の評価は別途必要。システム側のミュートやスピーカー音量まではアプリから保証しない。

参照：Blue Fire公式のaudioplayers-v6.7.1ソース（AudioPlayer / AudioCache / WrappedPlayer）、MDN Autoplay guide。Webの音付き再生は利用者の操作が必要な場合があるため、自動再生に依存しない。
