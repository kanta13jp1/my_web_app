### 1. ユーザー獲得の加速 (最優先)
現在4人の登録者数を早急に増やす必要がある。本日追加した「毎日の習慣テンプレート」「リマインダー機能」「RewardsPage」「ActivityFeedPage」はユーザーエンゲージメントを高める重要機能。これらをまとめた**Zenn/Qiita 技術記事**を即日公開し、#buildinpublic タグで拡散すべき。記事のネタは「Flutter Web で習慣管理アプリを作る方法」が最も受けやすい。

### 2. 思考妨害排除機能 (abstinence_slips) の早期完成
`0886b21` で設計書と DB テーブルは完了済み。これは競合21社の中で自分株式会社にしかない独自機能。UI 実装を優先し、**差別化ポイント**として LP に追記することでユーザー獲得につなげる。

### 3. Supabase API 接続の自動化改善
Schedule タスクが毎回「Supabase API 接続不可」で終わっている。Claude Code Web のエグレスプロキシ制限を回避するため、**Claude Code Schedule を Remote Trigger** で実行するか、GitHub Actions 経由でレポート生成する方式に切り替えを検討。これにより日次メトリクスの自動取得が実現する。
