**3. Supabase API 接続問題の恒久対策**
Claude Code Web 環境からのエグレスプロキシブロックにより、毎日の日次レポートでリアルタイムメトリクスが取得できていない。GitHub Actions の `daily-report.yml` に Supabase API 呼び出しを移管し、Claude Schedule は Actions 生成済みレポートを読み込む形に切り替えることで、メトリクス欠損を解消できる (CLAUDE.md 「ケース A」アーキテクチャ対応)。
