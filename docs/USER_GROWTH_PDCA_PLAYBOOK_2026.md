## 2. なぜユーザーが増えなかったのか（5つの構造的根本原因）

1. **X タイムラインと LP 第一印象の断絶**:
   - X で貼られるカードが白背景の見切れ旧画面＋偽ボタン＋X 左下黒帯への文字被りで、「何が得られるか」が 1 秒で伝わらずタップされない。
   - タップしても Flutter 起動前シェル (`#seo-shell`) が白背景 (`#F5F7FA`) で、起動後に濃紺 (`#07111E`) へ切り替わるため視認フリクションが発生していた。
2. **LP 心臓部（登録なし AI 体験）の停止（OpenAI 429 単一障害点）**:
   - OpenAI 単一依存のため 429 エラー時に即時体験が機能せず、LP の最大差別化（「登録前に1件試す」）が発揮できていなかった。
3. **体験後フリクション（`h03` 77 trials → 0 save CTA）**:
   - 本番 LP 右パネルで「5つの短い質問で整理…」という入力ステップを挟み、かつ下部サンプル枠がダーク背景上で白浮きしている。初見ユーザーの 9 割は 5 問入力の前に離脱する。
4. **X アカウント内の集客導線断絶**:
   - 政治・選挙追跡では最大 44,555 imp（99 プロフィールクリック）の実績があるにも関わらず、プロフィール・固定ポスト・改善告知に「自分株式会社で解決できる具体的な日常課題」と統一ビジュアルがない。
5. **開発者用語中心の改善告知（`v1.0.2369`、`重複記録` 等）**:
   - 一般ユーザーには「支払い忘れや二重チェックの不安がなくなる」価値として翻訳されておらず、スクロールを止められない。
